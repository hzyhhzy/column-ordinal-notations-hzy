2026-09-30。前几稿的“普通容量够大”不能保证复制后继续覆盖。本稿改用更严格的关系：选中列的高度、高父和每一行的祖先关系都完全保持。

在下文明确的平高星父图范围内，这个关系可以持续模拟全部后续展开，包括暴露控制父时经过非一致高尖端的情况。由此从原候选 A、B 中提取两个七列父图过程 \(K_A,K_B\)，并有

\[
\boxed{\rho_F(K_A)\le\rho_Y(A),\qquad
\rho_F(K_B)\le\rho_Y(B).}
\]

这是辅助比较引理及较小核心的下界，**不是 A、B 的等价简化，也不是 Y 与 SRPD 的新大小比较**。仍需把 SRPD 五列块族与这些过程接起来，或找到其他比较路线。以下为纸面论证，未 Lean 形式化。

## 对象和已使用的原 Y 父表公式

列从0开始。每列有普通父表 \(P_j\)、普通高度 \(h_j=|P_j|\)，以及可空高父 \(H_j\)。普通行父向左；第 r 行父的高度至少为 r；高行祖先细化低行祖先。

目标是原 Y 的实际数值状态，处在已有[窄源类](../e0mn-y1343-aligned-20260920/COLORED-SPINES.zh-CN.md)中：

- 高边是对齐平星，高根普通，尖端比根高一行。
- 正普通行父都是普通列；尖端的全部正行父都是本星根，底父是本根或同根尖端。
- 零高度星保留原有严格接口；不将 `Y1343` 或 `Y134259` 未进入窄类的准备状态直接套入。

A、B 已有从 Y1343 到该窄类的实际路径，本稿使用其后代闭包及完整父表公式（未随本次收录的来源：`output/e0mn-y1343-aligned-20260920/aligned-source.cjs`）。没有重新证明整个 Y 的良基性，也没有从数值实验推断闭包。

源不必是规范 Y 数值词。定义一个原始父图过程 F：使用相同的平星父表复制公式，不在每步之后把它重建成数字再重新找父。实现见 y-induced-core.cjs（未随本次收录的来源：`output/y-134258a-49141710-srpd-20260930/y-induced-core.cjs`）。因此 F 的秩是该明确重写关系的下降秩；这里没有给这些父图另造一个已证明良序的字典序记号。

若目标末列 x 普通，最高控制行 r=h_x−1、父 c；高末列则以 c=H_x 控制，令 h=h_c。跨度 d=x−c。删旧末列后，第 b 份复制旧区间 `[c,x)`，父地址按所在份搬运。空图是终止态，不把展开函数对空图返回空图算作下降边。

普通首列在 r 以下继承旧末列父，在 r 以上及高标记处继承旧 c。高首列父为旧末列前 h 行的前份像，再接 b 个前份 c；其他列若以 c 为第 h 行祖先，就在第 h 行重复插入 b 个父项。其余列只搬运。指标0删末列。

## 诱导祖先关系

设源图 G 的列通过严格递增 f 选在实际目标 T 中，目标已截到 f(x) 为末列。要求：

\[
\begin{aligned}
h^T_{f(j)}&=h^G_j,\\
H^T_{f(j)}&=\begin{cases}\varnothing&H^G_j=\varnothing,\\f(H^G_j)&\text{否则},\end{cases}\\
i\prec_r^G j&\iff f(i)\prec_r^T f(j)
\quad\text{对所有 }i<j\text{ 和 }r.
\end{aligned}\tag{1}
\]

未选中目标列可以是普通列或高尖端。条件 (1) 不只是单向容量不等式；反向尤其保证源中不上升的数据不会在目标里擅自加高。

每个源直接父，恰是目标相应行路径上遇到的第一个选中祖先。反之，若对保留集合把每个普通父沿本行走到第一个保留祖先，保留高度及字面高父，且所有必要祖先存在，就得到这样的诱导图。不能随便删除一个行链的终止节点而仍声称高度不变。

## 暴露普通控制父

先补充真实 D 返回引理。D 是 `[1]` 后用 `[0]` 删回原宽；只改当前最后一列。

若末列普通，高度 m>0，最高父为 p，D 保留前 m−1 行，并继承 p 从第 m−1 行起的尾部；m=1 时连高标记一起完整继承 p。正行父普通，所以 m>1 时不会突然变成高列。

若末列高，根 c 高度 h，普通表长度 h+1，末父为 c，则高首接缝公式给

\[
P_D=P_x[0:h]\frown(c)=P_x,\qquad H_D=\varnothing.
\tag{2}
\]

这对第一尖端和非一致尖端都成立，不仅限于恒父第一尖端。

固定前缀后，D 的普通高度不超过当前和前缀的固定最大高度。把父表补缺为 −1，并附加高标记位：普通 D 在旧最高行把父换成更左父或 −1；高 D 保持父表、将高位由1变0。故每次 D 严格降低一个有限字典序状态，不能无限执行。

若源普通末列的控制行为 r、父为 c，由 (1)，f(c) 是目标末列的第 r 行祖先。不断 D 直到目标控制恰为 `(普通,r,f(c))`：

- 高于 r 的普通 D 保持第 r 行和全部低行；到 r 行时，父沿含 f(c) 的行链向左移动，不能越过它。
- r>0 时正行父普通，不会在到达之前产生高控制。
- r=0 时可以继承并经过高尖端；式 (2) 保留底父，再继续沿底链返回。

因此会在有限步内到达所需控制，不会先删空。r 以下的旧祖先关系完全保留；r 以上的临时变化无妨，因为该工作末列随后被源和目标的正式复制同时消费。

## 普通复制保持诱导关系

暴露后，源、目标采用同一指标 n。目标跨度 \(d'=f(x)-f(c)\)。新代表按

\[
f_b(j)=f(j)+b d'\qquad(c\le j<x)
\tag{3}
\]

选择，保留旧非末代表。末尾多出来的未选列用 `[0]` 删除。

逐行看复制后的森林：

- 首列低于 r 的父路径来自旧末列，在前一份中继续。暴露没有改变这些低行，它们遇到选中祖先的顺序仍与源相同。
- 首列 r 及以上的路径来自旧切点 c，因 c 的父都在 c 左方，源、目标都继承同一外部选中祖先路径。
- 其他列的每条行路径只作地址搬运。在到达首接缝之前，同份路径的第一个选中祖先不变；穿过接缝后使用前两项。

源、目标的“父在切点左方还是不在左方”一致，故相邻复制份的归属也一致。于是压去未选路径段后，恰得到源的全部行森林。高度未加行且切点高度精确相同，高父字面搬运也交换。

这一论证包括 r=0 且切点本身为高尖端：它的高根位于切点左侧，两边均继承这个外部根，不要求把高尖端当成普通列。

## 高复制保持诱导关系

源高末列的根为 c，目标高末列根字面等于 f(c)，两根高度同为 h，因此不需要先暴露。定义活动集合

\[
R=\{c\}\cup\{j:c\prec_h^G j\},\qquad
R'=\{f(c)\}\cup\{q:f(c)\prec_h^T q\}.
\]

条件 (1) 给 \(f^{-1}(R')=R\)。所以每个选中数据列是否加高完全一致。
仍按式 (3) 选择副本，逐行检查：

1. h 以下不插行；首根使用旧高末列的低父路径。该路径压去未选列后等于源路径，前份地址搬运亦同。
2. 在重复带内，源、目标重复的是同一第 h 行森林。各份首根连到前份首根，新增的根链在两边逐个对应。
3. 重复带以上，活动列的行号统一增加 b。某条第 u≥h 行路径一旦进入活动集合，行细化就迫使它的起点也在活动集合；因此不能发生选中不活动列的高行路径穿过一个被单独拉伸的活动中介。活动路径与非活动路径分别按原行或平移行搬运，压缩继续交换。

高尖端与其高根同步上升。旧高边的两个端点都是选中节点，搬运后仍字面匹配；新首根两边都普通。高度和高父条件遂与全部行森林一起恢复。

反向祖先保持是这一步不能省掉的假设。前稿仅有“目标容量≥源容量”，就不足以证明这项同步。

## 同一目标上的全后代模拟

零指标直接删到前一个代表。若源删空，目标继续用原 `[0]` 清空即可；这一步无需保存可继续调用的源合同。

由前两节，对每个源正步骤，先有限暴露、再真实复制、最后有限删尾，终点恢复 (1)。每个源步至少花费一个目标原步骤，没有每步重新选择初始目标。

因此从同一目标良基关系归纳，得到 F 源的良基性及

\[
\boxed{G\preccurlyeq T\quad\Longrightarrow\quad
\rho_F(G)\le\rho_Y(T).}\tag{4}
\]

这里要求实际目标一直满足开头的父表公式和窄类闭包；不是对所有原始 Y 字符串、所有高层结构的无条件定理。源则可始终是原始父图，不需要在归纳中重新证明数值规范性。

## 两个七列核心

在 A、B 中选择零基列

\[
(0,3,7,8,9,10,11).
\]

它们的诱导父表如下，高父空白表示普通列。

| 核心列 | 普通父表 | 高父 |
| --- | --- | --- |
| 0 | 空 | |
| 1 | 0 | |
| 2 | 1,1 | |
| 3 | 2,2,2 | 2 |
| 4 | 3,2,2 | 2 |
| 5 | 4,2 | |
| 6 在 K_A 中 | 2,2,2 | 2 |
| 6 在 K_B 中 | 3 | |

式 (4) 分别给出 \(\rho_F(K_A)\le\rho_Y(A)\)、\(\rho_F(K_B)\le\rho_Y(B)\)。另外直接代入 F 有

\[
K_A=K_B[1][0][0],\quad\text{故}\quad\rho_F(K_A)<\rho_F(K_B).
\]

按普通顶值1、高顶值2重建，两个初态数字分别为 `1,2,4,9,14,17,9` 和 `1,2,4,9,14,17,10`。这些数字只是辨认初态的辅助，不是宣称其整个原 Y 展开锥与 F 相同，更不是原 A、B 的等值标准式。

## A 的一个更简单的单参数下界族

在 A[n] 中选 `0,3`、所有根 \(r_b=7+4b\)（0≤b≤n），及最后的两尖端和入口。令 h=n+2，所得 \(G_h\) 是

\[
\begin{array}{c|c|c}
\text{列}&P&H\\\hline
0&()&\varnothing\\
j\ (1\le j\le h)&(j-1)^j&\varnothing\\
h+1&h^{h+1}&h\\
h+2&(h+1)\frown h^h&h\\
h+3&(h+2,h)&\varnothing.
\end{array}
\tag{5}
\]

表中上标表示父号的重复次数，不是序数幂。这只是一条普通阶梯，末端接两枚高尖端和一个两行入口。由诱导图引理，

\[
\rho_F(G_{n+2})\le\rho_Y(A[n])<\rho_Y(A).
\tag{6}
\]

这比在 A[n] 内直接寻找 SRPD 全对容量少了一层不必要的对应选择：现在可以先比较 SRPD 的 \(L_a\) 与明确父图 \(G_h\)。若以后证明每个 β_a 都被某个 \(\rho_F(G_h)\) 支配，结合已有 \(E=\sup_a\beta_a\)，就得到 E≤A。

**这项 β_a 与 G_h 的比较尚未完成；也没有证明 G_h 在 A 中共尾。** 这里只给出可供后续使用的充分路线，不把目标改成只研究这个路线。

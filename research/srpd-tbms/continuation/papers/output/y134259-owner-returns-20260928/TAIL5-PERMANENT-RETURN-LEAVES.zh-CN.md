## 1. 整个第一层基本列的闭式

令 P=(1,3,4)、R_b=2^(b+1)，则对每个 n≥0，原数值规则给

\[
\boxed{X[n]=P\frown\mathop{\frown}_{b=0}^{n}
(R_b,\ 2R_b+1,\ 3R_b+2,\ 4R_b+2).}\tag{1}
\]

例如

```text
X[0] = 1,3,4,2,5,8,10
X[1] = 1,3,4,2,5,8,10,4,9,14,18
X[2] = 1,3,4,2,5,8,10,4,9,14,18,8,17,26,34
```

每块首列 r_b=3+4b，其普通高度为 b+1。
第0块首列父表是 `[0]`；b>0 时它的 b+1个普通父全为 r_(b−1)。
块内其余三列的父表、高父分别为

\[
\begin{array}{c|c|c}
\text{列}&\text{普通父}&\text{高父}\\\hline
r_b+1&(r_b)^{b+2}&r_b\\
r_b+2&(r_b+1)\frown(r_b)^{b+1}&r_b\\
r_b+3&(r_b+2)\frown(r_b)^{b+1}&\text{无}
\end{array}\tag{2}
\]

证明：X末列为颜色1的高尖端，根为原值2的列，高度1。
整个四列坏块在该第1行组件内，所以第 b 份都上升 b行；
首根新行全接前份根，两个高尖端与末普通列按上升父表运输，得到 (2)。
首根各行数值依次为 2^(b+1),2^b,...,1。
两个高尖端的顶值为2，最后普通列顶值为1；自顶向下求和即得 (1)。
这是原规则逐份公式，不是从前三个数列实例插值。

## 2. 最高返回 R₂ 的定义

采用[两色窄类](../e0mn-y1343-aligned-20260920/COLORED-SPINES.zh-CN.md)。
高尖端颜色为同根底父链的深度；X的最高颜色为2，所有后代仍≤2。

普通列 e 若底父是颜色2尖端 t、高根为 c，且

\[
h_c\ge1,\qquad h_e=h_c+1,\qquad P_e(h_c)=c,
\]

称为 R₂。沿用返回类型的运输公式（未随本次收录的来源：`output/y134259-owner-returns-20260928/README.zh-CN.md`）：
高控制颜色 d只新生 R_(d−1)，普通正行控制首列不新生返回，
其他副本继承类型。因无颜色3，R₂只可能继承，不会凭空新生。

## 3. 永久叶定理

**在 X 的所有原标准后代中，每个 R₂ 都不被任何普通父边或高边引用。**
也就是没有后来列以它为父；不是说它自己没有父。
初始唯一 R₂ 是数值10的列6。它右边只有最后的5，后者的全部父都为列3，
所以该 R₂ 确为叶。给它作标记，之后所有副本继承标记。

更一般地，在当前窄类中，一组未被任何父边引用的标记列，其存活副本仍不被引用。
按一次原展开证明：

- 删尾不产生新边。
- 正控制切点 c 是旧末列的一条真实普通父或高父，因此不可能是标记叶。
- 非首复制列的父来自旧父的地址搬运；旧父不带叶标记，新父也不带。
- 普通首列的低父来自旧末列，其余父来自旧切点，都不是标记叶。
- 高首列及高插行重复带新用到的父，是旧父的搬运或某个新首根 c_b。
  旧父不是叶；c及其各份首根也不带叶标记。内部原叶副本不可能与 c_b重合。

全部情形都保持叶性；被复制的叶只能是非首模板，所以保留其 R₂类型。
结合无新 R₂的事实，标记叶恰好排满所有 R₂。归纳完成。

这比“最高返回数量有限”强，但不是一个下降量：叶数仍可随指标任意增加，
它们被展开时仍会触发复制。
尤其不能把叶随手删掉然后重算规范 Y；此前压层／删除改变父搜索的问题仍须另行处理。

## 4. 为什么旧高度1入口定理仍不能直接套用

最短的具体分支之一是 X[1][1]：

```text
X[1]    = 1,3,4,2,5,8,10,4,9,14,18
X[1][1] = 1,3,4,2,5,8,10,4,9,14,17,23,29
```

第二步展开最高返回叶18，其控制根为列7（值4），普通高度2。
新首列10（值17）具有普通父 `[9,7]`，没有高边：
它是颜色2尖端14的直接普通孩子，但普通高度为2，不是1；它本身不再是 R₂。

因此[旧递归端口预算](../y-recursive-port-upper-20260927/RECURSIVE-PORT-UPPER.zh-CN.md)的
“第二尖端的每个直接孩子高度恰为1”入口条件在这里已经失败。
不能凭最高返回都是叶，就宣布旧定理已经覆盖 X。

一般第 b>0块的末叶被正展开时，同样生成高度 b+1的非返回入口。
这个出口仍需要给出可持续的目标预算；叶性只排除了“再以最高返回本身作为控制根”的分支。
这是一条具体且更窄的下一义务，不排斥采用另一种整体嵌入路线。

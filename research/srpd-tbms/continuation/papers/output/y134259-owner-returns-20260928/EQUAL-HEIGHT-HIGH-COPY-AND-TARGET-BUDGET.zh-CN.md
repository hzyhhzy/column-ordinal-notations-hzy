## 1. 这轮实际检查了哪个目标侧方案

SRPD 原生插行能够增加可用行位置，但“当前一步装得下”不等于同一个初始目标能一直装下。
重读了两项实际接口：

- [raw K 的行1背景](../y-m13-owner-audit-20260922/GRADE-ROW1-AUDIT.zh-CN.md)：
  可以搬运旧等级，不必让每个等级都有两行支撑；但一致高步骤不负责产生可反复使用的新等级。
- [影子复制容量](../y-m13-owner-audit-20260922/SHADOW-CAPACITY-TRANSPORT-AUDIT.zh-CN.md)：
  在控制行 q、切点 c 的复制中，早份到晚份的容量受 q−1 限制。
  因而不能把新出现的物理地址直接视为具有旧调用能力的新库。

已有[付费自索引字典](PAID-SELF-INDEXED-DICTIONARY.zh-CN.md)能保存旧库、分配严格较低标签并恢复主接口。
尚缺的仍是：原 Y 的所有插层/改接操作为何总能给出这样的有限付费计划。

一个拟议的归纳是利用冻结定理：给未开启闭根按其固定高度分层；
如果高操作只能复制严格低于活动根的闭根，就有望按层安排递归归档。
本稿证明这个严格下降前提失败，甚至能在任意指定正高度 n≥2 发生**同层复制**。
用出生时高度取代当前高度也不能修复本族。

## 2. 约定和已经证明的源事实

所有列号、普通行号从0计。普通父表 P，高父 H，高度 h=|P|。
最高返回叶 e 与其普通根 c、两个高尖端 u、t 构成连续四列：

\[
u=c+1,\quad t=c+2,\quad e=c+3,
\]

\[
P_u=c^{h+1},\quad P_t=(u)\frown c^h,\quad
P_e=(t)\frown c^h,\qquad H_u=H_t=c,\ H_e=\varnothing.
\]

把这个根 c 称为闭根。固定 X[n] 后，仍闭合的根高度冻结且 owner 为空；
它们不能成为高控制根，也不在别的高步骤中上升。
“不升高”没有蕴含“比活动根严格矮”；这正是需要分开的两件事。

使用此前的原 Y 局部减一宏：非后继末列先取 [1]，再删回原宽，使末数减1、前缀不变。
故任何正整数末值的有限降低都可写成有限原展开路径。
下面记录每个降低的起点、终点和次数；没有使用无限固定指标迭代。

## 3. 先构造任意高度的真实高复制例 Q_n

令 n≥1，

\[
R=2^{n+1},\quad a=3+4n,\quad c=a-4,\quad t=a+2.
\]

已知

\[
X[n]=(1,3,4)\frown\mathop{\frown}_{b=0}^{n}
(2^{b+1},2^{b+2}+1,3\cdot2^{b+1}+2,2^{b+3}+2).
\]

最后闭根 a 高 n+1，其前一闭根 c 高 n。
执行以下有限路径：

1. 取 X[n][1] 并删尾至宽 a+4。末数为 4R+1，父表为 \((t)\frown a^n\)。
2. 将末数减1至 4R。父表变成 \((t)\frown a^{n-1}\frown(c)\)。
   这是控制行 n、切点 c 的普通末列。
3. 取 [1] 并删尾至宽 a+8。令 x=a+3、z=a+7。
   新 x 是高 n 的闭根，父为 \((t)\frown a^{n-1}\)；
   最后 z 普通，父为 \(x^{n+1}\)。
4. 将 z 的数值降至 3R+2。

第2步的普通父搜索可直接核对：第一差分为 R−2，
随后沿 a 的行值依次相减；到第 n 行时剩2，与 a 的第 n 行值相等，
而前根 c 的该行值为1，所以最高父恰为 c，最后差分为1。

第3步新出的最后五个数为

\[
\begin{aligned}
x &: 4R-1,\\
x+1 &: 6R-3-3n,\\
x+2 &: 8R-5-6n,\\
x+3 &: 10R-8-9n,\\
z &: 6R-4-3n.
\end{aligned}\tag{1}
\]

推导：x 的第 r 行值（1≤r≤n）为 \(2^{n+2-r}-3\)；
由完整父表逐行向下相加得到 (1)。这是行递推公式，不是数值拟合。
第4步需要 \(3R-6-3n>0\) 次局部减一。

因为 x 及其私有三列的值均严格大于 3R+2，
新的末列与之前 t 的普通父链和对角回溯一致，成为根 a 的颜色2尖端。
记所得项为 Q_n，则

\[
H_{\rm last}=a,\quad h_a=n+1,\quad
\text{高坏块中唯一闭根为 }x=a+3,\ h_x=n,\quad D=7.\tag{2}
\]

取 Q_n[1]，闭根 x 复制到 x+7，仍高 n、owner 为空。
这一步本身有严格高度差1；它提供后面同层反例的标准起点。

构造及核验（未随本次收录的来源：`output/y134259-owner-returns-20260928/tail5-high-copy-family.cjs`）检查 n=1,2,3,4,5,8,12。
n≤3 完整重放最后降低，较大参数用已证有限宏构造端点，再按原 Y 重建山脉和展开；
并未声称重放 n=12 的24534次减一。
结果（未随本次收录的来源：`output/y134259-owner-returns-20260928/TAIL5-HIGH-COPY-FAMILY-VERIFICATION.json`）共759个原步骤，约55MiB。

## 4. 任意 n≥2 的同高度复制反例

现在固定 n≥2，从 Q_n 继续，仍使用 R=2^(n+1)。

### 4.1 先把一批旧闭根带到工作区

把 Q_n 末数 \(3R+2\) 降到7。
其真实父表为 [7,7]：第7列的值是4、第1行值是2；
更靠右的旧根值至少8，不能遮住这条父链。
于是普通控制行1、切点7。

取 [2]。坏块跨度是

\[
D=(a+7)-7=4n+3.
\]

每份的正行数值不变，底数统一增加2b。
原因是旧切点第7列高2，其正行值仍为2；
首接缝的底父是前份切点，故首列值依次为4、6、8，
坏块其余列都在其底子树中，沿原差分一并平移2b。
不能把这个结论泛化成所有普通步骤都对数值作相同平移。

所得末列是第2份的闭叶。定义以下旧列位置：

\[
q=12n+5,\quad A=12n+9,\quad r=12n+12,\quad
u=r+1,\quad x=r+3=12n+15.
\]

q 是原第 n−1 个闭根的第2份副本，高 n；
A 是原根 a 的副本，高 n+1；
r 是 Q_n 中闭根 x（第3节记号）的副本，高 n。
u 为 r 的第一高尖端，当前物理末列 x 为 r 的闭叶。

其相关行数值为

\[
\begin{aligned}
\text{第1行值}(q)&=2^{n-1}=R/4,\\
\text{第1行值}(A)&=2^n=R/2,\\
\text{第1行值}(r)&=R-3,\\
U:=\text{底数}(u)&=6R+1-3n,\\
\text{底数}(x)&=10R-4-9n.
\end{aligned}\tag{3}
\]

### 4.2 一次普通接缝把同层闭根接到第一尖端下

将末数降低到

\[
Z=U+R/4+1=25R/4+2-3n.\tag{4}
\]

它位于 u 的值和第二尖端的值之间，所以底父为 u。
第一差分为 R/4+1；沿 u 的底父链，r、A 及中间高尖端的第1行值均不小于它，
第一个严格小于它的值是 q 的 R/4。
故末列父表准确为

\[
P_x=(u,q),\qquad H_x=\varnothing.\tag{5}
\]

式 (4) 小于原闭叶数值，需 \(15R/4-6-6n>0\) 次有限降低。
旧根 r 因末闭叶被改造而不再闭合；其两个高尖端仍保留。

对 (5) 取 [1]：控制行1，切点 q，高度 n，跨度 x−q=10。
在原末槽 x 产生新根 c=x，其父表为

\[
P_c=(u)\frown P_q[1:n],\qquad h_c=n.\tag{6}
\]

q 的私有三列随模板搬来，所以 c 是一个**仍闭合**的新根。
它在普通底树中位于高尖端 u 之下，而 \(H_u=r\)、\(h_r=n\)：

\[
\boxed{h_c=h_r=n.}\tag{7}
\]

两者的出生标签也都为 n：r、q 最初都来自 X[n] 的高度 n 闭根，
普通复制只搬运标签；r 开启后标签作为高根来源记录保留。
因此改用“出生高度严格下降”同样失败。

此时整词宽为12n+25，c的底数是 \(Z-1=U+R/4\)。
其后新列都在 c 的底子树中，故值均大于 U。

### 4.3 暴露一枚真正会复制这个同层闭根的高末列

将物理末数再降低到 U。
旧根 r 后的旧第一尖端数值恰为 U、旧第二尖端数值更大；
第4.2节新产生的全部列也都大于 U。
所以最近较小底父仍为 r，沿 r 的父链重建各行，与旧第一尖端完全相同；
原对角回溯同样给高父 r。

记终点为 H_n，物理末列 z=12n+24：

\[
P_z=r^{n+1},\quad H_z=r,\quad
h_r=n,\quad z-r=12,\quad c=r+3,\ h_c=n.\tag{8}
\]

这是颜色1的真正高控制，不是只画出一个高根祖先关系。
此次高坏块中唯一闭根是 c。
它没有第 n 行，因此不在高步骤的上升域；这与已证冻结定理完全一致。

对任何 b≥1 取 H_n[b]，则每份都生成一个新的闭根

\[
\boxed{c_i=c+12i,\quad h_{c_i}=n,\quad O(c_i)=\varnothing
\quad(1\le i\le b).}\tag{9}
\]

新活动首根则高 n+i。所有旧闭枝均保留，闭枝总数恰增加 b。
这既否定严格高度分层，也说明在某个固定高度层内单数剩余闭枝，仍不是下降量。
没有从 (9) 推出无限原展开链；后续控制状态已经改变，不能免费恢复到旧 H_n。

最后一次降低的起点可直接计算为 \(55R/4-4-9n\)，
终点 U，所以次数为 \(31R/4-5-6n>0\)。
这也保证构造对所有 n≥2 都是有限原下降，而非只有测试过的几例。

## 7. 对下一步的具体影响

现在不能再把“闭根冻结”当成“递归调用严格降高度”，也不能给同层闭根一个固定剩余次数。
本族展示需要保存的接口：新闭根的底父换到当前高星的第一尖端，
**正行父却继承更早的同层模板 q**。活动星和旧模板不能合并成一个无上下文的层号。

这与已存在的多端口字典思路相容，但尚未给出所需的严格细化计划。
下一预算若沿这条路线，至少要追踪同层模板 q 的剩余普通父表/来源，而不只记录其高度。
也可换另一种整体比较路线；本稿不规定后续必须采用该候选。

本轮改变了下一行动的依据，但**没有增加完整 Y 节点的上界**。
无公共 NER、Lean、commit/push 修改，所有探针和证书进程已退出，目标保持 active。

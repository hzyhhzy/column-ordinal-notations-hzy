## 2. 源类：限制闭根深度，不限制整个核心深度

列和普通行从0编号。\(P_j\) 为普通父列表，\(H_j\) 为可空高父，\(h_j=|P_j|\)。
所有输入均是按原 Y 规则重建的有限规范数值词；不是任意有向无环图。
标记 \(\mu\) 是覆盖全部真正根、排除高尖端的合法永久标记，复制继承，不在下降途中重置。

先取已有两色窄类：对齐平高星、星带、正普通行不以高尖端为父、
高尖端的正行父均为本星根、尖端颜色只有1和2、严格零高度星接口。

允许旧 C 条件唯一的一种例外：某普通根 c 后有连续私有块

\[
\begin{array}{c|c|c}
\text{列}&P&H\\\hline
c&\text{普通高1}&\varnothing\\
u=c+1&(c,c)&c\\
t=c+2&(u,c)&c\\
e=c+3&(t,c)&\varnothing .
\end{array}\tag{2.1}
\]

进一步要求：

- \(O(c)=()\)、\(\mu(c)=1\)；高根 c 的全部高尖端恰为 u,t。
- u 的唯一入引用是 t 的底父；t 的唯一入引用是 e 的底父；e 无任何入引用。
  这里同时检查普通父和高父，不只检查第0行。
- 除这些 e 外，所有以第二尖端为直接底父的普通列均恰高1。
- 删去每块的 u,t,e 得到规范核心 \(E_3(s)\)，属于旧 C 类。

将上述块称为闭枝，c 称闭根。闭根上的布尔位 \(\sigma\) 和永久标记 \(\mu\) 不是一回事：
开启只消耗 \(\sigma\)，不抹掉继承的 \(\mu(c)\)。
特别地，\(\mu(e)\) 可以是0，也可以是1；实际标准路径的 T 中它是1。

不在闭枝内的第二尖端称开放第二尖端。
在 \(E_3(s)\) 中，记 \(D(j)\) 为 j 的真底行祖先中全部第二尖端的有序栈。
定义

\[
b(s)=\max_{\sigma_c=1}|D(c)|,\qquad\max\varnothing=-1.
\]

令 \(\mathcal K_d\) 为满足以上条件且 \(b(s)\le d\) 的源状态；\(\mathcal K_{-1}=\mathcal C\)。
不要求输入是某一指定标准起点的后代。这样端口归一化得到非标准但规范的词时，
归纳假设仍有明确适用域。

**关键区分：** \(|D(c)|\) 只在仍闭根上取最大值；
核心所有列的最大第二尖端深度可以在一次开启后增加任意有限值。
不使用先前已被反例推翻的“闭根高度随递归调用严格降低”。

## 3. 全类闭包，而非仅检查 W 的几条轨迹

### 3.1 存活私有块不能被切开，也不会上升

控制不可能切在存活闭枝的 u,t,e 中间：
正普通父不能为高尖端；零行切 u 所需的普通孩子不存在；
切 t 只能由末 e 控制，而那是消耗本枝的开启；e 没有孩子。
高控制根是普通列，且存活闭根 c 仅有 u,t 两个高尖端，
它们右侧有 e，故不能以 c 作高控制。

考虑其他高控制根 a 的高度 h。若 h≥1，闭根高1而没有第 h 行父，不能上升；
私有 u,t,e 只有两行。h=1 时它们的行1先到 c 并在那里停止，
不会到不同的活动根 a；h≥2 时根本没有检测行。
h=0 时，活动星的严格零接口排除把这个含标记普通根的闭块放进控制带。
所以每个存活闭块只作整段保留或整段搬运。

新跨份接缝不能额外引用私有 u,t,e：
其低父来自旧末列；要引用 u/t 就要求旧末列分别为 t/e，
而仍保留 e 时 t 不可能是末列，e 情形则开启此枝。
其他边只搬旧引用，插入行只引用普通控制根。
闭根的额外高尖端也不会新生：所有高边来自旧高边，且不能在 c 与私有 u 之间切开。

普通步不插行，owner 公式只搬运普通切点的旧 owner；
高步中闭根不上升，所以 owner 也只搬运。故存活闭根仍高1、owner 空、标记为1。

### 3.2 不开启时，核心恰作原 C 步

原末列不是 e 时，它和控制父都在保留核心。
删枝保留完整父祖先链；原山脉及对角回溯的规范性按第1节第2项的原生剪枝证明保持。
坏块的保留列恰为核心坏块，控制行和上升判断相同，因此

\[
E_3(s[n])=E_3(s)[n].\tag{3.1}
\]

不会凭空新生高于1的第二尖端普通入口：
非首列只搬运，原高1入口不在外部高控制的上升域；
普通正行首列的底父若为第二尖端，旧末列已经是这种入口。
它若高1，控制行只能为0，矛盾；它若为私有 e，则属于下一节的开启。
高首根的底父只能是根或第一尖端，也不会制造该例外。
已有例外因3.1的私有性整段保持。这同时说明 E₃ 删的确实是原来的存活闭块及其副本。

C 对原展开闭合，故新核心仍在 C。旧 C 栈运输给每个存活闭根副本

\[
D'(c_b)=\phi_b(D(c)),\qquad |D'(c_b)|=|D(c)|.\tag{3.2}
\]

### 3.3 开启仅消耗末枝，新增部分纯 C

末列为 e 时，切点 c、行1、跨度3。核心保留至 c，显露 u,t；
再对 \(b=1,\ldots,n\)，在 \(d_b=c+3b\) 追加

\[
\begin{array}{c|c|c}
d_b&(d_b-1)&\varnothing\\
d_b+1&(d_b,d_b)&d_b\\
d_b+2&(d_b+1,d_b)&d_b .
\end{array}\tag{3.3}
\]

所有新普通入口都高1，满足 C 屏障；新增各块不带闭标记。
其他闭根全部在 c 左边，它们的父链、深度和标记不变。
因此核心仍是 C，闭枝恰少一个。n=0 也包括在内。

由3.1—3.3，

\[
s\in\mathcal K_d\Longrightarrow s[n]\in\mathcal K_d
\quad\text{且}\quad b(s[n])\le b(s).\tag{3.4}
\]

前缀也在同类：完整闭块保留；若恰截在 u 或 t，丢失 e 的该块改为没有普通支体的开放尖端，
不会产生坏入口，也不增加此前闭根的栈。
上述证明只用定义中列明的规范性和局部条件，没有偷加“来自 X”的假设。

## 4. 含闭枝的开放端口可归一化到严格低一层

对开放第二尖端 t，取其全部严格底行后代，形成端口森林 F。
每个直接入口高1，故入口屏障仍成立。
闭枝全部保留在森林内，**不能为套用纯 C 定理而把它们删掉**。

若 t 的原值为 a，将 t 替换成普通端口1，森林各值作 \(v\mapsto v-a+1\)。
第0行入口仍是2；内部差分不变。正行父不能越过高1入口，高父也不能从外星跨入口。
所以按原山脉算法得到的全部内部普通父、高父恰为原图重编号；
原允许的内部展开逐项交换。端口标记设为1，其余标记继承。

所得规范词记 \(\widehat F\)：
私有块原样保留，闭根仍高1、owner 空，无额外高尖端；
E₃ 与此归一化交换，其核心是原 C 端口的归一化，仍在 C。
若某闭根 c 位于 F，则

\[
|D_{\widehat F}(c)|=|D_s(c)|-|D_s(t)|-1.\tag{4.1}
\]

因此

\[
s\in\mathcal K_d,\ d\ge0
\quad\Longrightarrow\quad
\widehat F\in\mathcal K_{d-1}.\tag{4.2}
\]

无闭根的空／非空端口自然落在 \(\mathcal K_{-1}=\mathcal C\)。
这里不需要整个核心有固定深度界；每次只对一个有限规范森林用归纳假设。

定义门控秩 \(\kappa(F)\)：保留端口，不许正指标切端口本身，只允许内部原展开和删尾。
端口列不计入秩。较低层的完整上界给它良基性，且

\[
\kappa(F)\le\rho_Y(\widehat F).\tag{4.3}
\]

因组件相互之间没有父引用且只动最后组件，仍有
\(\kappa(F_1\cdots F_m)=\sum_i\kappa(F_i)\)、
\(\kappa(\text{裸入口})=1\)。此加法用限制秩归纳，不需预先假设当前 \(\mathcal K_d\) 良基。

## 5. 全前缀预算：为何嵌套开启不要求免费重置

固定 d。假设较低层所有源的秩均小于 \(\alpha_{d-1}\)，其中

\[
\alpha_{-1}=\Lambda,\qquad
D_0=\Lambda,\qquad D_d=\omega^{\alpha_{d-1}}\ (d\ge1).
\]

对完整状态 s 的每个前缀 \(\ell\) 和其中第一尖端 u，定义

\[
R^*_\ell(u)=
\begin{cases}
\Lambda,&u\text{ 属于 s 中仍闭枝};\\
\displaystyle\sum_t\omega^{\kappa(F_{t,\ell})},&u\text{ 为开放第一尖端}.
\end{cases}\tag{5.1}
\]

t 按列次序枚举 u 的第二尖端孩子。
第一行是完整状态提供的预留见证；前缀尚未包含 e 时也保存它。
删除闭叶后只能撤下这个预留，不能在没有原步骤时免费补回闭枝。

由 §4 和较低层归纳，所有开放端口 \(\kappa<\alpha_{d-1}\)。
有限项和严格小于 \(\omega^{\alpha_{d-1}}\)；
此不等式对后继或极限的正 \(\alpha_{d-1}\) 都成立，不假设 \(\lambda_N\) 是 ε 数。
d=0 时纯端口以 Λ 为界，\(\omega^\Lambda=\Lambda\) 给开放预算严格小于 Λ。
私有预留也是 Λ，故

\[
R^*_\ell(u)\le D_d.\tag{5.2}
\]

但只证 (5.2) 不够。必须检查下列实际运输：

1. **开放端口内部。** 整个 F 包括它的闭枝；控制切点在端口右侧时，
   这是低一层门控系统的真实一步，故 κ 严格下降。
   嵌套开启也在此列：不能用开启后 E₃ 核心增长来替代整个 F 的下降。
2. **切在开放第二尖端。** 只可能是删除末裸入口的零行控制。
   若此前森林秩为 \(\tau+1\)，末项
   \(\omega^{\tau+1}\) 变为 \(\omega^\tau(n+1)\)，严格下降。
3. **切在第一尖端或其他外部复制。** 各份得到各自第一尖端及原森林副本；
   不把所有份的预算累加给一个旧尖端。
   外部高步不能越过高1入口插行，整个带闭枝端口真正同构，而非只核心同构。
   完整份用旧全词见证，部分份用相应旧前缀见证，外部根用旧全词表。
4. **非一致高控制。** 控制末列是开放第二尖端，不可能是仍闭枝的私有 t。
   其森林为空，所以活动预算恰为 \(\delta+1\)；
   早份对应尖端预算为 δ，当前部分份仍用原局部见证。
   新首根挂在第一尖端而非第二尖端，不额外增加被计的森林。
5. **开启私有枝。** 包含它的所有旧开放端口按第1条实际下降。
   新显露的 u 及其副本只拥有式 (3.3) 的纯 C 端口，预算严格小于 Λ；
   故低于旧预留 Λ。其他旧端口不变。
   不要求新纯端口深度小于 d，它可以很深，但纯 C 的统一 Λ 界已经完成。
6. **仍闭的私有 u。** 整段保留或复制，预算一直为 Λ。
   它不会成为非一致高末控制，因此无需虚构“Λ=δ+1”。

全前缀组织与旧端口证明相同：保留段保留自己的表；
新完整份、部分份、外部根分别使用上面指定的旧表。
输出截到较短前缀时，开放森林 κ 只下降；若截掉 e 则私有预留转成小于 Λ 的自然预算。
因此没有把某个短前缀的大储备错误地借给不相关的跨份请求。

## 6. 固定 Q 的容量合同，包括历史已标记闭叶

按初态标记根的列序 \(i=1,\ldots,k\)，初始化正极限等级

\(v(\gamma_w(c))\ge\delta+2\)，在旧全词外层等级之上、旧活动等级以下选择有限个

其他高／普通父需求按旧 min 容量证明保持。

## 7. 有限 SRPD 行库给出每个 K_d 的统一界

首先列出两条目标事实，它们的量词都是“任意有限源宽度”。

## 1. 旧局部条件确有反例

旧候选（未随本次收录的来源：`output/tbms-srpd-equalities-20260929/D44-UPPER-FRONTIER.zh-CN.md`）只约束高三元组两端，宽六检查没有暴露下面的七列反例：

```text
G = [][][2][3,3,3][4,3][5,5,5,5][4]
G[1] = [][][2][3,3,3][4,3][5,5,5,5][3,3,3][7,3][8,8,8,8]。
```

旧图满足原候选；新图对 r=3,u=5,v=6,z=7 有高容量4、根返回容量3，违反根返回至多2。
即使额外禁止高对的所有强祖先被后来底行访问，仍有

```text
H = [][][][3,3][4,3,3][4,4,4,4][4]。
```

它的一次完整反射为

```text
[][][][3,3][4,3,3][4,4,4,4][3,3][7,3,3][7,7,7,7][7]。
```

删去末临时列后，r=3,u=4,v=6,z=8 仍给根返回3。
两图都与原有限行 TBMS 父查找相容；**没有声称它们是 D44 的标准后代**。
失败的是通用局部闭合引理，不是 D44 的等号猜想。

## 2. 新类：记录分量的完整前导头部

列、行均一基。只用原生相容的严格父图：每个父 p 满足列高 h≤p<子列。
记 C(a,j) 为逐行祖先容量，h(j) 为列高。第二行森林的分量根定义为

\[
 o(j)=\begin{cases}j,&h(j)<2,\\o(p_2(j)),&h(j)\ge2.\end{cases}
\]

根 R 的分量由 o(j)=R 的列组成；它不必是一个连续区间。
称高度 R+1 的分量内列为峰。新类 \(\mathcal H\) 满足：

1. 每列 j 的高度≤o(j)+1。
2. 每个峰 V 都纯，即 `[U]^(R+1)`，且数据列 U 的高度≤R。
3. 若分量有峰，它的前导头部必须原样存在：列 R+1 是 `[R]^m`，2≤m≤R；列 R+2 是 `[R+1]^(R+1)`。
4. 对 z>R+2，C(R+1,z)=0：前导数据列没有后来的底行后代。
5. 对 z>R+2，C(R,z)≤2。
6. 每个峰 V 之后，不允许同时 C(V,z)>0、C(R,z)≥2。

有峰的分量称为 armed；无峰时所有列高≤R，称为 unarmed。
后来的弱峰可共享数据列，数据列也不必邻接弱峰；不作这些额外限制。

### 二行根引理

o(j) 等于 j 的底行祖先链上最近的高<2节点，包含 j 自身。
因为第二行查父沿底行祖先链向左寻找，遇到的第一个缺第二行节点的值为0，不能越过它；
继续沿第二行父链最终恰停在那里。
**这个说法只用于第二行，不能逐字推广到第三行或更高行。**

于是对 R<j，o(j)=R 当且仅当 C(R,j)≥2，前提是 h(R)<2。
若末列 N 的高度≥2，末父 d 处于同一第二行分量；d 后、N 前的其他分量，其低根 S>d，且 C(S,N)=0。
若末列是 `[d]`，它直接以 d 为底父，同样没有 d<S<N 的分量根能成为 N 的底祖先。

### 与旧“高三元组”的关系

在 \(\mathcal H\) 中，C(r,u)≥2、C(u,v)>r 的三元组恰为峰及其根、数据列。
证明：三点在同一第二行分量 R，故 C(u,v)≤R+1；又 R≤r<C(u,v)，所以 r=R、C(u,v)=R+1。
峰纯且其数据列高≤R，因此这个高度的祖先 u 只能是其直接数据列。
反向显然。每个峰只计一次。

## 3. 全参数闭合定理

**定理。** G∈\(\mathcal H\)，末列非空且末父 d≥2，则每个原基本列 G[n] 仍在 \(\mathcal H\)。
删除末列显然保持该类。证明其余情形时令 N 为原宽、h 为末列高、L=N−d。
以下“完整反射”保留末临时列；最后才将它删除。

使用[七类精确容量公式](../../../../archive/output/tbms-e0mn-bridge-20260925/FULL-REFLECTION-CAPACITY-INTERFACE.zh-CN.md)：
严格外部祖先 a<d 的容量保留；旧坏块 a≥d 到新副本的容量为

\[
 \min(C(a,N),h-1,C(d,t));
\]

新接缝 N 到副本 t+L 的容量为 C(d,t)；副本内部容量按
f(x)=x（x≤d）、f(x)=x+L（x>d）搬运。因为 d≥2，f 不改变容量1、2。

### 3.1 唯一不能单独保持的完整反射：打开前导峰

若 N=R+2 是前导峰，则 d=R+1、L=1。单次完整反射会留下失去头部的临时峰，
所以不能拿“每次完整反射都闭合”草率证明整个规则。
但整个基本列有直接公式：

\[
 G[n]=G\upharpoonright(N-1)\frown
 ([R+1]^R,[R+2]^R,\ldots,[R+n]^R).
\]

n=0 时后串为空。它消费了这个分量唯一的峰，并只添加高R的列，分量变成 unarmed。
没有复制其他分量，其他根的限制不变。这证明所有 n 的特殊分支。

以下证明**除这一分支外的一次完整反射**闭合。

### 3.2 h≥2：分量内部切点

令 R=o(N)=o(d)。先考虑 d>R。
如果分量 armed，则除上一分支外，d 不能是前导数据列或前导峰（否则 N 是前导数据列的后来底后代）。
也不能是任何弱峰（N 与它同第二行分量，违反条件6）。故 d≥R+3 且 h(d)≤R。
接缝的高度 max(h−1,h(d))≤R，是非峰。

原分量的高度≤R+1<d，故其副本不插行；纯峰仍纯，数据列仍高≤R。
前导头部在切点以前，不动。根及前导数据均严格外部，容量公式保留条件4、5。
旧分量的每个早于 N 的峰 V 都有 C(V,N)=0，所以它也没有新副本中的同分量底后代。
副本内部条件6由容量搬运保持。若分量 unarmed，同理所有自身列高≤R<d，无新峰。

对任何低根 S>d 的其他分量：它的已出现部分完整处于复制区，C(S,N)=0。
它的头部、数据、峰都整体搬运；新根 S+L，峰高 S+L+1，非峰高度≤S+L。
旧头部及旧峰到接缝、新副本的容量为0，因此不会得到新的禁止返回。
不同分量可交错，但上述完整性只要求其根之前没有该分量列，并不要求连续。

### 3.3 h≥2：切在低根 d=R

若 h=2，接缝变成一行，产生新低根 N。
原 R 分量的副本以 N 为根：原非峰高≤R不变，原峰高 R+1 变为 N+1。
前导数据搬到 N+1，前导峰搬到 N+2，形状正合要求。
接缝到副本容量 C(R,t) 保留；旧 R 到副本容量至多1，故旧分量不产生同分量峰返回。
原 R 分量的峰不能是旧 N 的底祖先，亦不会因接缝产生新的祖先叠加。
其他 S>R 分量整体搬运，理由同3.2。

若 h≥3，armed 分量不可能出现这一情况：前导峰本身已单列处理，后来列 C(R,N)≤2。
所以分量 unarmed，h≤R。接缝保留第二行，仍属于旧 R 分量，所有自身列高≤R，
不插行、不产生峰。**此时不能错误地把接缝当成新低根。**其他分量仍整体搬运。

### 3.4 h=1：整列继承

接缝 N 完整继承列 d，而不是保持 d 作为自己的父。

若 d 是低根，接缝 N 成为新低根；整个原 d 分量按3.3的地址变换搬到以 N 为根的副本。
旧坏块到副本的容量全为0，故没有旧峰返回或旧数据别名。

若 h(d)≥2，令 R=o(d)。若 armed，前导数据隔离强迫 d>R+2，前导头部冻结；
若 d 非峰，接缝高≤R，自身分量不插行，仍由严格外部容量公式保持条件。
若 d 是弱峰，接缝成为它的纯峰别名。但它**绕过旧 d**，不成为旧 d 的底后代。
而 d 之后的整个坏块中不可能再有 R 分量的列，否则原条件6已被违反。
因此新别名峰也没有同分量的后来底后代。坏块内其他低根分量整体搬运。
若 R unarmed，没有新峰，论证更直接。

### 3.5 其余旧分量、重复反射及删除

根和头部在 d 以前的非当前分量，对副本的严格外部容量不变；接缝只继承它们对 d 的容量。
若它们不是 d 的第二行分量，这个根容量至多1，不能制造条件6禁止的返回。
根在 d 之后的旧分量已有 C(S,N)=0，所以由跨接缝公式没有新返回。
这覆盖了3.2—3.4未逐项重述的旧分量限制。

非特殊反射之后，新的末临时列不会变成前导峰：
内部切点时仍在原头部之后；根上二行切点时新末列只有二行，不可能高于新根一行；
根上更高切点始终 unarmed；一行切点的新末列仍是一行。
故可反复应用以上非特殊闭合，任意 n 次后删除末临时列。
定理得证。切点1未包含在本定理里。

## 4. 更强的结论：逐列峰深度运输，而非仅有限样例最大值

定义 d_G(j) 为 j 的底行祖先链中峰的个数，包含 j 自身；空链深度0。
在3.2—3.4的非特殊完整反射中，有精确等式

\[
 d_{G^+}(j)=d_G(j)\quad(j<N),\qquad
 d_{G^+}(N)=d_G(d),\qquad
 d_{G^+}(t+L)=d_G(t)\quad(d<t\le N).
\]

理由如下。h≥2 时，d 不是峰；坏块中每个早于末列的峰 V 都不在旧 N 的底祖先链上：
当前分量用条件6，其他分量用低根屏障。因此接缝保留的旧底链在 d 之后没有额外峰，
接缝本身又是非峰，其深度恰等于旧 d。每个新峰对应一个原峰；副本接在该接缝上，
不会额外叠上旧坏块峰。h=1 时，接缝完整继承 d；如果 d 是峰，峰标记改落在接缝，
其严格祖先链没有 d。因此仍是相同深度。副本内部一一搬运峰，得到最后一式。

打开前导峰的特殊基本列只删除该峰，添加的全是非峰；新列深度等于原数据列深度。
所以任意原基本列满足

\[
 \boxed{\max_j d_{G[n]}(j)\le\max_j d_G(j).}
\]

这个量可以停顿，**不是严格下降势**。

## 5. 应用到 D44：有限分支的统一结构界

使用[已证块公式](FINITE-ROOF-WHOLE-TBMS-LOWER.zh-CN.md)，D44[n] 是冻结的六列 P6 后接 n+1 个块：

```text
R=7+6b： [R-1], [R]^7, [R+1]^(R+1), [R,R], [R+3]^7, [R+4]^(R+1)。
```

每块有一个完整前导峰和一个弱峰；前导数据没有后来底后代，回根容量为2，两个峰之间不成底祖先。
下一块低根接在上一块的弱峰上。故初态属于 \(\mathcal H\)，且最大峰深度**恰为 n+1**
（冻结前缀自身的最大深度为1）。

P6 之后的父号始终≥6：复制和接缝均保持这一屏障。因此在退入 P6 以前，所有实际正切点≥6，
上面的切点≥2定理始终适用。得到 D44[n] 的任意这类后代都在 \(\mathcal H\)，峰深度≤n+1。
退入 P6 后是固定前缀的后代；最终序数上界仍须显式纳入它，不能免费忽略。

## 6. 尚缺的真正反向上界

即使以上结构引理成立，也还没有 D44≤TBMS Limit。
所缺是：为这些有限初态构造一个**预先固定的实际递归 TBMS 项**，支付每个原 SRPD 步，
包括原图删改、头部打开、私有块内步、返回后再复制，以及冻结前缀。
有界峰深度只限制跨层嵌套；同层的复制与返回仍可无限多次发生，不能忽略其下降秩。
也不能每到一个状态就重选更大的 TBMS 上界。

可尝试按峰深度递归的带返回参数解释；必须先证明解释在返回口上如何组合，才有序数不等式。
完整 TBMS 极限等号目标仍未完成。

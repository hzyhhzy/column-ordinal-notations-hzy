## 1. 每个打开块的一张真实普通 TBMS 表

设打开块 A 的物理首地址为 a，唯一的外底父为 p。
删去通往 p 的外边，仅保留块内父关系，并按块内父链深度写数值。
块中底父在外部的列必恰好是一行 `[p]`，去外边后成为空列；
其余列的全部父都在块内。

记 E(A) 为整个块共有的背景祖先链。给原第 r 行（从0计）标上

\[
w_r=\begin{cases}\omega&r\in E(A),\\1&r\notin E(A).\end{cases}
\]

每一原行变成一个同数值、长度 w_r 的区间，得到普通 TBMS 表 L(A)。
所有列使用同一组标记，原父链沿整个行区间保持，故原 TBMS 确实恢复同一个块内父表。
每张表只有有限个 ω 区间及有限间隙，所以真实行高严格小于 ω²。

结合既有完整祖先覆盖引理，每个固定 L(A) 的秩严格小于
Γ=ρ(TBMS ()(1^(ω²)))。这是局部表的统一界，**不是整个 SRPD 状态的界**。

## 2. 冻结背景时，每个私有原步都有真实 TBMS 下降

私有正控制的父 c≥a，原块高度≤a，因此原动作没有插行。
若原末行不是标记行，直接进行对应 TBMS 单位步。
若它是标记行，先把末列当前 ω 区间真正截到长度1，再作同指标单位步。
接缝从父列回填的区间保持原标签，所以输出常值轮廓恰等于新的 L(A)。
原删除对应真正删除 TBMS 末列，必要时先有限细化末行标签。

这覆盖背景冻结时的所有内部正步与删除；真实截行使用旧普通 TBMS 截行引理。
它不把标记 ω 改写成1，而是作实际下降。

若原块末列为外返回 `[p]`，L(A) 的末列就是空列。
写 A⁻ 为非空余前缀，则

\[
\rho(L(A))=\rho(L(A^-))+1.
\]

这个后继差正是控制图需要额外末返回列时，私有部分真正消耗的量；
不能因为它只是加1，就不计私有前缀在返回后的复制。

## 3. 底行返回复制保持全部私有轮廓

原末列以背景父 c 做第0行返回，物理复制跨度为 Δ。
对任意被复制的完整私有块，或末私有块保留下来的非空前缀，记第 b 份为 A_b。
那么

\[
\boxed{\operatorname{profile}L(A_b)=\operatorname{profile}L(A).}
\]

这里末私有块右侧使用的是 A⁻，不是包括已删除返回列的旧 A。

证明：前序性保证 c 是坏块内所有私有列的背景祖先。
复制后，c 以前的背景祖先不变，c 及其后祖先一起搬运；旧 c 不再是新块的祖先。
若原列高≤c，没有插行也没有涉及这个标记。
否则原第 c 行所承载的数值被重复 bΔ 次，复制标记 c+bΔ 的 ω 区间仍在最后。
新增有限行全部位于该 ω 区间之前，因有限数+ω=ω，轮廓不变。
内部父号只整体重编号，逐区间数值也不变。这同时证明完整父区间保持，不只总高度相等。

## 4. 正返回口复制的膨胀公式

现在末列是两行口 `[p,R]`，深度 d 是它在所属 R 口森林中的深度：
R 深度0，`[R,R]` 深度1，之后沿低父每经过一个同属 R 的口加1。
故 p 到 R 之间有 d−1 个口。

对坏块内任一旧私有块 A，第 b 份副本 A_b 满足：

\[
\boxed{L(A_b)=L(A)\text{ 的同轮廓变体，只把原第 R 行的 }
\omega\text{ 换成 }\omega\cdot(1+bd).}
\]

若 A 的某一列还没到第 R 行，那一列没有这项变化。
其他原行段、每个数值和全部私有父号都保持；可出现新的冗余常值断点，但轮廓相同。

证明：复制根 R_b 的底父是前一份的 p。
对第一份，新背景祖先在旧 R 的位置贡献：旧 R、其后 d−1 个口、新 R₁，共 d+1 个标记。
每多一份，再增加 d 个标记，所以共有1+bd个 ω 区间。
这些标记都位于原第 R 行的反射插入段内，数值和私有父相同。
标记间有限空隙由随后 ω 吸收，故得到上述同父、同值区间膨胀。
R 后面的旧背景祖先及所有原有私有行，按同一偏移搬运。

这说明正口运输并非任意改造私有表：它是一项明确的单区间线性膨胀。
但膨胀后私有表的秩可能增大；Γ 只是两边共同的严格上界。
不能把 Γ 当成每次都可免费重新领用的原生 TBMS 资源。

## 5. 联合上界的缺口现在在哪里

两行控制图加上本篇，给出了完整的局部接口：

| 原动作 | 控制部分 | 私有部分 |
|---|---|---|
| 打开末包 | 父图不动、fresh转open | 产生行高<ω²的有限表 |
| 私有内部 | 父图不动 | 真实原生 TBMS 下降 |
| 底行返回 | 带必要的额外末控制列作原 TBMS 步 | 丢掉末空列，余表在所有复制中轮廓不变 |
| 正返回口 | 一步原两行 TBMS | 某个 ω 区间变为 ω·(1+bd) |

因此可将下一步集中到“带有上述精确膨胀操作的两行控制图上下文”，
无需继续把每个物理地址都当独立的未知序数。
尚须给这个联合系统构造一个真正下降、落在某个明确 TBMS 项以下的量。
特别需要同时支付保留的私有前缀与正口复制后的膨胀；本篇没有完成该步。

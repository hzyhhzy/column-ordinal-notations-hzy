## 1. 任意有限嵌套父图的无插行游戏

父表 G 有 N 列，行、列地址均从1开始。第 j 列的每个父 p 都满足1≤p<j。
每个较高行的直接父，必须是该列在前一行的祖先。因此全部逐行祖先森林嵌套。

这里**不要求**：

- 第1行是按前序排列的森林；
- 用父链深度写成整数，再交给原生 TBMS 父查找能恢复原表；
- 行高不超过父地址，或者祖先容量不超过左端地址。

例如 `[][1][1][2]` 的末列真实父是2，但按数值恢复原生父会得到3。
不能把它重新解释为另一个父图，然后声称模拟了原图。

定义无插行的完整反射：末列高 h>0、末父 c、跨度 L=N−c。
旧末位置 N 改为

\[
G_N\upharpoonright(h-1)\frown G_c[h,\ldots]。
\]

复制原 c+1,…,N 列，其中父号≥c的加 L；**不插入物理行**。
重复 n 次完整反射，最后删临时末列。空末列或 n=0 时直接删末列。
记这个辅助游戏为 \(\mathcal O\)，不是原 SRPD 的 \([n]\)。

### 定理1：固定原生初值的持续覆盖

设 H 为初始 G 的最大行高。若 N>0，则有同一个原生标准目标

\[
 V_0=B_{H+1}[N-1],\qquad B_\alpha=\operatorname{TBMS}()(1^{[\alpha]}),
\]

持续模拟 G 的每一种后续 \(\mathcal O\) 步骤；每个源步骤花费非空有限目标下降。
于是，在所用 TBMS 良基性背景下，

\[
 \rho_{\mathcal O}(G)\le\rho(V_0)<\rho(B_{H+1})<\rho(B_\omega)。\tag{1}
\]

H、N 均在初态固定。这里的 \(\omega\) 是 TBMS 的总行高，
不是说原始高图或 SRPD 的整个序数小于普通的 \(\omega\)。

### 1.1 嵌套性、行高和容量公式

接缝在 h 行以下保留原末列，h 行及以上继承 c。
c 在末列每个低于 h 的行上都是祖先，所以接缝边界仍嵌套。
副本内的链只搬地址；经过 c 的链改为经过接缝 N。故反射保持嵌套性。
所有列的高度仍≤H。

令 q(a,z) 为 a 成为 z 祖先的初始行区间长度。完整反射后的容量恰为：

| 位置 | 新容量 |
|---|---|
| a<z<N | q(a,z) |
| a<c，z=N | q(a,c) |
| c≤a<N，z=N | min(q(a,N),h−1) |
| a<c，z=t+L | q(a,t) |
| c≤a<N，z=t+L | min(q(a,N),h−1,q(c,t)) |
| a=N，z=t+L | q(c,t) |
| a=s+L，z=t+L，c<s<t≤N | q(s,t) |

这与[旧七类公式](../../../../archive/output/tbms-e0mn-bridge-20260925/FULL-REFLECTION-CAPACITY-INTERFACE.zh-CN.md)
的区别是最后一行没有对角插行函数 f。

证明逐行分解路径即可：接缝以下的严格外祖先正是 c 的外祖先；
复制块回到旧坏块只能经过 N；同份内部链完全搬运。
因为现在没有插行，不需旧稿为处理插行而使用的 q(a,z)≤a、h≤c。
也没有哪一步要求源由原生父查找生成。

### 1.2 从真实目标暴露源的控制父

覆盖关系取：源每条第 r 行父边，在目标同一行上成为祖先链。
等价地，目标完整祖先容量逐项支配源容量。

源正步骤末高 h、末父 c。把目标末列真实截到 h；若它在第 h 行的直接父还在 c 右侧，
就用一次真实同宽降低，再截回 h，直至直接父成为 c。
c 原来就在该祖先链上，因此不会被越过；父地址严格左移，所以准备有限。
这里使用[已证原生截行宏](../tbms-e0mn-bridge-20260925/TRANSFINITE-ANCESTOR-UPPER.zh-CN.md)。

准备后目标末列容量为

\[
 \widehat v(a,N)=
 \begin{cases}
 \min(v(a,N),h),&a\le c,\\
 \min(v(a,N),h-1),&a>c。
 \end{cases}
\]

源在第 h 行的直接父是 c，故 a>c 时 q(a,N)≤h−1；其他 a 的容量≤h。
因此准备没有丢掉所需覆盖。随后目标执行原生 `[n]`。
上表全部是单调的 `min` 公式，同一切点、同一跨度的反射继续保持覆盖。
每份临时列参与归纳，最后两边同时删去它。n 任意。

源删列时，目标执行真实删末列宏；其余前缀不变。这穷尽源步骤。

### 1.3 标准初值和非循环性

原生 \(B_{H+1}[N-1]\) 在前 H 行都是完整相邻祖先链，故覆盖任意源左父边。
以后不重建这个目标，只沿其实际后代运行。所有准备宏的终止性已有固定前缀势证明，
不借用尚待推出的源良基性。

所以这里补的是旧祖先覆盖定理的**源端假设**：源不必原生；目标仍必须原生。
它没有把任意 raw 图自动识别成一个原生表达式。

## 2. 对实际非原生高图的应用与局限

[低行/高行分解](FLOOR-BAND-AND-RAW-HIGH.zh-CN.md)给出的实际10步标准证书
`D44[1][0][0][1][0][0][1][0][0][1]`，其高图有12列、最大行高11，且不是原生父表。
定理1仍为它的**无插行辅助游戏**给出固定真实目标 \(B_{12}[11]\)。

核验中，这个非原生源经14个指定辅助步骤清空，目标花费1,863个真实 TBMS 原子，
含1步初始全链生成。它从头到尾只有一个目标初值。

**不能据此声称同一个目标覆盖实际 SRPD 高步**：后者还会插行；
低行阶段另会在高图中产生别名操作。这两个动作是下一部分的对象。

## 3. 根界类 R 中，行高增长只发生于新生分量

取原始高图的第1行空根 r(j)。类 R 的条件是：每列高≤r(j)，且该列全部行父都属同一空根。
这是[上一稿已建立的实际高图不变量](FLOOR-BAND-AND-RAW-HIGH.zh-CN.md)。

本节的局部结构结论只用这些条件，甚至不需要源原生或森林嵌套。
应用定理1时则仍须另有嵌套性。

记根 r 所有列的最大行高为 H_r≤r。一次完整原 SRPD 反射的切点 c、跨度 L=N−c。
以下也适用于低步所诱导的高图别名反射：末高列为空，在外部指定 c≥0，
接缝整列继承 c（c=0 时为空），仍作原来的对角复制；临时空末列最后删除。

### 定理2：完整反射的分量分类

1. **r≤c 的分量：**其全部列高≤r≤c，故副本不会插行，只有父地址搬运。
2. **r>c 的分量：**所有列和父都在 c 之后，因此复制的是整份分量。
   它的新空根为 r+L，各列同做“第 c+1 行重复 L 次”的拉伸。
   新分量的最大行高精确为
   \[
   H'_{r+L}=\begin{cases}H_r,&H_r\le c,\\H_r+L,&H_r>c。\end{cases}\tag{2}
   \]
   它不再指向旧分量；所有父都同加 L。
3. **每个仍位于真前缀中的旧空根 r<N：**反射后仍存在，且
   \[
   H'_r\le H_r。\tag{3}
   \]
4. **接缝成为空根 N：**若 c>0，则必继承一个空的切点 c。
   接缝连同 c 分量的副本构成新分量，最大行高仍为 H_c，不增长。
   c=0 的别名另外产生一个孤立空接缝。原末位的孤立空占位符可被覆盖或重新绑定，
   不能把它当成已经有后代的老分量。

证明：前两项直接由高度界、同根父关系和原复制公式给出。
旧前缀列不变；接缝若非空，来自活动分量的旧末列和切点列，其高不超过该分量已有最大值。
能重新接入旧根的复制列只属于第一项，行高不变，因此得到(3)。
接缝为空的情况逐一读 h=1 和别名继承规则，即得第四项。

每次完整反射继续满足 R，所以分类可以迭代任意 n 次，再删除临时末列。
这正好覆盖实际高步骤和低步诱导的高图别名，不是一个换过规则的版本。

在一个固定底树坐标系内，这说明：**一个既有空根的分量可以不断增加列，
但它生存期间的最大行高不会增长；插行产生的更大行高全部落在新根的复制分量中。**
底树本身整体复制、改变地板坐标的步骤，仍按前稿的行列地址抵消公式处理。

## 4. 这个分类为什么还不是全局下降秩

固定行高不等于固定分量的秩下降。即使完全没有插行，也会发生：

```text
G = [] [] [1] [2]，  G[1] = [] [] [1] [] [1]。
```

旧根1的分量从 `[][1]` 变成 `[][1][1]`，行高均为1，
后者却通过 `[0]` 真正下降到前者。一次别的分量的动作，可以增加这个旧分量的秩。
所以不能给每个根独立赋秩后，未经联合控制证明就取一个简单和。

别名本身也可能增长高图：

```text
rawAlias([][1][], cut=1, n=1) = [][1][][3]。
```

输出以整个输入为前缀；删除其最后一列才回到输入。
低行阶段支付了这个别名动作，但裸高图没有下降。

因此当前真正缩小的难点是：

- 既有有限行高分量之间的回调、追加；
- 新的整分量复制及其更高但有限的行预算；
- 支付这些生成/别名动作的低行控制。

定理1解决了固定无插行联合图的原生覆盖；定理2把行高增长定位到新分量。
**二者尚未给这个联合生成系统构造一个持续的 TBMS 目标或事件秩。**

## 5. 旧无限生成模板在 D44 的真后代中被结构性排除

这是此前带头分量不变量 H 的一个直接推论，不是新证明 H 本身。
H 对 D44[n] 的相对后代成立，冻结前五列的秩仍需另计。

假设存在 r<u<v<e，满足旧弱返回模板的必要条件

\[
C(r,u),C(r,v),C(r,e)\ge2,\qquad C(u,v)>r,\qquad C(v,e)\ge1。\tag{4}
\]

令 R 为 v 的第2行分量根。由 C(r,v)≥2，r≥R。
H 给 v 高≤R+1，再由 C(u,v)>r，强制 r=R、v 高=R+1。
所以 v 是峰，并且 u 正是它的纯父数据点。
但 H 禁止峰 v 有同时满足 C(v,e)>0、C(R,e)≥2 的后续点 e，矛盾。

因此，在这些真后代中，连四点弱返回模板都不存在，更不可能有旧五点可反复克隆母模板。
这排除了直接靠那个现成模板证明某个固定 D44 真后代承载整个 TBMS 极限的路线。
**它没有排除其他承载机制，也没有证明 D44≤Limit。**

D44 本身不满足 H：它的末列 `[12,7]` 正是未消耗的返回口，
给出 r=7、u=11、v=12、e=13 的四点必要结构。
不能将“D44[n] 后成立”的不变量误用到 D44 本身。

\[

\]

\[
\boxed{\rho_Y(W)\le\rho_M(M13[12])<\rho_M(M13).} \tag{1}
\]

对每个 n，具体初始化项为 `M13[12][3n+6]`，模拟 W[n] 的全部任意指标后代。

## 2. 新源类：支体不拥有该高根

保留 S 的所有条件，特别是正普通行不引用高尖端、严格零星接口及永久标记。
高尖端颜色仍只允许 1、2。颜色 2 尖端 t 的高根为 c，底父为颜色 1 尖端 u；
称 `(u,t)` 为一对芽尖。增加以下条件：

**P1.** t 没有底行子列；u 恰有一枚高尖端子列 t。u 可以有普通子列及其整个支体。

**P2.** 对 u 的每个**普通底行后裔** j，都有 `c∉O(j)`。
也就是说，支体可以复杂，但其中没有普通列同时通过 u 的底链和 c 的第 h_c 行。

**P3.** 对每个根 c，所有满足 `c∈O(j)` 的普通列 j，均在 c 的全部剩余第二尖端 t 之后。
如果已没有这样的 t，这项条件为空。

这里 P2 是完整祖先关系条件。**不能用“u 的第一个普通子列高度不超过 h_c”代替 P2。**
原 Y 可越过低列重新连接较高行，详见
已经否定的行凸性命题（未随本次收录的来源：`output/e0mn13-y-location-20260920/REJECTED-ROW-CONVEXITY.zh-CN.md`）。
本稿不使用那种高度屏障论证。

记 k(c) 为根 c 的第二尖端数。P1 保证每个计数项使用不同的 u。

## 3. 精确 owner 公式如何给出源闭包

使用已有公式：普通复制只将每列的 owner 集按同份地址搬运；高步只有在当前尖端颜色 2 时，
才给上升列在指定位置插入早份控制根链 `c_0,…,c_(b−1)`。
“上升”是实际第 h_c 行祖先关系，绝不是仅凭列位置或高度判断。

### 3.1 P1 与颜色保持

颜色保持由 S 的定理给出。只有复制首列的底接口可能新接到旧尖端。
新普通子列若要接到 t，旧控制的底父就必须是 t：普通控制与 t 原来无子列矛盾；
高控制则会要求颜色 3，也不可能。高控制首复制列自身是普通根，不是新高尖端。

普通正行不能切高尖端；普通零行复制高尖端时不改其底父。
因此旧第二尖端只跟着其第一尖端 u 一起复制，不会给同一个 u 新增第二枚高尖端子列。
u 可以新增普通支体，但 t 仍然是叶子。

### 3.2 普通复制保持 P2

设普通切点为 d。对一对保留芽尖 `(u,t)`，分三类。

1. u 位于不动前缀，而新普通列进入 u 的底行子树。
   此时 d 位于该子树，旧坏块内的普通列已经受 P2 约束。
   c 位于 d 左侧，普通 owner 搬运不产生新的外部 owner c，故这些副本仍不拥有 c。
2. u、c 都随同份复制。新副本里 u 的普通后裔若在同份内部，其关系来自旧支体，P2 直接搬运。
   若接缝使较晚一份进入较早一份的 u 子树，普通 owner 公式只含同份内部根及原外部根，
   不会新增较早一份的内部根 c；所以这类跨份普通列也不拥有该 c。
3. c 不复制而 u 复制。由底行子树区间性及链 `u→c`，切点必为 u 本身；
   且控制行只能为 0。整个坏块都在 u 子树，原普通列均不拥有 c，搬运后仍然如此。

这三类包含所有可能，不依赖“中间列高度低则阻断后续高行”。

### 3.3 高复制保持 P2

若当前高控制根 d 不是这对芽尖的根 c，则新插入的 owner 只是 d 的副本，
不会凭空产生另一个内部根 c 的 owner；旧 c 的成员关系按旧公式搬运。
若 c 在不动前缀，且操作在 u 支体内部，原来缺失的外部 owner c 仍然缺失。

若当前高根就是 c：对任何仍受保护的 u 及其普通后裔 j，P2 给出 `c∉O(j)`。
由于 u 本身就是底行尖端见证，这等价于 j **不在本次实际上升集内**。
高步的 owner 插入公式因此不会给这些普通列添加任何 c_i，也不会在同份添加 c_b。

新的首复制根跨份接到当前控制尖端的底父：一致高步接到普通根 c；
非一致高步接到当前一对的 u，但当前 t 已删除，该 u 已不再受保护。
它不能把新普通支体接入另一对仍受保护的 u。因此 P2 保持。

### 3.4 P3 的次序保持

普通步若 c 随份复制，c 的普通拥有列与第二尖端同时、按原次序复制，保持 P3。
若 c 不复制且没有复制它的第二尖端，新列都位于这些保留尖端之后，也保持 P3。

唯一需要另查的情况是：c 不动、其第二尖端被复制。这必为 §3.2 第 3 类：切点是 u。
当前末列 x 在 u 子树；该子树是区间，故 c 的其他第一尖端分支都位于 u 之前。
P3 排除所有位于当前 t 之前的普通 c 拥有列；P2 排除 u 子树内部的全部普通 c 拥有列。
所以**此时整个旧词没有普通 c 拥有列**。普通搬运后仍无这样的列，新增第二尖端再多也不违反 P3。

高步对非活动根仍按同份搬运；外部根的第二尖端都在切点之前，故新列次序也无问题。
对活动根 c，一致高步不插入 c 的 owner 链。
非一致高步则分两种：同份 c_b 的拥有关系来自旧 c，保持旧次序；
新增的早份根 c_i 只出现在较晚份 b>i 的列上，而 c_i 自己保留的第二尖端都在第 i 份中。
所以每个新普通拥有列均在相关第二尖端之后，P3 仍成立。

删尾保持全部条件。由 S 的闭包及 §3.1—3.4，新源类对全部指标封闭。

## 4. 计数什么时候能够增长

除当前被删除的第二尖端之外，所有颜色保持。
若芽尖对的根一起复制，则每个根的 k 不增加；非一致高步的活动根及其副本各减一。

要在同一个旧根 c 上增加第二尖端，必须将尖端与 c 分开复制。
由 `t→u→c`、底行区间性、P1 的 t 叶子性及正行禁止切尖端，唯一可能为：

\[
\text{普通第 0 行控制切在受保护的第一尖端 }u,
\quad H_u=c.
\tag{3}
\]

这一份坏块含一枚第二尖端 t，故 `k'(c)=k(c)+n`；其他旧根计数不增。
§3.4 已证明，此时 c 是**干净根**：

\[
\forall j\;(H_j=\varnothing\Longrightarrow c\notin O(j)). \tag{4}
\]

因此本稿不会试图事先猜出未来全部指标，用一个固定自然数预算覆盖任意增殖。
只需在满足 (4) 的具体步骤前，真实地增加该根预算。

## 5. 两个额外目标储备

沿用前稿的完整中间插层覆盖及同时预算 `B(g(c))≥k(c)+1`。
另保留实际背景位置 b，以及锚列表倒数第二个位置 s；最后位置仍是顶储备锚。
要求

\[
b<g_0,\quad B(b)=1,\quad B(s)\ge b+2. \tag{5}
\]

s 可以临时作为根等级，但始终保留为一枚储备锚。所有根等级不超过 s。
初始取 b=1，在所有根等级以上再预留一枚 s 和一枚顶锚，即可满足 (5)。

旧零步、普通步、高步都保持 (5)：b 位于所有准备切点左侧；
s 总选自己的最后副本，而不是非一致插层的较早弱副本。
因此 B(s) 保持或反射增大。b 不动，B(b)=1 保持。
若当前根恰好也使用 s，插层后 c 降到早份，而 s 仍指原 s 的最后副本。
不能把作为储备的 s 一起降到早份。

## 6. 干净根可以移到储备等级

满足 (4) 时，c 没有被拥有的标记根，因为标记根都是普通列。
因此把 c 等级提高到 s，不会破坏任何被拥有标记根的严格等级顺序；
c 的旧 owners 的等级仍严格在 s 之前。

哪些源边会增加需求？干净根没有普通拥有列；若一枚其他根 a 的高尖端拥有 c，
则其普通根 a 也拥有 c，与 (4) 矛盾。
故仅有 c 自己的第二尖端可能受到影响。
这类尖端高 h_c+1，选择 c 作为 owner 的行只有最高普通行 h_c，父正是 c，
已有 Q 储备，足以覆盖 `s+1<Q`。
所以提高 c 的等级是合法的见证变更，没有修改或补造 M 边。

## 7. 任意有限增殖预算的真实补充

设下一个源普通步需要 `K=k'(c)+1`，而储备容量 `r=B(s)` 尚不足 K。
令 z 为当前闭合位置、d=z−b，选有限 m≥1 使

\[
r+md\ge K.
\]

在实际闭合列暴露父 b、行 1，取原 M 的 `[m+1]`，选第 m 份的全部主位置和锚，
保留下一份首根为新闭合列。置 δ=md，所有锚、主位置及 Q 增加 δ，并令 `b'=b+δ`。

原反射规则作用于行标 `q>b`。由 `r≥b+2`，储备容量变为

\[
r'=r+\delta\ge K,\qquad r'\ge b'+2.
\]

新 b' 到选定主位置仍有原容量 1。
所有有 owner 的旧需求严格大于相应等级、因而大于 b，与支持行标一起反射；
字面普通需求不增加；Q 储备与 Q 同步反射。
所以全部旧源边仍有完整覆盖，其他根预算也不会减少。

**此刻不能伪称闭合列仍然共享全部强背景接口。** 新闭合列是行 1 复制的下一份首根，
它对本份内锚的接口可能为 0。操作只需要它现在存在，不再拿它做下一次背景准备。

立即删掉该闭合列，用本来就保留的旧源末列主位置作为普通控制；
按原普通主复制步骤取足够份数，选所需源副本及一个新的闭合列。
源切点的外部背景接口被首复制列继承，所以完整步骤结束时，主位置和新闭合列重新共享背景。
这也恢复了 `B(b')=1`、储备条件 (5) 以及全部预算。

若原 r 已足够 K，§6 的等级变更后直接作原普通模拟，无须背景复制。
两个分支都是非空有限串真实 M 下降；没有重新初始化当前源，也没有把删掉的闭合列加回来。

## 8. 全局闭合与 W 的初始化

在新源类内，每步有且仅有以下处理：

- 每根计数不增的普通步、零步、一致高步：沿用前稿保持。
- 非一致高步：取 `q=k(c)+1`，每个活动根副本的预算和计数同时减一。
- 普通计数增殖：由 §4 自动得到干净根，使用 §6—7 补到新的有限预算后作该普通步。

§5 的储备始终保留，所以这是完整的逐步闭包，不是“将来若有可用位置”的条件结论。

原 Y 父表给出，对每个 n，

\[
W[n]=(1,3,4)\frown\mathop{\frown}_{j=0}^{n}(4j+2,\;4j+5,\;4j+8). \tag{6}
\]

每个三项块的根 r_j=4j+2 普通高度为 1。第一根底父是初始 1；
后续根底父是前一块的第一尖端 r_(j−1)+3。
两尖端父表分别为 `(r_j,r_j)` 和 `(r_j+3,r_j)`，高父均为 r_j。
于是每根恰有一对芽尖；全部普通块根都无 owner，只有固定前缀 134 的普通 4 拥有零高度根。
逐列直接验证 P1—P3，不凭高度猜测整个后代。

初始所有标记根等级为 0；最大普通高度 H=2。可统一取

\[
b=1,\qquad (g_0,s,g_{\rm top})=(2,6,10),\qquad Q=11.
\]

宽度为 `3n+6`，故真实项 `M13[12][3n+6]` 初始化 W[n]，与 n 无关地满足全部储备条件。
对真实目标下降秩作归纳并对全部 n 取上确界，得到 (1)。
`W[1][0][0]=Y1342586`，所以源端又严格推进一步。
W 是标准项：从 `Y1343[1][2]=Y13425811` 四次局部减一可达。

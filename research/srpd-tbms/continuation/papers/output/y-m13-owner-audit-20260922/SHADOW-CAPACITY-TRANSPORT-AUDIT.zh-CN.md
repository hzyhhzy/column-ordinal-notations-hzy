## 1. 约定与完整公式

一基地址。令 G 为**已经完成暴露**的图，实际末列为 x，
末列最后一条记录为 `(c:q)`，`1≤q≤c<x`。
令 `C(p,j)` 为 G 中从 j 到 p 的最大瓶颈容量；不相连为 0。
G 有有限严格语法和 F：每个固定阈值的全部祖先成链。

取 `G'=FS(G,n)`，n≥1，`L=x−c`。保留旧列 1,…,x−1，
复制每个 `c≤j<x` 得 `j_b=j+bL`，1≤b≤n，且令 `j_0=j`。
定义行反射

\[
\psi_b(r)=\begin{cases}r,&r\le c,\\r+bL,&r>c.\end{cases}
\]

记 C' 为 G' 的容量。则：

**同份：** 对 `0≤b≤n`、`c≤p<j<x`，

\[
\boxed{C'(p_b,j_b)=\psi_b(C(p,j)).} \tag{1}
\]

**旧外部父：** 对 `p<c≤j<x`、`0≤b≤n`，

\[
\boxed{C'(p,j_b)=C(p,j).} \tag{2}
\]

**前份到后份：** 对 `0≤a<b≤n`、`c≤p,j<x`，置

\[
T(p)=\begin{cases}q-1,&p=c,\\C(p,x),&p>c,\end{cases}
\quad
I(j)=\begin{cases}+\infty,&j=c,\\C(c,j),&j>c.\end{cases}
\]

则

\[
\boxed{C'(p_a,j_b)=\min(T(p),I(j),q-1).} \tag{3}
\]

特别地：`C'(c_a,c_b)=q−1`；`p>c` 时 `C'(p_a,c_b)=C(p,x)`；
`p,j>c` 时就是提问中的 `min(C(p,x),C(c,j),q−1)`。
这些容量**不随 b−a 继续递减**。

从后份点到前份子点的祖先容量为 0，因为父地址必须向左。
q=1 时全部跨份容量为 0，式 (1)、(2) 仍成立。

## 2. 控制列先给出的两个事实

末列记录按父下降、行严格上升排序，因此 c 是最小直接父，q 是最大直接行。
所以

\[
C(c,x)=q,\qquad c<p<x\Longrightarrow C(p,x)\le q-1. \tag{4}
\]

第二式使用有限整数行：通向 p>c 的路径不能经过更左的 c，
只能从末列其他严格低于 q 的直接边进入。

对 p<c，F 及 c 为 x 的第 q 阈值祖先进一步给

\[
C(p,x)=\min(C(p,c),q). \tag{5}
\]

“≥”来自路径 `x→c→p`；“≤”由 F 中 p、c 两祖先可比，
及 x 的所有出边容量≤q 得到。

另外，对 c<j，有限严格性给 `C(c,j)≤c`。
故式 (3) 的入口 I(j) 不受 ψ_b 反射；这解释了公式中为何是旧 `C(c,j)`。

## 3. 复制规则的阈值证明

原 M 的 `down` 将末控制 `(c:q)` 降为 `(c:q−1)`，并接入旧 c 列的行≥q 后缀；
原先末列较低记录保留。`rfl` 随后复制坏块，父地址≥c 搬运、行>c 反射。
`FS[n]` 重复该动作 n 次后删除最终临时控制列。
q≤c 保证各临时控制行仍是同一个 q，而不是被反射变大。

固定阈值 r。对于每个新首根 c_b：

- r≥q 时，跨份接缝不可用；其外部祖先来自旧 c 的行≥q 后缀，和旧 c 相同。
- r≤q−1 时，新首根可进入前份控制末列的整条第 r 阈值祖先链。
  原 c 是这条链上的点；F 保证链到 c 左侧后，外部部分恰是旧 c 的第 r 祖先链。
  在 c 右侧的成员则恰是满足 `C(p,x)≥r` 的坏块旧点。

因此 c₁ 对旧外部 p<c 的容量恰是 C(p,c)，对旧 c 的容量恰是 q−1，
对坏块旧 p>c 的容量恰是 C(p,x)。
对后续份重复同一分析：每次都以相同阈值 q−1 接上前份根，
这些跨份瓶颈串联取 min，仍是 q−1，不是 q−b。
由 (4)，所有旧坏块需求 C(p,x) 已≤q−1，所以也不会再降。
这先证明 (3) 在 j=c 的端点形式，以及所有新根的 (2)。

**同份内部。** 从 j_b 到 p_b≥c_b 的任何路径，尚未到 p_b 前不能走到更早份，
否则地址已过小，不能返回 p_b。故这段路径完全位于同份原坏块，
其每条边都按同一严格递增 ψ_b 搬运。
ψ_b 与有限 max/min 交换，得到 (1)，包括 p=c 的停止端点。

**从新普通列跨出本份。** j_b 向前份的路径只能经本份首根 c_b；
不经过首根而直接离开本份的复制旧边，其父<c，是旧外部点，
不可能再到位于 c 或其右方的 p_a。
因此跨份容量再取与 `C'(c_b,j_b)=C(c,j)` 的 min，得到完整 (3)。

**外部旧父。** 对 p<c，同份继承的外部路径与经 c_b 的路径都存在。
后者容量为 `min(C(p,c),C(c,j))≤C(p,j)`，其余旧路径也不增加容量；
反过来旧 j→p 路径复制后仍可经新根相同外部接口实现。
于是恰得 (2)。首根端点已在上面单独证明。

Sky 去支配格式不会改变这些容量：F 下，被删低父记录可由支配它的较大父沿同阈值链达到。
所以证明适用于实际规范列，而不只适用于临时多重边列表。

## 4. 被审代码的具体判定与端点限制

原脚本 `verify` 的 `p===c ? q−1 : cap(g,p,x)` 以及 `j===c` 分支正确。
它在 p>c 时未再显式取 min(q−1)，由 (4) 可知该项冗余，因此不是漏项。
其 `psi(cap(...))` 和外部直接等于旧容量的断言也正确。
原脚本主要检查第 n 份对旧第 0 份；式 (3) 补足所有 `0≤a<b≤n`。

但不能扩展到以下未定义端点：

- 旧 x 已被删去。物理地址 x 现在是 c₁，不能把它仍当作旧末点。
- j=x 不在被保留坏块内；最终临时末列 x+nL 也已被 FS 删除。
- `C(c,c)` 按通常容量接口是 0，不可直接代入 j=c 的公式；
  必须用上面的 I(c)=∞ 作为“已到入口”的记号，或单列根端点。
- C(p,x) 必须取**暴露后**的 G；暴露前旧末列容量可能更高，不能未经证明替换。

此外 F 不可省略。语法合法且各行≤父的图

`G=()()()(1:1)(4:2;3:3)`

不满足 F。取 c=3、q=3、x=5，旧 `C(1,3)=0`，但 `[1]` 后
新首 c₁=5 通过旧父4到父1，`C'(1,5)=1`。这直接否定无 F 版本的式 (2)。
它只是说明定理假设必要，不被冒称为标准源反例。

## 5. 保留旧工厂、只搬主点的精确升级条件

取 `c<p<x` 为**保留的旧工厂**，将旧主点 j>c 搬到 j_b。
即使旧 `C(p,j)=1`，由 (3) 仍有

\[
C'(p,j_b)\ge2
\iff q\ge3,\ C(p,x)\ge2,\ C(c,j)\ge2. \tag{6}
\]

同样要让新的实际闭合点 e_b 可用，必须真实保留某个模板 `c<e<x`，
并满足 `C(c,e)≥2`。如选择 e_b 作为新末点，应以真实零步删尾到该地址。
不能只升级某个主点而把未达到行2的末点称为工厂入口。

外部 p<c 不能因此升级旧弱容量，式 (2) 恰好禁止；
p=c 跨份容量也不超过旧 C(c,j)。同步移动工厂到 p_b，则式 (1) 使容量1仍为1。
所以这个现象确实依赖“旧工厂不动、主点向后份移动”的混合选择。

原脚本的精确例

`()(1:1)(2:2)(3:2)(4:1;3:2)(3:2)(4:2;3:3)`

有 x=7、c=q=3、L=4，保留工厂 p=4，把 j=5、e=6 移到9、10。
旧 C(4,5)=1，但 `C(4,7)=C(3,5)=C(3,6)=2`，故新两容量都等于2。
同步搬到工厂8对主点9的容量仍为1。这不是无条件再生；
随后若真实使用旧工厂4作为行2切点，新的跨份工厂容量又最多为1。

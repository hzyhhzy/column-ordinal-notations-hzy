## 保留父组标签的改进及其限度

[原分组背景](GUARD-GROUP-LABELLED-BACKGROUND.zh-CN.md)把同一个高 1 保护根 r 上的封闭块合成一组，标签 a(r) 支配所有严格内部组。旧受限关系在保护根返回或封闭根裸工作边界，要求活动组的全部存活副本都严格降标签。

新的候选关系仍要求所有副本标签不大于来源标签、内部组严格较小，但只在正指标普通行 1 切 r 时，要求新产生的保护根副本组严格小于旧 a(r)。留在原 r 上的组可以保持 a(r)。零删除和普通行 0 的封闭根复制不另强制整组降标签。它记为 Wret，仍只是一种受限带证书关系。

这个修改保留两项有用的源端事实。

第一，旧最大标签处的完整特殊祖先栈仍逐份运输。特殊祖先同时包含封闭块根和开放第二尖端。切 r 后，保留旧标签的活动组只在未改变的第一份；其余新活动组严格较小。切封闭 c 的行 0 时，新 c 继承旧 c 的外部底父，产生并列副本，不在旧 c 的下方增加一层。其他情况沿用原 L 类的私有屏障和完整份公式。因此最大标签不增加；若仍达到旧最大值，最大特殊深度也不增加。

第二，私有叶开启后的新工作只暴露低于被消耗预留标签的组。原 r 上较早的保留块位于刚开启的第二尖端以前，不会进入该尖端的新工作。后份中的 r 副本已严格降标签，原严格内组也早已低于 a(r)。保留旧 r 标签并不破坏这一项严格性。

完整端口归一化仍删除至少一个特殊祖先：内部保留同一最大标签时降低深度，否则降低最大标签。这些是标签和几何的结论，不自动给 Wret 原生目标秩界。旧 W_G 是更强限制的关系，不能因它已有背景定理就把定理直接套给这个更大的关系。特别需要重新证明：同标签私有预留的复制、裸返回，以及所有短前缀仍满足固定目标图中的持续容量合同。本文不把这项尚未完成的目标运输检查隐藏为“证明不变”。

保留父组实验（未随本次收录的来源：`output/srpd-limit-y-lower-20261001/GUARD-GROUP-RETAINED-PARENT-VERIFICATION.json`）验证了 505 个原步骤、1187 份最大栈运输、89 项新暴露低标签条件和 1000 个完整端口。另有三个旧标签规则拒绝而新规则接受的小例，包括标签 1 的裸封闭根复制、标签 1 的零开启，以及标签 2 的父组保留并产生标签 1 子组。新关系仍会拒绝标签 1 的正开启，故不存在从有限测试推出的全 Y 提升。

## 一个复制窗口不是整个新调用

设普通行 1 控制切高 1 根 r，末列为 x，跨度 d=x−r，指标为 n。把以 r 为入口的完整程序归一化为根 1、入口 2，记为 N_r(s)。第 b 个新入口为 r_b=r+bd。

每一份单独截到长度 d 的窗口都恰是 N_r(s)[0] 的重编号。然而新 r_b 的完整身体通常还含它之后的全部复制份。真正的整尾公式为
\[
N_{r_b}(s[n])=N_r(s)[n-b],\qquad 1\le b\le n.
\tag{1}
\]

证明直接对复制份重编号。第 b 份首根归一化后成为入口 2，其内部普通和高父按同份移动；第 b+1 份以原末列的低父在前份中的像作底父，与对原归一化程序取第 n−b 项的首接缝一致。之后逐份相同。数值平移、完整父表和继承标记均交换。b=n 时才只剩最后一个窗口。

因此，不能把全部新子调用都定价为旧程序删末列一次所得的那一个窗口。式 (1) 是精确恒等式，不是秩下降证明：右边仍含待处理程序的较早基本列项。用它给标签赋值还需要一个已完成且非循环的上下文预算。

最初调用检查（未随本次收录的来源：`output/srpd-limit-y-lower-20261001/GUARD-CALL-FRONTIER-VERIFICATION.json`）对 30 个完整后缀核对了式 (1)，但另外的 528 次调用前沿检查全部处于内部，外围分支次数为 0。它不能被描述为“调用所有返回分支均已通过”。

## 整个调用不一定在外围视图中静止

所谓单入口调用，最初取一个普通高 1 根 q 的完整底行子树。它不是任意一段并列兄弟。把严格身体删去、只保留 q，称为收缩。正内部控制不会越过 q，但这不足以推出收缩后的外围状态不变。

反例为
\[
s=(1,2,5,8,10,3),\qquad q=1.
\]
末列的父为 (q)，控制是普通行 0 切 q。于是
\[
s[1]=(1,2,5,8,10,2,5,8,10).
\tag{2}
\]
第二份入口不是 q 的严格后代，而是与 q 共有外部父的兄弟。只跟踪旧 q 的子树，会把完整的第二个调用漏到外围；同时收缩两份则得到 (1,2,2)，仍不同于原收缩 (1,2)。

一般地，普通行 0 切 q 时，将一个调用变成 n+1 个并列调用，每一个恰是旧调用删掉最后一个严格后代后的完整副本。原首根和新首根的全部父均相同地指向外部，其他列按同份搬运。这给出正确的三种分支。

1. 严格内部步：控制在 q 之后，或在 q 作不会产生外部父的完整行返回；外围收缩静止。
2. 第 0 行入口分裂：外围收缩增加 n 个同型的裸兄弟入口；新身体各为原身体删末列后的副本。
3. 外围步：非空的暂停调用被完整复制，收缩与相应原 Y 外围步交换。

这里第 1 项还需要下一节的行高限制。若整个调用已清空，取消它的“不透明身体”标签，随后直接由外围处理根，不能继续把它当作内部非空调用。

边界检查（未随本次收录的来源：`output/srpd-limit-y-lower-20261001/GUARD-CALL-BOUNDARIES-VERIFICATION.json`）保存了式 (2) 对旧断言的实际失败，并检查修订分支：750 次中有 590 次内部、14 次分裂、146 次外围，其中 5 次为真正复制非空调用的外围高步骤，15 个旧调用标签退休。它不是仅仅增加了更多原先的内部样本。

## 高入口的部分行返回会重新引入外部端口

高 1 入口不能原样换成任意高度的“独立子树”。设普通入口 q 的高度为 h，严格身体最初没有指向 q 以前的引用。若正普通控制在第 a 行切 q，且
\[
0<a<h,
\]
则新入口 q_b 的低 a 个父来自末列在前份中的父，而第 a 至 h−1 个父仍继承旧 q 的外部父：
\[
P_{q_b}(i)=
\begin{cases}
\phi_{b-1}(P_x(i)),&i<a,\\
P_q(i),&a\le i<h.
\end{cases}
\tag{3}
\]
低父使 q_b 位于原 q 的身体内，高部未替换的父却回到 q 以前，故原单入口隔离条件失效。这由普通首根公式直接得出，不依赖实验频次。

最小记录之一是 (1,2,5,7,10)，q=3，高度 2，P_q=(2,1)，末列 P_x=(q,q)。正第 1 项产生的新入口父为 (q,1)。外部列 1 重新进入内部身体。q 高度为 1 时不存在 0<a<h，这解释了旧入口条件的实质用途。

外围高复制也确实能增加普通调用入口高度。例如 (1,2,5,7,8,5) 中的 q=3，经指标 n 高展开，复制入口高度为 2,3,…,n+2。不能只在调用建立时检查一次高度，随后假定它永远不变。

主候选的 B[0] 正好遇到式 (3)：q=7，P_q=(3,3)，最后的 17 有父 (9,7)。第 1 项的新入口在列 10，父为 (9,3)。因此需要保留外部列 3，而不只是记住内部入口 7。独立记录（未随本次收录的来源：`output/srpd-limit-y-lower-20261001/GUARD-CALL-PARTIAL-RETURN-VERIFICATION.json`）核对两种初态、各三个正指标的全部外部引用，也保存了四种高复制的入口升高实例。

调用实现第三版（未随本次收录的来源：`output/srpd-limit-y-lower-20261001/guard-call-frontier-v3.cjs`）对通过隔离检查的步骤给出精确分支，但它并非全体隔离初态的闭包实现。上述部分行返回会被它拒绝；文件开头关于“保留接口”的简略注释不能作无条件闭包定理。该版本保留以维护实验文件身份，没有改写先前成功记录所用源码。

## 保留整个末尾程序的双端口修正

采用固定框架 Q=(1,2,5,8,10,4)，仍将外部高 1 根 r 映到列 1，普通高 2 入口 c 映到列 5。本次与[旧双端口工作归一化](SEALED-TWO-PORT-NORMALIZATION.zh-CN.md)不同：保留 c 后的整个程序，包含 c 自己的高尖端和叶，不先删除任何私有三列。

入口要求 P_c=(r,r)、H_c 为空。尾部各普通父只可为 r 或不小于 c 的内部列，高父均不小于 c。数值平移为
\[
v\longmapsto v-\operatorname{value}(c)+4.
\tag{4}
\]
第 0 行与所有内部差分保持，r 的第一行值为 1，c 的第一行值为 2。固定框架保留这两个外部行值；后续严格寻父与高父搜索沿相同内部父链进行。因此完整父表正是地址重编号。标记继承，框架的 r、c 标记也从原状态保留。这只是规范词接口，不声称它仍在旧 L 类中。

令门控步骤不删除最初的 c，且正指标切点不得小于 c。则
\[
\operatorname{Norm}_{c,r}(s[n])
=\operatorname{Norm}_{c,r}(s)[n].
\tag{5}
\]
普通、高手续的每份都只复制同一个尾区；复制公式中的外部父 r 保持，其余父重编号。第 0 行分裂保留所有并列副本，因而这里必须取整个尾区，不能重新截为最初 c 的严格子树。第 1 行部分返回按式 (3)继续保留 r。第 2 行完整返回和高控制也有相同的逐父公式。零删除在 c 之后时直接交换。以上情况保持同一双端口条件，故式 (5)可以沿任意有限门控历史组合，不需要重选框架。

如果正控制切到 c 以前，只能切普通根 r；r 高度 1，所以控制行只可能为 0 或 1。此步明确在式 (5)的合同之外。禁止它不等于证明它不会发生；这正是仍需支付的外部返回。

## 主候选的第一层展开族

写 A=(1,3,4,2,5,8,10)。主候选为 B=Y(A,4,9,14,17,10)。其末 10 的父为单列 8，普通行 0 跨度为 3，复制平移为 0。因此对所有 n≥0，
\[
B[n]=Y\bigl(A,4,(9,14,17)^{n+1}\bigr).
\tag{6}
\]
同一普通根 c=7 上有 n+1 对高尖端，每对后面附一枚返回 c 的高 2 普通叶。这不同于同根全部叶返回高 1 保护根 r 的旧 L 模式。

设 Z=B[0]。Z 的末 17 在普通行 1 切 c，跨度仍为 3，但复制平移为 12，故
\[
Z[n]=Y\left(A,\mathop{\frown}_{b=0}^{n}(4+12b,9+12b,14+12b)\right).
\tag{7}
\]
式 (7)就是[旧两行受保护入口稿](../y134259-owner-returns-20260928/GUARDED-TWO-ROW-PORTS.zh-CN.md)已有 Z[n] 公式的另一种书写，不作为新的下界或首次发现。这里的新用途是与式 (3)、整个尾区的式 (5)以及主候选的式 (6)接合，说明应补哪一种接口。

式 (7)的第 b 组记 c_b=7+3b、u_b=c_b+1、t_b=c_b+2。b>0 时 P(c_b)=(t_(b−1),3)，高尖端分别为 P(u_b)=(c_b,c_b,c_b)、P(t_b)=(u_b,c_b,c_b)，高父均为 c_b。b=0 时 P(c_0)=(3,3)。这逐份给出式 (7)的全参数证明；数值检查仅作实现对照。

## 为什么还没有取得新的完整下界

这些接口尚未给出 B 或 Wret 的全后代秩界。当前尚需的是一个可持续的上下文预算：它既要支付同一保护根的再次调用，又要支付部分行返回引入的外部端口和随后对该端口的再次返回。

不能把新调用的初始宽度较短当成未来宽度下降；不能只给单个复制窗口计价；不能把不同有限轨迹分别选到足够大的整数标签，视为一个固定初态证书。更不能先取未比较完整程序的 Y 真秩，再把该秩当作 SRPD 已有资源。

下一步可尝试带端口的上下文秩，或者直接构造其 SRPD 持续容量接口。若继续标签路线，应先证明 Wret 的同标签复制运输，再构造规范标签；若直接处理 B，则需对式 (6)的全部 n 及全部合法后代给出统一说明。本文不把任何一个选择写成主目标的硬路线。

## 源类保留完整结构

源列从0编号；Pj 是普通父表，Hj 是高父。沿用[规范 L 类](GUARD-ALIGNED-PACKET-WORK.zh-CN.md)
的规范性、私有枝、永久标记及严格零星条件，进一步要求每个封闭块根 c 的父为(r,r)。
r 是带旧私有三列的高1保护根。c 后三列仍私有：

\[
P_c=(r,r),\quad
P_u=(c,c,c),\ H_u=c,\quad
P_t=(u,c,c),\ H_t=c,\quad
P_e=(t,r),\ H_e=\varnothing,
\tag{2}
\]

其中 u=c+1、t=c+2、e=c+3。c 标记为根、owner为空，u、t不标记，e保留其历史标记。
这与[旧 J 类](GUARDED-ROOT-WORK.zh-CN.md)的私有块完全相同，不省略其私有引用约束。

在 e 后允许若干直接返回头 v，它们的父均为(c,r)，无高父。
每个 v 后紧跟它的完整、连续的底行子树 Fv；v 的全部直接工作入口恰为单父(v)，无高父。
更深处可以有开放高结构、完整私有块及它们自己的返回头，不能把这些内容删掉后计秩。
本 c 的返回头彼此是兄弟，不能用另一个本 c 返回头作为底父。

全部返回头及其完整工作之后，才是 c 的普通高1入口工作 Fc。
同一 r 的各块连同两类工作仍构成连续块列，不夹杂无所属空隙。
称此类为 D。对每个返回头 v，记其严格底行祖先中的全部返回头为栈 E(v)，定义

\[
d(s)=\max_v|E(v)|,\qquad\max\varnothing=-1,
\quad D_d=\{s\in D:d(s)\le d\}.
\tag{3}
\]

没有返回头的 D_(-1) 恰是整个旧 J，而不是仅无额外私有块的 J_(-1)。
其已记录统一界是[工作证书稿式 (5)](ONE-CAP-CERTIFICATE-LIFT.zh-CN.md)：

\[
\rho_Y(s)<\theta_\omega<\rho(I_{29})\quad(s\in D_{-1}),
\qquad \theta_\omega\text{ 为 ε 数}.
\tag{4}
\]

## 所有原生步骤下的闭包

L 的旧闭包处理一般父表、标记与私有性；现在核对额外的直接返回头、完整工作和连续排列要求。

**外部步骤。** 高1入口禁止正行及高父从工作内部越过端口。
返回头的第二父直接到仍封闭 r，行≥2在入口结束；r 的旧私有叶尚在，不能在 r 上作开启高控制。
故外部高步不能把返回头或直接入口升成另一种形状。
其余外部步骤完整搬运头和身体；外部引用仍通过对应 c、r。
该事实也沿用 L 的严格零星条件排除行0高步的例外，不将任意语法图算入 D。

**头内工作。** 控制点在 Fv 内时，步骤留在这片工作内。
它可以改变内部私有块及其头，但不改变外头的(c,r)入口。
若末列是裸单父(v)，正控制在行0切 v，接缝继承原 v 的(c,r)，
得到 n+1 个兄弟头，各带原 Fv 去末裸列后的完整工作；不是把新头嵌在旧头下面。

**空头返回。** 若末列恰为 v，它没有身体，且 Fc 为空。
控制为行1切 r。设末列位置为 x，则对所有 n≥0，

\[
s[n]=s_{<r}\frown\mathop{\frown}_{b=0}^n(s_{[r,x)}+3b).
\tag{5}
\]

加3b指该数字块的整体平移。同份 c 的值比 r 大2，新首根又比前一份 c 大1，
所以每份整体加3。新首根的底父是前一份活动 c，不是前一份返回头。
从而被复制的上下文接入 Fc，而没有插入到剩余兄弟头之间。
此前的完整头身体、块列及其私有部分逐份不变；活动块只少最后一个空头。

**块工作边界。** 末裸单父(c)在行0切 c，得到 n+1 个同 r 的兄弟块。
各自的私有三列及返回区完整保留，Fc 都是原工作去末裸列。
这是旧 J 边界，只把返回区作为完整未改的前部携带。

**私有开启。** 末列为 e 时，返回区与 Fc 均空，活动 c 失去封闭身份。
连续块列保证新增开放结构只围绕此前完整块，不产生无来源的封闭块。
新 r 的底父为前一份刚开放的 t，而不是返回头。
旧高1私有枝开启时，其后块列已经空，新增部分仍是旧纯 C。

这些分支穷尽实际末列控制；零指标只删除末列，截前缀只截短身体或撤掉末私有块的完整身份。
因此 D 对全部基本列及前缀闭合。

若本步切点为 a、跨度 Δ，第 b 份的地址映射为 φb(j)=j（j<a），否则 j+bΔ，
上述分支还给每个存活完整头和每个完整块的**整个严格头祖先栈**的逐份运输。
头工作边界复制的是兄弟头；空头返回的新根接 c；私有开启的新根接开放尖端。
这些是可能增加祖先的全部接缝位置，均没有增加返回头祖先。
所以

\[
E'(\varphi_b(v))=\varphi_b(E(v)),\qquad d(s[n])\le d(s).
\tag{6}
\]

不能改用删去身体后的头数：Y(W,6,7)[1]=Y(W,6,6)，头数从1变2。

## 完整工作端口

对一个头 v，完整身体 Fv 的所有直接入口高1。
以一个标记根1替代 v，内部数值 z 改为 z−value(v)+1，所有内部标记继承。
高1屏障保证没有遗漏的外部正父或高父，原 Y 重算父图恰为原身体重编号。
内部的私有块和返回头全部保留。每个内部头的栈删掉 v 及其全部外部头祖先，因此

\[
s\in D_d\Longrightarrow\widehat F_v\in D_{d-1}.
\tag{7}
\]

Fc 和开放第二尖端的完整工作也可作同样的单端口归一化，但它们不必降低 d。
只有头身体使用式 (7)。
所有端口的门控过程都固定端口根：允许内部原步骤及删尾，禁止删根和正指标切根。
内部步骤与归一化逐项交换；正切端口的边界已在上节单列，不能混成内部交换。

## 先证明受限带标签背景

固定非零极限 Θ 和正规 b0，要求对 α<Θ 有 b0(α)>γ=ΓI5、b0(α)<Θ，值为 ε 数，
且行高严格低于 b0(α) 的所有有限普通行森林秩也严格低于它。
这是[旧背景定理](RESERVE-LABELLED-BACKGROUND.zh-CN.md)的精确条件。

对任意有限 D 状态，给每个完整块 c 一个正标签 a(c)<Θ，要求它严格大于：
其全部 Fv 和 Fc 内的所有块标签，以及同 r 此前块列的最后标签。
每步先取真实 Y 子项，各完整副本标签只能弱化；空头返回和裸 Fc 边界要求活动 c 的全部副本严格降标签。
头内工作和裸 Fv 边界在这个受限关系里不额外要求 c 严格降标签。
私有开启消耗 c。单独改标签不是一个步骤，且并不预设任意 Y 子项都有可用标签。
记这个关系为 WD。

令 α 为最大块标签，无块取0；k 为标签恰为 α 的块的最大开放第二尖端祖先栈长。
私有尖端不计入该栈。对 α，再对 k 归纳，得到

\[
\rho_{W_D}(s,a)<b_0(\alpha+1)<\Theta.
\tag{8}
\]

下面说明旧背景证明的每一项为何仍适用，不先使用未知的完整 D 秩。

1. 最大 α 块不可能位于另一个块的 Fc 或头身体内；那会违反标签支配条件。
   因而头身体内部或裸身体边界仅复制更小标签，不能给 α 块增添开放祖先。
2. 空头返回及 Fc 边界的活动副本严格降标签；被复制的此前块列、身体都小于活动标签。
   私有开启也只把此前较小块置于新的开放结构内。其他 α 块的完整开放祖先栈原样运输。
3. Fc、Fv 的带标签端口只含小于所属 c 的标签。
   开放端口若处于某个封闭块内，同样不含全局最大 α；否则归一化删除自己的开放祖先层，
   对仍含 α 的端口严格降低 k。递归取的门控秩因此已经在较低归纳参数完成。
4. 无完整块时使用旧 γ 界。旧高1私有枝预留 Λ，私有块 c 的第一尖端预留 b0(a(c))，
   开放第一尖端预留其全部完整端口的有限指数和 Σω^κ。它们都小于 b0(α+1)。
5. 标签 ξ 的私有开启只显露最大标签 β<ξ 的有限完整端口；归纳给 κ<b0(β+1)≤b0(ξ)。
   b0(ξ) 的 ε 闭包支付新开放端口的全部有限指数和，不能使用当前待证层的秩。

预算的原生运输继续用[全前缀 owner 接口](../y-general-owner-interface-20260927/GENERAL-GRADE-INTERFACE.zh-CN.md)。
新增的裸 Fv 边界只是普通行0继承(c,r)，没有新高控制；头返回仍是旧普通行1切 r。
标记控制的需求2留下1行，支付新 r 到前一份 c 的低边；未标记控制用固定 Q 储备。
私有开启和 Fc 边界是[旧闭根工作计算](ROOT-WORK-ORDINAL-BOUND.zh-CN.md)的同一分支。
完整份、部分份、外部根和保留前缀各用相应旧前缀预算，不只检查完整词。
短前缀尚未显露 e 时，仍用完整状态的储备见证，不能在源中免费补回 e。

固定初态的全部有限前缀预算最大值 D0<b0(α+1)，取 Q=ω^(D0+2)<b0(α+1)。
上述运输保持同一个 Q；每个准许 WD 步骤给普通主图非空有限下降。
普通森林闭包取得式 (8)，同时建立当前类良基性。

同一图上的有效标签 a′≤a 时，每个从 a′ 准许的子项也从 a 准许，
严格活动标签条件也保持。所以已良基门控秩随标签弱化不增。
在上面的归纳中只对已完成的较低端口使用这个子项包含论证；不是提前调用待证当前层。

## 以较低深度的原 Y 秩给头身体定层级

固定 d≥0，假设 D_(d−1) 的全部秩小于一个 ε 数 η。
由式 (7)，每个头身体的**原 Y 门控秩** κY(Fv)<η 已经可用。
定义 c 的返回层级为普通序数和

\[
\beta(c)=\sum_{v\text{ 为 c 的头，按列序}}\omega^{\kappa_Y(F_v)}<\eta.
\tag{9}
\]

这里不使用尚未证明的整个 Dd 的 Y 秩。原 Fc 的工作秩也不在这里直接使用。

头身体内部步骤严格降低其门控秩，且被改变的是最后一个头，故 β 严格降低。
裸头身体边界的旧门控秩为 τ+1，新各身体秩为 τ，于是末项
ω^(τ+1)变为ω^τ(n+1)，也严格降低。
空头返回令 β=β′+1 变为每份的 β′。
Fc 内部步骤及其边界不改本 c 的返回区，β不变；外部完整复制保持所有身体同构。
私有开启只在 β=0 且 Fc 为空时发生。

这些等式是整个身体秩的变化，不是计数显示的变化。

## 非循环的规范块标签

令 b0 正规枚举大于 η 的 J 闭合 ε 数；令 bξ 正规枚举所有较低 b 层的共同不动点。
需要一个 ε 数 Θ>η，满足

\[
b_\xi(\zeta)<\Theta\quad(\xi\le\eta,\ \zeta<\Theta).
\tag{10}
\]

本节先在这个明确条件下证明源提升，下一节给它实际承载。
所有块使用同一套 b 函数，不按其头深度更换函数。

已经标好的完整 Fc 有

\[
a(F_c)=\max\{F_c\text{ 内块标签}\},\qquad
h(F_c)=a(F_c)+\kappa_{W_D}(F_c).
\tag{11}
\]

空工作取0。式 (8) 已在不假设源提升的情况下证明，所以这里的 κWD 有定义。
内部准许步使 h 严格降低，单纯标签弱化使 h 不增，完整身体同构保持 h。

对 c 令 A 为其全部头身体内的最大块标签，ν 为同 r 此前块列最后标签，空集取0，
μ=max(A,ν)。置 gβ(x)=bβ(x+1)，Gβ 为它对迭代指标连续的迭代，Gβ_0(x)=x。定义

\[
L(c)=G^{\beta(c)}_{\omega^{h(F_c)+1}}(\mu).
\tag{12}
\]

先给真身体内和此前块列的块赋值，再给 c 赋值；这两类依赖构成有限无环图。
进入身体的依赖严格进入子树；该子树内部块的同根此前块列也完整留在子树内，
不能沿此前块列返回外层。留在同层的依赖则严格向左，故不存在循环。
较深块与较浅块都使用当前同一套式 (9)至(12)，不从未知未来路径取秩。
额外的 A 不能省：只用 ν 无法保证外块标签支配其头身体内的块。

由[迭代代数](TREE-CAPPED-RETURN-CERTIFICATES.zh-CN.md)，对 β<η、h,μ<Θ，

\[
G^\beta_{\omega^{h+1}}(\mu)
\le b_{\beta+1}(\mu+\omega^{h+1})<\Theta.
\tag{13}
\]

式 (10) 和 η、Θ 的极限及 ε 性给最后一个严格号。
式 (12) 大于 μ 及 Fc 内部最大标签，因此有限依赖归纳得到有效标签表，全部小于 Θ。
这里 β+1<η，不把 κWD 所在的较大标签域 Θ 误当作 β 的索引域 η。

### 工作步骤与裸块边界

按旧活动位置外面的封闭块嵌套数，从最内层向外验证。
Fc 内的原步骤先由内部块的验证取得一次准许 WD 步，故 h′<h，外块标签降低。
这使用的是旧状态中有限的依赖深度，不对新状态的未知未来作递归。

裸 Fc 边界得到 n+1 份相同较小工作 F′，本 c 的 β 和 A 不变。
第一份取起点max(A,ν)，之后每个新标签已经>A，所以后份起点就是前份标签。
连续迭代的组合律给最后一份标签

\[
G^\beta_{\omega^{h'+1}(n+1)}(\mu)
<G^\beta_{\omega^{h+1}}(\mu).
\tag{14}
\]

每份都小于旧标签，满足 WD 的严格条件，而不是把任意多个副本免费合并。

### 头身体内部与裸头边界

此时实际末列在最后一片头身体内，Fc为空，故旧标签
λ=Gβ_ω(μ) 是 bβ 不动点，也是 ε 数。
内部有限提升使身体内标签不增，故 A′≤A；前面的同根块列不动，μ′≤μ。
由式 (9)，β′<β；因此 λ 也固定 b_(β′+1)。于是

\[
L'(c)\le b_{\beta'+1}(\mu'+\omega)<\lambda.
\tag{15}
\]

β′+1≤β 和 μ′+ω<λ 是两个独立所需条件。
裸 Fv 边界虽然复制身体并增加头数，仍由末项指数和的不等式得到 β′<β，适用同一证明。

### 空头返回的全部新嵌套

此时 β=β′+1，Fc为空，旧 λ=Gβ_ω(μ) 固定 bβ 及全部更低函数。
此前完整块列和保留的全部头身体有原证书，标签≤μ<λ。
式 (5) 的活动副本具有层级 β′；只有它们的新 Fc 需要重建。

按新有限结构从最内份向外赋式 (12)。若一份新 Fc 的所有内部标签已小于 λ，最大为 a，
则已完成的背景式 (8) 给

\[
\kappa_{W_D}(F_c)<b_0(a+1)<\lambda.
\]

所以 h(Fc)<λ。其头身体标签和此前块列标签也都小于 λ，故 μ′<λ。
式 (13) 以及 b_(β′+1)(λ)=λ 给

\[
L'(c)\le b_{\beta'+1}(\mu'+\omega^{h(F_c)+1})<\lambda.
\tag{16}
\]

这支付任意有限 n 所造的全部新自嵌套。
完整未改的旧对象沿同构搬运原证书，不把改变了身体的对象冒充旧证书。
有限新结构重建与旧活动嵌套归纳是两种不同归纳，均不使用当前未证的整体 Y 秩。

### 私有开启与外部步骤

私有开启时两类工作均空，活动块消失，此前完整对象照旧搬运。
外部控制对完整对象只复制或减去后缀，标签不增；处于旧外层头身体时，其原门控秩严格降低，
处于旧外层 Fc 时，已提升的 WD 门控秩严格降低。
依次向外重算分别使用式 (15) 或式 (14)的内部步版本。
实际末列所在块是其同根块列的末块，不会有一个仍保留的较后兄弟需要无根据地提高标签。

因此规范赋值将 Dd 的每个原 Y 步提升为 WD 的一步，覆盖整个后代锥：

\[
\rho_Y(s)\le\rho_{W_D}(s,L)<\Theta\qquad(s\in D_d).
\tag{17}
\]

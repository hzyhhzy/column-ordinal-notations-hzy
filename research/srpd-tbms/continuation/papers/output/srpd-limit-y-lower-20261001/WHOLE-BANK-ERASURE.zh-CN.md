## 投影删去整个块而不是只删私有枝

源、继承标记和规范父表采用[返回尾巴类 R](CAPPED-ROOT-RETURNS.zh-CN.md)。
一个封闭块根 c 隶属旧高1封闭根 r；它含私有三列 u,t,e、q 枚返回叶，随后是完整工作森林。
所有直接工作入口恰为普通高1。相同 r 的各块及其工作无空隙地填满 r 私有枝之后的块列。

若 c 的真底行祖先中没有另一个封闭块根，称 c 最外层。
定义 \(E(s)\)：对每个最外层 c，删去从 c 开始到其完整工作结束之前的整个区间。
因此连 c 本身、私有三列、返回叶及嵌套工作一起删掉。其他列的数值和标记原样保留，
仅给父引用重新编号。不是把删除部分替成新叶，也不重新标记源。

这个删法是规范的。存活列不可能引用被删块的私有列；块根的其他入引用只来自它的工作，
而工作也整段删除。高1入口阻止正普通父或高父穿过工作边界向外。
各完整工作是底行连续子树，所以剩下的父链和原数值差分一致。
在原山脉重建中跳过一个这样封闭、无向外引用的连续区间，不改变存活列的父选择。
这是旧私有剪枝论证对整棵受屏障保护子树的应用，而不是一般任意子序列剪枝。

删后没有附加封闭块，仍保留旧高1封闭枝；原 C 核条件不变。因此

\[
E(s)\in\mathcal J_{-1}=\bigcup_{d<\omega}\mathcal K_d.
\tag{1}
\]

类名沿用[闭根深度证明](../y134259-owner-returns-20260928/HEIGHT-ONE-SEALED-DEPTH-BOUND.zh-CN.md)。
对每个真实前缀同样成立：未完成的末私有枝按旧规则成为开放结构，而不是强行继续删除。

## 末列在删去区间之外

设 s 非空，末列 x 不在任何最外层块区间里。所有控制父也在存活部分。
普通步不改变被保护块；高步不能穿过高1工作入口插入行，也不能切开存活私有枝。
所以删前删后控制类型、控制行一致，切点按存活列索引对应。

每份坏块中，存活列恰是 E(s) 的对应坏块。对于复制的完整封闭块，内部父图及继承标记
原样搬运；相对于其所属 r 的数值也不变。删掉这些完整区间后，复制首列的外部父、
同份父、高控制的上升判定都和先删再展开相同。由原展开公式逐份归纳，得到所有 n：

\[
\boxed{E(s[n])=E(s)[n].}
\tag{2}
\]

等号包括数值、普通父、高父和继承标记。零指标、普通正高行、正高控制以及旧高1枝开启
都包括在此分支，不能只按普通行0理解。

更强的伴随结论是：每个外部 r 的完整非空块列作为带基点 r 的对象原样复制。
对象保存每列相对 r 的数值、所有父引用及全部工作；不会重新生成工作证书。
不在坏块的 r 保留一次，在坏块的 r 按原控制的跨度复制。此结论对后续组合预算有用，
但不能直接说投影秩已经支付了被复制块的内部计算。

## 末列在块内但不是最外层私有开启

设 x 位于最外层块 c 的区间，但 x 不是该块的私有 e。
一般内部切点严格在 c 之后，所有变化仍处于删去区间；嵌套块的开启也如此。

有两种需要另外说明的边界。

1. 封闭根处的行0工作边界把 c 连同删去一个末裸入口的工作复制成若干兄弟块。
   它们都仍被删除，外部 r 和此前存活前缀没有变化。
2. 最后返回叶的控制切 r，看似越过了 c。但是首份 c 仍封闭，尾巴减少一枚；
   后续复制的 r 和全部旧块列落在这份 c 的新工作内。
   所以后续各份也都在同一个被删区间中。

两种情况对任意有限复制次数都成立，故

\[
\boxed{E(s[n])=E(s).}
\tag{3}
\]

这里允许先前块具有比活动块更高的 q，也允许其工作非空。
它们的完整内容正是被包含、复制或删除的对象，不需要层级单调祖先假设。

## 最外层私有开启的唯一例外

现在 x=e 是某最外层块 c 的私有末列。此时 q=0、工作为空。
连续块列条件保证 E(s) 的最后存活列恰是 r+3；同一 r 的此前块列已经整段删去。

定义 A(s)：在 E(s) 后面重新接上活动块自己的 c,u,t,e 四列，保留原数值和标记。
它只含这一个附加封闭块，不重新接入此前其他块。由
\(P_c=(r,r)\) 及私有块固定差分，所得数值词规范。

私有开启以 r 为切点：每份中的此前完整块列删去后，恰剩 A(s) 开启的对应份。
活动块在此步失去封闭私有叶，故投影不再删它。其他最外层块仍整段删除。
于是所有 n 都满足

\[
\boxed{E(s[n])=A(s)[n].}
\tag{4}
\]

右边没有附加封闭块，属于旧 \(\bigcup_d\mathcal K_d\)。
但 A(s) 通常不是 E(s) 的下降后代，式 (4) 不能换成式 (2)。
特别是 n=0 也暴露 c,u,t 三列，所以连这个零步骤的投影都可以增加。

## 返回模板具有固定的背景骨架

沿用[返回模板公式](CAP-GATING-AND-TEMPLATE-ITERATION.zh-CN.md)：
若活动末列是 q>0 的返回叶 x，模板为

\[
P=(1)\frown\bigl(s[r:x]-s_r+2\bigr),
\]

其末活动块尾巴为 q−1；在该块的空工作位置递归插入 P，记为 \(P^{\circ n}\)。
P 包含 r 的私有三列和整个旧块列，包括各块的全部工作。
投影删去整个块列，仅剩 r 的固定私有枝：

\[
\boxed{E(P)=(1,2,5,8,10).}
\tag{5}
\]

标记为新基点 true，后接原 r,r+1,r+2,r+3 的标记，不额外重置。
当 n≥1，内层 P 全部位于外层活动块的工作，故

\[
\boxed{E(P^{\circ n})=E(P)\quad(n\ge1),\qquad E(P^{\circ0})=(1).}
\tag{6}
\]

这说明返回模板背景的复杂度不随旧块列或嵌套次数增长；增长部分精确地在被删去的块对象里。
并不意味着整个返回模板具有同一个无条件低秩。

## 当前能用与不能用的秩结论

由旧[统一闭根承载](UNIFORM-SEALED-DEPTH-CARRIER.zh-CN.md)，
\(\rho_K(E(s))<\Gamma_{I_5}<I_{28}\)。这个量在式 (2) 严格下降，在式 (3) 不动；
式 (4) 不保证下降。它也完全看不见被删块的内部过程。

不能把它和局部 LPO 简单串成字典序：私有开启可能增加第一分量，外部高步又可能增加
先前选择的 LPO。若把整个背景编码成一个秩标签，活动 C 项未必含有其他根的块列作为子项，
也不能借局部路径序的真子项规则免费支付全背景重建。

下一项义务是一个带完整块证书的相对背景预算：在保持式 (2) 的外部逐步下降时，
让式 (4) 所暴露的端口由开启前的同一储备支付；再在固定 SRPD 资源内实现这份储备。
[抽象重置预算](CAP-RESET-BUDGET-ALGEBRA.zh-CN.md)只处理其中的序数代数部分。

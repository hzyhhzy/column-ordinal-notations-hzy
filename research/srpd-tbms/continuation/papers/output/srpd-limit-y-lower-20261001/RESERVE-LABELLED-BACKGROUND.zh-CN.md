## 背景闭包函数

记 \(\gamma=\Gamma_{I_5}\)。旧[统一闭根承载](UNIFORM-SEALED-DEPTH-CARRIER.zh-CN.md)已给出：
没有附加封闭块的整个 \(\mathcal J_{-1}\) 类秩小于 γ。
旧高1私有枝开启后的纯 C 部分仍有更小的统一界 Λ<γ。

先抽象固定一个极限 Θ 及正规函数 b，满足对每个 α<Θ：

\[
\gamma<b(\alpha)<\Theta,\qquad \omega^{b(\alpha)}=b(\alpha),
\tag{1}
\]

且行高严格小于 b(α) 的任意有限普通行森林已良基，其秩严格小于 b(α)。
这些森林就是旧无插行过程：删末列、后继行反射及末极限段内的正端点截行。

已有资源满足这些条件的一例是 Θ=θω。令 b 枚举大于 γ、对已建立普通森林算子 J 闭合的 ε 点。
采用[预算代数稿的式 (9) 至式 (11)](CAP-RESET-BUDGET-ALGEBRA.zh-CN.md)，仅将该处下界 Λ 改为 γ。
选择足够大的 k≥1，使 γ<θk，证明原样给

\[
b(\nu+1)\le A^{\theta_k}_{\omega(\nu+2)}
<\theta_{k+1}<\theta_\omega<\rho(I_{29})
\quad(\nu<\theta_\omega).
\tag{2}
\]

小于 θω 的普通 J 已由[旧六点母模板](RECURSIVE-INDEXED-CLOSURE.zh-CN.md)取得良基性。
域外可任意延拓 J 后取闭包点；b 在这里使用的初段不依赖域外延拓。
J 闭包蕴涵 (1) 所需的有限普通森林闭包，由同宽恒高祖先覆盖得到。
式 (2) 的端点登记沿用同一个旧付费母模板，不能把“存在序数 b”代替这项目标资源。

下文设

\[
R_\alpha=b(\alpha),\qquad T_\alpha=b(\alpha+1).
\tag{3}
\]

对 β<α，有 \(T_\beta\le R_\alpha<T_\alpha\)。这是私有开启的关键预留关系。

## 状态与准许的步骤

无标签部分是[带返回尾巴的规范 R 状态](CAPPED-ROOT-RETURNS.zh-CN.md)，继承原标记。
给每个完整封闭块根 c 附一个正序数标签 \(a(c)<\Theta\)，要求：

1. c 的完整工作里每个封闭块 d 均满足 \(a(d)<a(c)\)。
2. 同一个 r 的块列按列序严格增加标签。

第二项使 c 的此前整个块列，包括各块内部的所有工作标签，都严格小于 a(c)。
这不是“自然数层级 q 沿祖先单调”；q 可以上下变化。标签也不是计数序列。

一次带标签步骤首先必须是原生 Y 的真实 \(s\mapsto s[n]\)。
存活完整块均有旧来源及复制份数，这是 R 的既有结构闭包。
准许给这些副本选择新标签，但必须满足新状态的两项条件，且：

- 每个副本的新标签不大于来源块旧标签。
- 若活动末列是返回叶，或在封闭块根 c 作裸高1工作边界，则 c 的每个存活副本必须严格低于旧 a(c)。
- 私有 e 开启时，活动块不再封闭；其他块依上项搬运。

其他步骤没有额外的标签严格性要求。没有新生、无来源的封闭块。
不把单纯改标签算作一个 Y 步，也不声称对所有 n 都存在准许的新标签。
例如最小正标签1的返回块，可能连一次零指标截短尾巴都无法保留正而严格更小的标签。

把此关系记为 \(\longrightarrow_W\)。它的计数枝及标签选择都是关系的一部分。

## 最大标签及其开放尖端祖先栈

令 α 是当前所有块标签的最大值，无块时取0。
取普通底行祖先中的**开放第二尖端**，排除旧高1私有尖端和封闭块自己的私有尖端。
对恰带标签 α 的块，令 k 为该祖先栈长度的最大值；没有 α 块时取−1。

最大标签块不可能位于另一个封闭块的工作内，否则标签条件1会给出更大标签。
同根此前块也都较小。于是所有准许步骤满足：

\[
\alpha'\le\alpha;
\quad\text{若仍有旧标签 α，则其开放祖先栈只按完整副本搬运。}
\tag{4}
\]

说明分三类。

**外部普通或高步。** 私有枝及高1工作屏障阻止从完整块内部切开，
非开启的 C 核逐项交换给开放尖端栈运输。保留或复制的 α 块沿对应地址搬运整栈。
新标签降低只能移除 α 块，不会造出新的 α 块。

**工作边界或尾巴返回。** 活动块副本严格降标签。其被复制的工作和此前同根块列
均小于活动标签；若活动标签≤α，这些新旧部分都不产生 α 块。
其余 α 块在切点左侧，或在真正完整的未改变部分，栈不变。

**私有开启。** 活动块工作为空，连续块列保证新增开放结构只围绕此前同根块列。
那里所有标签严格小于活动标签。新第二尖端虽然能增加这些较小块的开放深度，
不会给仍存活的 α 块增加祖先。旧高1枝开启时，自己的整个块列及右侧工作已经消失，
新增部分纯 C。

所以固定 α 的类闭合，且其 k 不增加。这个论证不能拿自然数 q 替代序数标签。

## 端口归一化给真正较低的归纳参数

对一个开放第二尖端或封闭块根取完整工作森林，保留全部内部块及其标签，
按已验证的端口规则（未随本次收录的来源：`output/srpd-limit-y-lower-20261001/capped-root-returns.cjs`）归一化到根1。
直接入口均普通高1，故没有外部正父或高父，标签的同根次序也原样保留。

- 封闭块 c 的工作，只含小于 a(c) 的标签。
- 开放尖端在封闭块内时，同样不含全局最大 α。
- 其余开放尖端若仍含 α 块，归一化删去该尖端及其外部开放祖先，k 严格下降；
  若不含 α 块，则有限个剩余标签具有某个最大 β<α。

内部控制和删尾与归一化逐项交换；正指标切端口本身仍是独立的裸入口边界，不能假装内部交换。
将端口自身固定、禁止正指标切端口的受限秩记为 κ；空工作 κ=0。
它只在下一节已经取得较低归纳层良基性之后定义。

## 带标签过程的统一上界

**定理。** 满足上述背景假设时，对所有 α<Θ、所有最大标签≤α的有效状态，

\[
\boxed{\rho_W(s,a)<T_\alpha=b(\alpha+1).}
\tag{5}
\]

按 α 作超限归纳，再按该 α 块的最大开放深度 k 作自然数归纳。
没有块时使用 γ 界；若没有等于 α 的块，使用有限标签最大值 β<α 的已完成归纳。
其余情形的开放端口，由上一节落在严格较低的 α 或同 α 较低 k，故 κ 已知且小于 Tα。

对全部源前缀，第一尖端预算取：旧高1私有枝为 Λ，块 c 的私有第一尖端为
\(R_{a(c)}=b(a(c))\)，开放第一尖端为

\[
\sum_t\omega^{\kappa(F_t)}.
\tag{6}
\]

这里用完整端口，不用删去工作后的投影。每个预算都严格小于 Tα。
短前缀尚未显露私有 e 时，继续使用完整状态给的储备见证；不存在免费补回 e 的操作。

需核对的预算运输如下。

1. 开放端口的真实内部步骤是较低归纳类的一步，κ严格下降。
   仅降低非活动副本标签时，κ不增，理由见下一节的子项包含论证。
   此处只将该论证用于**已经完成归纳的较低端口类**，两边秩均已定义；
   不借用当前待证类的良基性。整类完成后，下一节再陈述其全局推论。
2. 裸入口边界把工作 F0 加末裸入口变成若干 F0 副本。
   端口门控排除了正切根，故旧 κ=κ(F0)+1；指数和严格支付任意有限复制。
3. 工作边界、返回尾巴使活动块副本的标签严格降低，故各私有预留严格降低。
   其他完整工作对象只复制或弱化标签，每份使用对应旧全词／部分前缀见证。
4. 活动标签为 ξ 的私有 e 开启，只显露含标签严格小于 ξ 的有限端口。
   其最大标签 β<ξ，由已完成归纳，κ<Tβ≤Rξ。
   Rξ为ε数，所有新的有限指数和也严格小于原预留 Rξ。
5. 旧高1私有枝开启仍由 Λ支付纯 C 部分。
   非一致高步只能控制开放第二尖端，其末工作为空，预算由 δ+1降为早份的δ；
   不把闭合预留冒充后继数。

完整份、部分份、外部根及保留前缀仍按[一般 owner 接口](../y-general-owner-interface-20260927/GENERAL-GRADE-INTERFACE.zh-CN.md)
使用各自旧表。私有开启和工作边界的低行接缝采用
[闭根工作证明](ROOT-WORK-ORDINAL-BOUND.zh-CN.md)的标记／未标记两种计算。
新增尾巴返回也是普通行1切 r：标记末叶的行1需求为2，剩余1行支付新 r 到前份 c 的低边；
未标记末叶用原 Q 储备。其他块内关系同份继承，不需要新高控制容量。

因此，初态全部有限前缀预算的最大值 D<Tα可固定一次，取
\(Q=\omega^{D+2}<T_\alpha\)，初始化旧的正极限 owner 等级和普通 Q 行主图。
上述运输保持同一 Q，且每个准许步骤花费非空有限主图下降。
由普通森林闭包，初始主图秩<Tα，得到 (5)。
这是同时证明当前带标签类良基和其上界；没有事先使用当前类的 κ。

取式 (2) 的实际背景，所有标签<θω的状态均有

\[
\rho_W(s,a)<\theta_\omega<\rho(I_{29}).
\tag{7}
\]

同一个 I29 只承载**准许的带标签关系**。其某个状态缺少未加标签 Y 的子项时，
式 (7) 并不能给未加标签状态的全部下降秩上界。

## 降低标签不会增加工作秩

在同一未加标签状态上，设两个有效标签表 \(a'\le a\) 逐列比较。
从 a′ 出发的每个准许子项，也直接是从 a 出发的准许子项：
副本标签≤a′来源≤a来源，活动块严格不等式也保留，目标有效性不变。
因此在上述已经良基的关系中，由秩的子项上确界定义，

\[
\rho_W(s,a')\le\rho_W(s,a),\qquad
\kappa(F,a')\le\kappa(F,a).
\tag{8}
\]

这不是给源过程添加免费改标签步骤；它只是给同图两套有效证书比较上界。
门控条件仅取决于原控制位置，所以对子项集合包含的论证不变。

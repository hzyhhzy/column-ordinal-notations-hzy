## 1 两个控制点的条件

源为完整实际一致化图 V(G)，目标满足严格双辅助覆盖。
固定保留的正高度普通根 c，高度为 \(h_c\)。沿用
\[
E_c=\min_{c\in O(j),\ r\ge h_c}\bigl(A(j,r)-r\bigr)+h_c-1.
\]
空边集取无穷。锚为 \(g_0<\cdots<g_L<Q\)。

主门选择 \(g=g_s\)，满足 \(|O(c)|\le s<L\)、统一储备 \(a_s\ge2\)，以及
\(E_c\ge g\)。在两个相邻锚之间另选物理控制点 b，满足
\[
g_s<b<g_{s+1},\qquad
\operatorname{Cap}(b,p_j)=\operatorname{Cap}(b,p_j+1)
=\operatorname{Cap}(b,p_j+2)=\beta\ge2
\tag{1}
\]
对所有源代表及其两个辅助列成立。还要求每条 c 拥有体的被检查普通边满足 A>b。
特别地，\(E_c\ge b\) 足以保证这个严格不等式。

b 不必是锚，容量也不是任意指定的参数，必须从同一个实际目标中测得。
接口允许实际高控制根 d=c 或 \(c\in O(d)\)，包括第一和第二尖端。

## 2 任意指标的一次准备

给定高指标 n>0 和希望保留的余量 K≥1。记新源最高高度为 H′。
先把两个字面工作辅助列通过真实 [3] 增至四个。这个操作只作用于工作代表之后。
两个准备操作各消耗一个辅助列，最后恰留下两个；不能把重复制造辅助列当成免费操作。

第一个准备在 b 处暴露最大行 β，再取 [t]，t≥1。
若当前复制跨度为 S，则记 \(\delta_B=tS\)。所有源代表、Q 和 b 之后的锚
选择最后一个完整副本。主门 g 在切点外部，不平移，储备仍为 \(a_s\)。
旧 b 保留在前缀中，它到新区的容量变为 β−1；最后一个 b 副本则保留 β。

所有 c 拥有体旧容量都大于 b，故增加 \(\delta_B\)，行号不变，
从而 \(E_c\) 增加至少 \(\delta_B\)。原分级覆盖也保持：需跟随右侧锚平移的
旧需求已经严格大于 b，其他需求没有增加；高储备 Q 同量平移。

第二个准备在原主门 g 处以最大行 \(a_s\) 插入 n 个 owner 层，随后执行原始高步骤
并恢复完整实际 V。这里选第二个准备的最右主门副本，不选损失一行的中间副本。
记最终主门为 \(g'=g+\Lambda\)，其中 Λ 包括随后高准备引起的主门平移。
旧 b 的对应控制点为 \(b'=b+\Lambda\)。由前稿高步骤的绝对余量公式，
\[
E_c'\ge
\min\bigl(E_c+\delta_B+\Lambda-n,
Q+\delta_B+\Lambda-H'+h_c-1\bigr).
\tag{2}
\]
更内侧的准备可能额外增加容量及 Q，因此这里使用下界而非全部相等式。

只要选取 t，使
\[
\delta_B\ge
\max\{0,\ b+K+n-E_c,\ b+K+H'-h_c+1-Q\},
\tag{3}
\]
便有
\[
E_c'\ge b'+K>g',\qquad a'_{s+n}\ge a_s,
\qquad \beta'\ge\beta-1.
\tag{4}
\]
空边集时删去式 (3) 中含 E 的项。复制跨度为正，故任意有限 n、K 都能用有限 t 支付。
输出 b′ 仍在新主门与下一锚之间，且对所有代表及辅助列的容量统一。
其后任意长普通展开和删列阶段保留 E 的下界；保留根 c 时，主门强证书也保持。

这是paired-root-preparation.cjs（未随本次收录的来源：`output/srpd-limit-y-lower-20261001/paired-root-preparation.cjs`）的接口。
主门只需两行，不再要求三行；损耗转移到独立的补充控制点。
它本身不意味着补充点永远可用。

## 3 保留一份不花掉的控制点

第一准备还留下一个可记录但暂不使用的控制点：b 的最后副本。
经过第二准备和高步骤后，它的位置为
\[
\widehat b=b+\delta_B+\Lambda=b'+\delta_B,
\qquad \widehat\beta\ge\beta.
\tag{5}
\]
它仍位于主门与下一锚之间，并对所有源代表和辅助列具有统一容量。
与 b′ 不同，它没有在本次准备中损失一行。

为什么不立刻改用它，宣称无损续接？因为式 (2) 对整个新源只给出
\[
E_c'-\widehat b\ge
\min\bigl(E_c-b-n,\ Q-H'+h_c-1-b\bigr).
\tag{6}
\]
增加 \(\delta_B\) 不会改善这个下界，平移在相减时抵消。
新行可能使全体拥有边不能由这个较靠右的控制点支付。
保留容量 β 和取得任意大新余量，是两种不同的用途，不能同时免费获得。

## 4 返回旧前缀后的恢复定理

在调用前进一步要求 \(E_c\ge b\)。记调用前源为 P 后接工作列 x，
其中 P 是删掉 x 的原有前缀。高展开保留 P，再追加新列。
所有 P 中的源父边及行号原样保留。对应的目标旧边容量增加至少
\(\delta_B+\Lambda\)，所以仅限于 P 的拥有体边有
\[
E_{c,P}'\ge\widehat b+(E_c-b).
\tag{7}
\]
这一步没有式 (2) 的 −n，因为 P 中没有新升高的源行。

把 \(\widehat b\)、旧前缀 P、下界 β 和余量 \(E_c-b\) 记录为一份暂停的凭据。
处理追加后缀时不以 \(\widehat b\) 为切点。所有新两控制点准备仍使用当前主门
和更靠左的活动补充点。对于任一这种准备，若物理切点在 \(\widehat b\) 左侧，
凭据和受保护边一起放在最后副本：边容量严格超过切点，故取得相同平移；
若切点在它右侧，凭据不动，所需旧容量不下降。
主展开和普通展开只改变最后列，未删除的 P 保持不变。
于是式 (7) 沿整个尚未返回的历史保持，暂停容量不损失。

各暂停点的顺序也保持。一次新调用产生的活动点在新暂停点左侧；
旧暂停点位于新暂停点右侧。它们都在当前主门和下一锚之间，
所以高准备的锚切点不会落在这段内部，也不会意外花掉暂停点。
内部容量运输可能增大暂停容量，不需要把它强行固定为一个不变数。

当源宽缩到 \(|P|\) 或以下，且根 c 仍保留时，当前源已经是受保护旧前缀的一个前缀。
所有当前 c 拥有体边都受式 (7) 约束。此时可以恢复
\[
b_{\mathrm{active}}:=\widehat b,\qquad
\beta_{\mathrm{active}}\ge\beta,\qquad E_c\ge b_{\mathrm{active}}.
\tag{8}
\]
这是沿原目标实际下降得到的恢复，不是重新选择初始目标，也没有给容量重新赋值。
根 c 被删去时本接口结束，不能把本结论当成对更早根的自动证明。

实现及断言见paired-passive-reserve.cjs（未随本次收录的来源：`output/srpd-limit-y-lower-20261001/paired-passive-reserve.cjs`）。
其中保护的是原生源父表前缀，恢复前检查所有追加列确已消失；
不是看到另一个高尖端就提前恢复。

## 5 可以按尚未返回的调用深度记账

每次正高展开建立一个调用帧，保护展开前去掉工作列的前缀。
等源返回该前缀或其更短前缀时关闭此帧。只改末列的性质保证这些帧按嵌套顺序关闭。
这不是 owner 深度，也不是累计展开次数。

考虑一段保留 c 的历史，所有正高控制根均为 c 或被 c 拥有。
若开始时满足两控制点条件、\(E_c\ge b\)，初始 β≥m+1，且同时未返回的高调用
始终不超过 m 层，那么两控制点策略可以支付这段历史的任意有限前缀。
各高指标与普通阶段长度均不受这个结论的固定数值限制。

证明按调用栈归纳。入栈一次，当前活动补充容量最多损失1，并留下未损耗的暂停凭据。
栈深小于 m 时，活动容量至少为2，足以进行下一次高调用。
最深层允许活动容量为1，因为普通步骤和返回本身不要求再次支付高准备。
出栈时用式 (8) 恢复入栈前的容量下界。主门储备全程至少为原来的2行。
因此总调用次数可以任意大，只要未返回的嵌套深度满足条件。

这比按每个高调用永久扣一行更强，但仍是条件性覆盖定理。
目前没有证明 B 的全部合法后代具有这样的固定深度上界，也没有证明可以按 B[n]
取得足够的深度预算。旧的 owner 无界深度结果针对另一种深度，不能拿来冒充这里的反例。
对不属于 c 拥有区的高控制，以及根 c 被删除后的区域切换，也还需要接续论证。

后续[无界调用深度稿](UNBOUNDED-HIGH-CALLS-AND-GLOBAL-REACTIVATION.zh-CN.md)已经证明：
即使固定在 B[1] 以下，此调用深度也没有统一有限上界。因此不能再把取得这种固定上界
列为尚有希望直接补齐的前提；本节的条件性定理仍有效。后续稿同时给出按当前全域余量
提前重新启用暂停点的接口，不要求源已经返回。

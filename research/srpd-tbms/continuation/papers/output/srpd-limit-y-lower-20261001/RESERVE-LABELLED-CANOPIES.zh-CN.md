## 标签条件覆盖整个头树

源状态继承 H 的全部条件：规范原 Y 父表、永久标记、私有三列、
严格零星条件、同根连续块列，以及每个节点的头孩子先于高1尾部工作。
完整块 c 的父仍为 \((r,r)\)；本块头 h 的父为 \((p,r)\)，其中 p 是 c 或同块头。

给每个完整块 c 一个正序数标签 \(a(c)<\Theta\)，要求它严格大于：

1. c 的整个底行后代区域中所有其他完整块的标签。
2. 同 r 的此前块列的最后标签。

第一项包括所有深度的头孩子、它们的完整工作和 c 自己的尾部工作。
不能只给 c 的直接尾部工作加条件。同根此前块列再用第一项，得到其中全部嵌套标签也较小。
定义所用的有限依赖图无环：进入完整身体时严格进入子树，同一块列的依赖则向左；
身体内的此前同根块仍留在该身体内，不能靠这项依赖返回外层。

一步 \(W_H\) 首先必须是实际原 Y 步骤。所有存活块副本的新标签不大于旧来源标签；
若末列是任意层的空头，或正好在 c 处作裸高1工作边界，则活动 c 的全部存活副本严格降标签。
私有开启撤去活动 c 的封闭身份。单纯重赋标签不算步骤。
裸头工作边界不额外要求所属 c 降标签。

这些是受限关系的定义，不是已经证明每个原子项都能取得标签。
最小整数标签1的空头状态在某些真实子项上没有更小的正标签，有限检查明确保留这种拒绝。

## 最大标签的开放祖先栈

只计开放第二尖端，排除旧高1私有尖端和各完整块的私有第二尖端。
对恰带最大标签 α 的块 c，记其严格底行祖先中的开放尖端栈为 E(c)，
取这些栈的最大长度 k。没有块时 α=0；没有等于给定 α 的块时另用较小最大值。

最大 α 块不可能在另一个完整块的后代里，包括任何头的身体：
否则那个完整块必须有更大标签。因此任意头内部或裸头工作边界中被复制的内部块，
都小于该头所属块的标签，不能成为新的全局最大块。

空头返回的活动 c 副本严格降标签。
复制区的此前同根块列及其工作也都严格低于旧 a(c)。
新高1保护根接在该头的底父 p 上；p即使也是头，仍是普通列，不是新增开放第二尖端。
其他最大 α 块只完整运输旧栈。
私有开启则和旧证明一样，只给此前较小块加开放祖先。

外部普通或高步完整搬运所有仍封闭对象；高1入口及私有屏障禁止把内部的一半当成完整外部对象。
所以

\[
\alpha'\le\alpha,\qquad
E'(\phi(c))=\phi(E(c))
\quad\text{对每个仍保留旧标签 α 的副本成立。}
\tag{2}
\]

特别是仍有旧最大值时 k不增加。这里不限制头的本地深度，也不把头数当作下降量。

## 必须区分头的尾部工作与整片头子树

对块 c 或头 v，只取其头孩子之后的**完整高1尾部工作** F，
以标记根1替换端口并平移内部数值，所有内部私有块与标记保留。
这个 F 的所有直接入口均高1，故其正父及高父不越过端口。
归一化后的原 Y 父图与原表重编号一致，内部原步骤与之交换。

这里不把含高2头孩子的整片子树误当成单端口工作：
那片子树还引用外部 r，不满足这个归一化前提。

块工作或头工作端口中的所有块标签都严格小于该头所属的 c 标签。
开放第二尖端的完整端口若在某个封闭块内，同样不含全局最大 α。
若它在封闭块外并仍含 α，归一化删去自身及外部开放祖先，所以其 k严格下降。
这正是旧背景归纳需要的两种严格来源。

记这些完整端口的门控秩为 κ，固定根且禁止正切根。
只有在下一节已完成较低归纳参数之后才取该秩，不调用未知的完整 H 秩。

## 背景上界的归纳

采用[旧背景定理](RESERVE-LABELLED-BACKGROUND.zh-CN.md)的同一假设。
Θ为极限，\(b_0\) 正规，对所有 \(\xi<\Theta\) 有

\[
\gamma<b_0(\xi)<\Theta,\qquad
\omega^{b_0(\xi)}=b_0(\xi),
\]

且有限普通行森林只要全部行高小于 \(b_0(\xi)\)，其秩也严格小于这个值。
无完整块时没有任何 H 头，仍由旧无块类的 γ 界处理。

对最大标签 α，再对其开放深度 k归纳。
上一节保证所有需要取完整门控秩的端口，落在较小 α或同 α较小 k。
赋予旧高1私有枝预算 Λ，块 c 的私有第一尖端预算 \(b_0(a(c))\)，
开放第一尖端预算取各完整第二尖端工作之
\(\sum\omega^{\kappa(F)}\)。
这些值全小于 \(b_0(\alpha+1)\)。

新增几何并不增加新的高父种类，所需运输分支为：

- 内部工作步骤严格降低已经定义的 κ；副本标签弱化只使 κ不增。
- 裸高1工作边界仍把 \(\omega^{\tau+1}\) 换成有限份 \(\omega^\tau\)。
  对头端口，整个既有头孩子区原样复制，低行接缝继承该头父表。
- 空头返回是普通行1切 r。活动 c 的私有预留随标签严格降低。
  原证明中“新 r 接 c”改为“新 r 接普通底父 p”：
  标记末头的行1需求2留下1行，恰支付这个底边；
  p并非高尖端，不产生新的高父容量义务。未标记末头仍用旧固定 Q 储备。
- 活动标签 ξ的私有开启，只暴露标签最大值 β<ξ的有限工作。
  较低归纳给 \(\kappa<b_0(\beta+1)\le b_0(\xi)\)，ε闭包支付全部有限指数和。
- 其余普通、高父、完整份、部分份和短前缀继续使用
  [全前缀 owner 接口](../y-general-owner-interface-20260927/GENERAL-GRADE-INTERFACE.zh-CN.md)。
  短前缀尚未显露私有叶时使用原完整状态储备，不能免费补回叶。

因此初态全部有限前缀的预算最大值 \(D_0<b_0(\alpha+1)\) 可固定一次，
取 \(Q=\omega^{D_0+2}<b_0(\alpha+1)\)。
每个准许步骤由同一普通主图的非空有限下降承担，得到式 (1)并同时证明该受限关系良基。
证明不依赖头本地深度的上界。

同图有效标签 \(a'\le a\) 时，从 a′准许的子项也是从 a准许的子项，
故已完成关系的门控秩随标签弱化不增。
在归纳过程中只对已经完成的较低端口使用这项包含论证。

取旧定理已实现的 \(\Theta=\theta_\omega\) 及相同 \(b_0\)，可得

\[
a(c)<\theta_\omega\ \forall c
\quad\Longrightarrow\quad
\rho_{W_H}(s,a)<\theta_\omega<\rho(I_{29}).
\tag{3}
\]

这是任意有限头树的受限带标签上界，**不是所有 H 状态的原 Y 上界**。

## 每一次选中头正返回都会使删边投影增长

沿用分层稿的 \(H_d\) 与 \(\pi_d\)，选中头是本地层数恰为 d的头。
若末列 x是选中头，父表为 \((p,r)\)，则对任意 n≥1，

\[
\boxed{\pi_d(s)\text{ 是 }\pi_d(s[n])\text{ 的真前缀，包括永久标记。}}
\tag{4}
\]

证明直接看第一接缝。所有 x左侧的列不变；旧投影第 x列的父表为(p)。
原行1返回产生的新 r恰在 x位置，底父也是 p，且继承旧末头标记。
因此投影后的这一列也相同。其后追加 \(n(x-r)-1>0\) 列，
因为 r、私有块和末头之间的跨度大于1。
再作对应次数的实际 [0]，恰回到旧投影。

所以原分层投影不仅“有时不下降”，而是在它排除的每个正返回边界都严格增秩。
这不否定原 Y 良序，只说明投影丢掉的第二条边承担了真实的返回费用。

## 外层选中权重不变而投影工作增大的标准例

写 W=(1,3,4,2,5,8,10,4,9,14,16)，
令 \(P=Y(W,6,8,8)\)，标准路径为 S9[2] 后作两次真实同宽 D。
取

\[
Q=P[2],\qquad Q'=Q[1].
\tag{5}
\]

Q和Q′都在 H1，全局选中头嵌套均为0。
第一个完整块 c的较浅直接头 v处于层0；
它仍有且只有一个属于本 c的选中头，身体为空。
在 Q到Q′之间这个选中头及其空身体完全不变，故常见候选权重

\[
\beta(c)=\sum_{\substack{h\text{ 属于本 }c\\h\text{ 选中}}}
               \omega^{\kappa_Y(F_h)}
\]

在两边都等于1。

但实际活动的选中头位于 v的高1尾部工作中，属于内层另一个完整块。
这一步在该工作端口内发生。归一化这片完整工作后应用式 (4)，
得到它的删边投影严格增长，旧投影还是新投影的真前缀。
这里的投影在 H0，故其完整秩已由旧 D证明定义且有上界；没有使用未知 H1秩。

这排除了如下直接补法：只用本 c选中头的权重控制新边界，
再用较浅投影的秩度量其余工作。内层返回时，前者完全不动，后者却增长。
一个新证书必须同时处理外层未选中头的完整工作，不只是提高 \(\beta(c)\) 的取值范围。

## 仍未完成的完整提升

式 (1)允许使用整个带标签 H工作秩作为非循环的辅助资源，
不必再把不下降的未加标签投影秩当作工作预算。
但还须构造一套源证书，使任意原子项都能被提升为准许的 \(W_H\) 步骤。
目前没有完成这项构造。

一个有待解决的具体冲突是：
空头返回删去一个头，却把此前整段上下文接入较浅父头的工作；
裸头工作边界则复制整个头子树，子树中的头数可能增加。
只按裸树形计复杂度处理不了后一种边界，
只按较浅投影秩计工作又被式 (5)排除。
旧闭包资源虽足够大，也不能代替这项源证书。

故不能从式 (3)宣布 S9≤lim(SRPD)，更不能宣布主目标 B已完成。
也没有取得 U≤124842或它的反向比较。

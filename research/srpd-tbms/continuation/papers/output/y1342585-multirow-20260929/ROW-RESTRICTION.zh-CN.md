2026-09-29。**新的原规则分解引理及一个反例，不是等值式证明。**

当前目标仍是找到标准 SRPD 项 S，使 ρ(S)=ρY(1342585)。
上一稿证明固定第一步后未打开芽的根高度有界，却不能将已打开块视为不透明叶子。
本稿在 SRPD 一侧作对应的准备：把低行接口与高行图分开，说明后者到底怎样受前者影响。

这里“限制”只是删行删列的图操作，**不是序数商，也不是保序映射**。
下文给出的标准项反例明确说明它不保下降。

## 1. 原规则、坐标及适用范围

使用当前隐含根版 SRPD：C₀=[]，可见列为 C₁,…,C_N，行从0编号。
记原基本列为 FS_n。若末列为空，或 n=0，删末列。
否则设末列长度 H>0、最后父项 p、跨度 ℓ=N−p；一次完整复制的步骤是：

1. 先取得 C_{p+1},…,C_N 的反射副本；父地址 q≥p 时改成 q+ℓ。
2. 对长度大于 p 的副本，在第 p 行前插入 ℓ 个同值行。
3. 把旧末列改成接缝

   C_N[0:H−1] ⌢ C_p[H−1: ]。

4. 接上这些副本。

重复 n 次，每次相应移动控制父；最后删去最终末列。这就是发布版 JS 的算法。
当前合法性条件为 h−1≤父<子，不额外假设所有原始父表都标准。

固定整数 d≥0，并冻结前 d 列。在当前活动后缀非空时，定义

\[
\pi_d(C_1\ldots C_N)
 =\bigl(C_{d+j}[d:] -d\bigr)_{j=1}^{N-d}.
\tag{1}
\]

即：删前 d 列，删每个余列的前 d 行，剩余父地址统一减 d。
原第 d 列对应新的隐含根0。由于 C_d 的高度≤d，它的高行部分确为空。
原合法性 h−1≤父也立即给新合法性 (h−d)−1≤父−d。

本稿每个正步骤要求真实切点 p≥d，因而没有复制越过冻结前缀。
若活动末列被删空至只剩冻结前缀，便停止这个相对系统；不继续假装 π_d 对更短词有定义。

## 2. 高行内步完全交换

**引理一。** 如果 H>d，且 n>0，则

\[
\pi_d(FS_n(g))=FS_n(\pi_d(g)).
\tag{2}
\]

此时原控制行为 H−1≥d，而新控制行为 H−d−1。
新切点 a=p−d≥0；前后的跨度相同：

\[
(N-d)-(p-d)=N-p=\ell.
\]

证明只须检查反射和接缝。父地址搬运满足

\[
(q\ge p? q+\ell:q)-d
=\bigl(q-d\ge p-d? q-d+\ell:q-d\bigr).
\]

由于 p≥d，第 p 行插入在删去低行后恰变成第 p−d 行插入；
判定 |C|>p 也恰变成 |C[d:]|>p−d。
接缝则有

\[
\bigl(C_N[:H-1]\frown C_p[H-1:]\bigr)[d:]
=C_N[d:H-1]\frown C_p[H-1:],
\]

就是限制后长度 H−d 的原接缝。复制及最终删除均交换，归纳于 n 即得 (2)。
没有改变指标，也没有用“存在某个更强目标”替代真实一步。

## 3. 低行步不是高图的普通基本列：它是精确的别名回调

现在 0<H≤d、n>0、p≥d。限制后的最后一列为空，但原最后一列仍是正控制。
所以不能按空列后继规则将其删除。

设 q=π_d(g)、a=p−d。定义操作 A_{a,n}(q)，其输入末列必须为空：

1. 跨度仍取 ℓ=|q|−a。
2. 按原 SRPD 反射规则，复制 q 中 a 后面的全部列；**复制前**末列仍为空。
3. 将旧末空列换成第 a 列的完整内容；a=0 时换成隐含空根。
4. 接上副本。副本的末列仍为空，可供下一次回调。
5. 重复 n 次，控制父随副本向右移 ℓ，最后删掉最后的空列。

**引理二。** 对上述真实低行步骤，

\[
\boxed{\pi_d(FS_n(g))=A_{p-d,n}(\pi_d(g)).}\tag{3}
\]

证明：反射与行限制仍按 §2 交换；唯一不同是接缝。
因为 H−1<d，旧末列的低行部分全部被删除，而继承的父列恰留下

\[
\bigl(C_N[:H-1]\frown C_p[H-1:]\bigr)[d:]=C_p[d:].
\]

这正是步骤3。原低控制长度 H≤d≤p，所以它的副本不在 p 行处插行，
限制后仍为空，故每次迭代都满足相同条件。最终删列也交换。

特别要保留两件事：

- 高接缝可以**非空**，不能一律写成空列。
- a=0 仍可正复制，不等于删尾：它对应原切点正好在冻结边界 d。

因此，一个完整的高行计算器必须接收低行部分给出的“在 a 回调”指令。
只保存高图、丢掉低接口，无法知道空列究竟是后继，还是等待回调的控制。

## 4. 一个标准候选上的反例

继续记

\[
L=(1,2,4,8,4,1,2,9,38,4),\qquad J_k=(L,k),
\]

这里 J₅,…,J₁₂ 特指从已知标准项 U[0]=J₁₂ 连续同宽局部降低得到的父表，
不把计数相同的任意非标准原始父表混进来。
J₆ 的第11列是 [10,7]。取 d=6，原切点 p=7，限制切点 a=1。

真实一步为

```text
J6    = 1,2,4,8,4,1,2,9,38,4,6
J6[1] = 1,2,4,8,4,1,2,9,38,4,5,12,45,7
```

相应高行父表是

```text
π6(J6)    = [][1][2,2][][]
π6(J6[1]) = [][1][2,2][][][5][6,6,6,6,6,6][]
```

后者以整个前者为**真前缀**。在限制后的原 SRPD 中，对后者作三次 [0] 才回到前者。
反之，若错误地对前者直接作原 [1]，因为它末列为空，只会得到

```text
[][1][2,2][]
```

故 π₆ 甚至不保持这一个真实下降步骤的方向。若谈下降秩，在这些图良基的条件下，
前者高图的秩严格小于后者高图的秩；这一结论来自真实三次删尾，不依赖字典序猜测。

还有一个更直接的“不存在自治高图展开器”证据：π₆(J₅)=π₆(J₆)，但同作 [1] 后，
π₆(J₅[1]) 仍是原高图，而 π₆(J₆[1]) 变成上面的真扩展。
前者回调切点 a=4，后者 a=1。故不可能只用输入高图和指标 n 决定正确输出，
无论怎样更换高图自己的基本列函数都不行；必须带上低行提供的接口信息。

这**不是** J₆ 与 Y1342585 不等的反例，也不是旧尾4森林证明的反例。
它排除的是本轮考虑的捷径：把两边“高图”或“私有 β 秩”单独配对，低接口一概忽略。

## 5. 具体候选变得更容易读，但还不能按此给等号

限制 d=6 后，第一批候选如下：

| 原 SRPD 项 | 高行父表 | 高图自己的计数（不是原项计数） |
|---|---|---|
| J₅,…,J₁₁ | `[][1][2,2][][]` | `1,2,4,1,1` |
| J₁₂ | `[][1][2,2][][4]` | `1,2,4,1,2` |
| U[4] | `[][1][2,2][][4][5,5][6,6][7,7][8,8]` | `1,2,4,1,2,4,7,11,16` |

其中 U[4] 是既有严格上界

```text
1,2,4,8,4,1,2,9,38,4,12,42,135,382,965。
```

所以 J₁₂ 的确处在一个结构阈值：它是上述同宽局部降低链中，末控制首次仍出现在
第6行及以上的节点；J₅,…,J₁₁ 的末控制都被限制操作删掉。
但后面这些候选的高图相同，**不代表候选等值**：§3 的低行回调不同，且会改动高图。
同理，这个阈值本身不证明 J₁₂=Y1342585。

当前仍只有既有全节点界

\[
\rho(J_5)<\rho_Y(1342585)<\rho(U[4]).
\]

没有新增 X 与 J₆,…,J₁₂ 的全节点大小结论，也没有排除以 J₅ 开头的更长等值项。
下一步如果采用这个分解，需要比较**高行图＋可执行的低行回调**的联合系统；
不能在这个缺口上假定“相同高图便可免费替换”。

```text

D^11                       = 1,2,4,8,5
[1], D^6                   = 1,2,4,8,4,2
[1], D^4                   = 1,2,4,8,4,1,2,9,38,5
```

2026-09-26。针对整体 `M13 = TBMS ()(1^ε₀)` 的反向研究。

**这是结构不变量，不是序数赋值，也还不是新的通用 TBMS 上界。**
它不同于已失败的固定行来源分层，使用的是展开后当前的父图。

## 1. 定义

使用一基列号及一基行号。固定行 r，沿第 r 行父边从列 j 向左追溯，
直到首次遇到高度小于 r 的列。这个停止列记为 R_G(j,r)。
没有第 r 行的列自身就是该行的根。

父总向左，所以这个计算有限。在本文的 M 严格锥里，
若第 j 列有第 r 行，则根号至少为 r。

从 r₀=1 开始反复执行

\[
 b_i=R_G(j,r_i),\qquad r_{i+1}=b_i+1,
\]

直到 r_i 超过第 j 列高度。得到 j 的**对角根梯子**，记其长度为 d_G(j)。
全图的层数为

\[
 d(G)=\max_j d_G(j),\qquad d(\varnothing)=0.
\]

每次行号严格增加，所以梯子本身有限；但仅此并没有证明其沿全局展开有界。
以下证明实际需要的保持性。

## 2. 使用的父图性质

这里讨论实际标准 M 图及其反射中间图。其逐行父森林具有山脉兼容性：
若 c 是第 N 列第 h 行的父，则对 1≤r≤h，c 在第 r 行的祖先链上，因而

\[
 R_G(N,r)=R_G(c,r).
 \tag{1}
\]

这一性质不是任意非增整数表的语法结论。
它在对角初始图中直接成立；普通父表反射及拼接保持它。
M 额外插入的行只在切点 c 以上：这些行的父严格大于 c，全部位于复制块内部。
所以在复制块中将该首高行重复、将其后行一起平移，仍保持逐行父森林的嵌套。
在第 c 行与首高行的交界处使用原来的同一对嵌套森林；重复段内部森林完全相同。
由此逐步保持 (1)。

下面的根公式也给出逐行核查，而不是仅从来源标签猜测嵌套。

## 3. 一次反射的精确根公式

当前宽 N、末高 h、末父 c、跨度 L=N−c。暂时保留最后的临时控制列，
记完整反射图为 G⁺。旧 j>c 的副本位于 j+L。

复制行号折回原行号的函数为

\[
 f(r)=\begin{cases}
 r,&r\le c,\\
 c+1,&c<r\le N,\\
 r-L,&r>N.
 \end{cases}
 \tag{2}
\]

对副本中实际存在的第 r 行，置 `b=R_G(j,f(r))`。则

\[
 \boxed{
 R_{G^+}(j+L,r)=
 \begin{cases}
 b,&b<c,\\
 b+L,&b>c,\\
 c,&b=c\text{ 且 }r<h,\\
 N,&b=c\text{ 且 }r\ge h.
 \end{cases}}
 \tag{3}
\]

理由如下。

- 根在切点之前时，路径通过接缝后仍回到原根；接缝的低行使用 (1)，高行继承 C_c。
- 根严格在切点之后时，整个根及到根的路径内部复制，故根加 L。
- 根恰为 c 时，C_c 在该行缺项。若 r<h，接缝保留原末列低行，仍通到旧根 c。
  若 r≥h，接缝继承的父后缀在该行也缺项，所以接缝 N 成为新的根。
- r>c 的插入／平移区间，其原父和根都严格在 c 之后；故属于第二种情况。

## 4. 复制保持整条梯子长度

令 (3) 中的新根为 B。逐项检查 (2)–(3)，有

\[
 f(B+1)=b+1.
 \tag{4}
\]

尤其 b=c 时，不论新根为 c 还是 N，下一层都会折回旧行 c+1；
复制虽然插入许多相同行，梯子不会在它们中逐一停留。

从首行 `f(1)=1` 出发，对梯子逐级使用 (4)。终止条件也对应：
若原列高不超过 c，它没有插行；若原列高超过 c，新高度恰为原高加 L。
故

\[
 \boxed{d_{G^+}(j+L)=d_G(j)\qquad(j>c).}
 \tag{5}
\]

这是复制列的精确等式，不只是有界抽查中的最大值没有变。

## 5. 接缝不会把两个层数相加

接缝为 `C_N[:h−1] + C_c[h−1:]`。

若 `|C_c|≥h`，由 (1)，接缝在低于 h 的各行与 C_c 有相同的根，
高行则直接继承 C_c。因此其整条根梯子与 C_c 相同。

若 `|C_c|<h`，接缝只是把原末列截至 h−1 行。
保留行的根不变，梯子只能提前结束。

所以

\[
 \boxed{d_{G^+}(N)\le\max\{d_G(N),d_G(c)\}.}
 \tag{6}
\]

这一步是用父关系控制重新继承；若只记每行的原始来源，就看不到这个限制。

由 (5)、(6)，旧前缀不变，完整反射的全图层数不增加。
反射 n 轮后删临时末列，得到

\[
 \boxed{d(G[n])\le d(G).}
 \tag{7}
\]

指标 0 或空末列的删列也满足 (7)。同样的接缝论证说明有限局部降低、
截至已有行的宏均不增加全图最大层数；单独末列的层数可能因继承而增加，不能混淆。

初始对角族 `D_k=[][1][2]^2…[k]^k` 满足 d(D_k)=k。
其第一步保留的列高度至多 k−1，所以所有 D_k[n] 及后代还有

\[
 d(G)\le k-1.
\]

## 6. 截去根以下行时，梯子层数恰少一层

取一个首空根为 b 的第一行连通块。对块内非空列 j>b，
删掉前 b 列及前 b 行、父号减 b，得到高层图 U（即已有的 T_b 截取）。
高于 b 的父边全部内部闭合，故

\[
 R_U(j-b,r-b)=R_G(j,r)-b\qquad(r>b).
\]

源梯子的第一步恰是 `1 → b+1`。删去它以后，上式使剩下的梯子逐级对应：

\[
 \boxed{d_U(j-b)=d_G(j)-1.}
 \tag{8}
\]

源列高不超过 b 时，右边为 0，高层列为空，也符合 (8)。
这是一个真正递归的层次分解，而不只是给当前图随意标一个有限数。

不过高层不是自主系统：源的低控制会使 U 执行保留外部切点的辅助复制，
见精确分解（未随本次收录的来源：`output/tbms-e0mn-bridge-20260925/SRPD-BOUNDARY-FACTORIZATION.zh-CN.md`）。
所以不能只对 (8) 作形式归纳，就宣称对应的序数上界也随之成立。

最底层可以直接控制：若 d(G)≤1，则每列高度至多其第一行根号。
活动块中的控制父不早于该根，因而以后永远不插行；总高度有初始的有限上界。
有限行祖先覆盖遂将每个这样的有限图控制在某个有限行 TBMS 种子以下，进而严格低于 S₁。
由有限多个空列组成的 d=0 图则是有限后继链。

## 7. 对整体等号的意义与缺口

这提供了一个只依赖初始有限种子的、对任意未来指标都有效的有限层数。
它通过了先前“同来源再次插行”的反例：来源可以相同，当前父图的根梯子仍不增长。

但 d(G) 不是严格下降量；只知道它是有限数，不能推出小于某个指定 TBMS 序数。
尚须构造并证明一个有保持性的翻译，例如证明有固定函数 H，使适当的
有界根梯子类可由 `TBMS ()(1^τ_(H(d)))` 统一覆盖。
这只是一个有希望的充分条件，当前没有证明，也没有把它定为唯一技术路线。

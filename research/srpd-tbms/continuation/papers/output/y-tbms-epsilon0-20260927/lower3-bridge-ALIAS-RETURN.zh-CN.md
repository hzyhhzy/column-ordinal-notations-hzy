## 1. 条件与结论

设实际 Y 状态为固定前缀 A 加最后一个可牺牲列 x，满足：

1. 全部高边仅为第一提取层的平星，没有更高提取控制；无高边且有普通父的列使用原普通控制
   （终端对角值为 1），不是把任意非标准对角根误当成普通列；
2. 每个高尖端 v 都一致：若高父为 c，c 无高父、普通高度为 h，
   则 v 的普通父表恰为 `[c]^(h+1)`；
3. 任何正普通行 r≥1 的父列均无高父。

给定 A 内的一列 q，假定 q 是 x 的真实行 0 祖先。
则存在有限个真实 Y 基本列步，逐字固定 A，将末列 x 变成 q 的别名：
完整普通父表及高父与旧 q 完全相同。
若 q 是所需的低层一致高尖端，便恢复同一高根的真实 driver。
本引理不要求 q 紧邻 x，也不要求 q 与 x 之间没有其他高尖端或 data。

## 2. 唯一使用的局部宏

`D` 表示原 `[1]`，随后使用原 `[0]` 删除所有超过旧宽的尾列。
所有被删列都在 x 的右方，故 A 逐字不动。每次 D 至少包含一个真实步。

若 x 普通、高度 H>0，令 r=H−1，最高普通父为 p。
原普通 shell 的第一复制列具有：

- 行号小于 r 的父仍为旧 x 的父；
- 行号从 r 起的父以及高标记继承旧 p。

若 r≥1，则 p 无高边，新 x 仍普通。
若 r=0，则新 x 的完整父表和高标记恰为旧 p 的，亦即得到 p 的别名。
因此沿底链遇见高尖端时不会凭空假定它是普通列。

若 x 是一致高尖端，高父 c、普通表 `[c]^(h+1)`，
原高 shell 的第一复制列同样有普通表 `[c]^(h+1)`，但不再有高边。
这是将跨度任意的 shell 限制到第一新列；其余复制列经真实零步删去。
此公式不要求 c 与 x 相邻。它把一个高尖端的别名变为普通列，随后可继续沿底链返回。

旧前缀的条件不变，新末列或者仍普通，或者是某个旧一致高尖端的别名。
故以上两种情况可反复使用，且正行父无高的条件保持。

## 3. 有限终止，不使用未证的秩界

令 M 为初态 A、x 中最大的普通高度。每次普通 D 的高部来自某个固定旧父 p，
低部只保留旧 x 已有的行；一致高 D 的普通高度不变。因此过程中高度始终≤M。

把 x 的普通父表补到 M 项，缺行填 −1，并从行 0 向上作通常字典序比较。
父地址都在有限集合 `{−1,0,…,|A|−1}`。
普通 D 的首个变化在 r：旧值 p 变为 p 的第 r 行父（严格小于 p）或缺行 −1，
所以该有限向量严格下降。较低行不变，较高行允许任意恢复，并不影响这个比较。
一致高 D 不改普通父向量，但把高标记从“有”变成“无”。
故再以这个布尔标记作为次关键字，每次 D 都严格下降一个有限全序。
这也解释了为何“高度单调下降”不是必要条件：复制旧父时普通高度可以上升。

在停止之前，q 一直是末列的底祖先：正行普通 D 不改底父；
行 0 普通 D 将 x 变成其旧底父 p 的别名；一致高 D 不改底父。
如果 p=q，立即停止，不再操作这个 q 别名。
否则底链上 q 仍在。有限严格下降不能一直继续，也不能在 q 尚未到达时落到无底父状态，
故必定有限停止于 q 的别名。

特别地，多带 scratch 从较高 u_l 向较低 u_k 返回时，可以经过多个一致高尖端；
遇到每个 u_l 时应用上述高 D，再继续普通 D。所有非 scratch 代表一直留在 A 内。

## 1. 序数槽分裂引理通过

设 λ 末 CNF 指数 δ≥β+2，λ=ξ+ω^δ·k，k为正有限整数。
对任意 η<λ，可取 η′ 满足 `max(η,ξ+ω^δ·(k−1))≤η′<λ`，
再令 `A_i=η′+ω^(β+1)·(i+1)`。因为 β+1<δ，对每个有限 i 均有 A_i<λ；
其末指数恰为 β+1，且 A_i 是极限。严格相邻槽之间也容纳任意有限偏移。
这没有改变真实目标，只产生更弱见证，随后仍须支付原生目标步骤。

建议主稿明确“所有旧外层等级”仅指 **E=O(c) 的旧全词等级**。
取 η 大于这个有限集即可；不应解释为所有位于切点左方但与 c 无关的标记根等级。
当前不变量只要求同一 owner 栈递增，并不保证所有不相关根也按地址递增。
新 owner 公式只加入 E 与本控制根副本，因此无需后一种更强要求。

## 2. 永久标记与最高 Q 储备

普通第 r 行的真正组件根恰有普通高度 r。沿任一真实第 r 行父链左行，
停止点 q 满足 h_q=r，因此永久根标记应包含 q。
普通复制首列只有低于控制行 r 的父改变；其高度仍为旧切点高度。
新组件根若不是旧组件根的副本，只可能是高复制新首根，它又是旧已标记高根的副本。
因此继承标记足够，无需每步把后来观测的根“补标”。

普通控制切点 c 满足 h_c≥r。若 c 未标记，则 h_c=r 不可能，故 h_c>r。
于是其最高普通行 h_c−1≥r，不在首列改造的 u<r 区间内。
这正好证明未标记新首列的 Q 最高接口从旧 c 保留。
若 c 是高尖端，窄类禁止正普通行引用它，所以控制行只能 r=0，
没有需要改接的低行，旧高 Q 接口也保留。

高步的新首根继承 c 的标记，故新增行只需要普通需求，不需要无来源的 Q 储备。
其他未标记列的最高普通父在插行前后是同一个旧最高父的同份像；
最高行即使被重复，旧 Q 路径仍可承担其中每条重复需求。

## 3. 普通接缝的合格 owner 相等

设旧末列 x 最高行为 r，父为 c，u<r。则

\[
\{a\in O(c):h_a\le u\}=\{a\in O(x):h_a\le u\}.\tag{1}
\]

正向：c 是 x 的第 r 行祖先，也是其底行及第 h_a 行祖先；
旧 owner 尖端见证通过 c 继续到 x。
反向：h_a≤u<r≤h_c；第 h_a 行的根检测不能在 c 右方先终止再越过它。
底行尖端见证若位于 c 与 x 之间，则其正行父结构、r 行祖先细化和星带条件
迫使 c 已位于同一 owner 区域；这也可逐星沿原父表核对。
切点本身若是该高尖端，则只能 r=0，与 u<r 不相容。

普通复制不改变相关高度，因此新首列低行的需求恰为旧全词 x 的低行需求。
主稿的 `γ+1+(r−h)` 编码使最高需求为后继：同 owner 的低行有限偏移至少少1；
不同 owner 时，外层极限等级加有限数严格小于内层等级。
故已标记控制的 `q=g(x,r)` 确能提供全部低行 `≤q−1` 需求。

## 4. 非一致高步的完整 owner 插入

令 c 的高度 h，末控制 x 是颜色2尖端，底父为颜色1尖端 u；写 E=O(c)。
对上升列 j（除新首根外），旧 owner 栈可写 `E⌢B_j`，输出第 b 份满足

\[
 O'(j_b)=E\frown(c_0,\ldots,c_{b-1})\frown\phi_b(B_j).\tag{2}
\]

新首根的底链先经过前份的 u，再到 c；u 是颜色1尖端，所以跨份链只新增
相应控制根 c_i，不会经过别的早份第一尖端。第 h+i 行的真正根恰为 c_i，
给出这些新 owner 的检测关系和高度 h+i。内部原 owner 由同份复制保留。
普通父行的细化与星带条件排除其他早份星成为新增 owner。
不上升列的 owner 栈则只按同份地址运输。

因此早份控制根槽 A_i 应插在 E 之上、当前 c_b 的旧局部 Γ_j(c) 之下。
由于 `A_i<Γ_w(c)≤Γ_j(c)`，其顺序正确。旧内层 owner 位于 c 后方，
使用同一个 Γ_j 表，本来就严格高于 Γ_j(c)，不会被新槽挤出顺序。
外部 owner 使用较弱的 Γ_w，而当前部分份内部使用 Γ_j，亦不破坏这个关系。

## 5. 第 h 行重复与更高行同步上升

对不是同根高尖端的普通上升 body，旧 owner 栈含 c。
旧第 h 行需要 `Γ_j(c)+1`。复制后：

- 新行 h+i，0≤i<b，选到新早份 owner c_i，需求为 A_i+1；
- 新行 h+b 选到当前 c_b，需求仍为 Γ_j(c)+1。

因此每条重复行均不超过该旧第 h 行的保证容量。
若还有额外有限偏移，A_i 是严格低于 Γ_w(c) 的极限槽，
`A_i+有限数<Γ_w(c)≤Γ_j(c)`，所以结论仍成立。
同根高尖端的普通行则直接由原 Q 高路径承担，不应只拿一个普通行保证。

旧 r>h 行变到 r+b。其选中的合格 owner 至少是 c，
该 owner 的检测高度也增加 b，所以 `r−h_owner` 保持。
内部高根与其尖端是否上升是同步的：较高普通父链细化第 h 行，
故一个进入上升区，另一个也进入。非上升列不可能拥有一个上升的内层根，
否则它也会经该根成为 c 的第 h 行后代。
这补足了“非上升列相关 owner 高度不变”所需的理由。

低于 h 的旧行只使用 E 中的 owner，其高度不变。
所以高步既没有把某个旧高需求无支付地增大，也没有漏掉新重复行。

## 6. 全部前缀表及初始化

当前部分份的源根 c_b 使用 Γ_j(c)，进入下一份成为早份时改用 A_b；
因 `A_b<Γ_w(c)≤Γ_j(c)`，该等级下降。
普通内部根从当前部分份 Γ_j 改成旧全词 Γ_w 也只下降。
保留旧前缀沿用原表，其进入复制区域后的外部根改为 Γ_w，同样只下降。
旧列 owner 集及其高度由左前缀决定，追加列不改变；因此等级不增也使已有普通需求不增。

初始化按标记根列序设置 `γ(c_i)=ω^(D+1)i`，给同一 owner 栈严格递增的极限等级；
其末指数 D+1 承担任意旧 α≤D 的要求 α+1。
`Q=ω^(D+2)` 大于全部这些等级加任意有限偏移。
有限个源列的普通需求均<Q，高接口需求=Q，故同宽完整 Q 行链足够。
这一部分没有发现 owner 或标记层面的初始化缺口。
从 E 实际取得这条链仍应引用原 TBMS 的 CNF 行标签下降与初始化原语，
不能只凭行序数大小声称真实可达；该原生义务由目标侧审计负责。

## 7. k=1 固定 ω 锚稿

在一致高类中，跨份新首根底父是前份 c，绕过早份尖端；
因此不存在 (2) 中的新 owner 链，整个 owner 栈只按同份运输，其层号不变。
旧边界行 h 原需 `ω(ell+1)`；复制后的前 b 行只能选外层 owner，严格低于此锚；
最后一行重新选到 c_b，仍恰等于该锚。更高行与 owner 高度同步上升，编码不变。
这部分独立检查通过。

已标记普通控制若 G_x(r)=ωa 是极限，低行均落在至多前一个 ω 段，
有限偏移≤当前最大普通高度 H+1。选 `β=ω(a−1)+(H+2)` 能统一支付这些低行，
同时 `β+1<ωa` 保证暴露可用。a=1 时就是有限 β=H+2，不遗漏边界。
未标记或高控制以 Q 接口支付，新首根仍是已标记根，不产生额外 Q 义务。

所以该稿 §§4–5 的源端行序／标记论证通过。§3 原生容量语义和 §6 初始化实际路径
不在本报告的独立源码审计范围内，不能用本报告代替那两项。

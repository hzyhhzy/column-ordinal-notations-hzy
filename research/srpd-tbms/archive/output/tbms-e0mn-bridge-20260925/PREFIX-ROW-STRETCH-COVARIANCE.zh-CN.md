# 最新前缀副本的精确容量协变，以及温资源的稀疏保存

> 归档原稿（未逐篇翻译）：本版保留最终路线所用论证；历史旁引不作为本包依赖。当前有效结论及阅读顺序见[归档导读](../../README.zh-CN.md)；原稿状态不自动代表当前结论。


2026-09-27。此页证明一条全尺寸、全基本列指标的结构引理。
它补上“最新温副本不再是原图的字面副本”之后仍可保留何种接口的问题。

## 1. 定义与结论

列、行均从 1 开始。G 是宽 N 的严格嵌套 M 父表，末列非空，末行高 h，
末父 c，L=N−c。严格指每列父号非增，且对该列所有父号 p 都有
`列高≤p<列号`；嵌套指任一列的第 r+1 行祖先集合包含于第 r 行祖先集合。
Cap_G(p,j) 是 p 在 j 的逐行祖先链上出现的最大行号，不出现时为 0。

对整数 n≥0 定义

\[
\sigma_n(t)=\begin{cases}t,&t<c,\\t+nL,&t\ge c,\end{cases}
\qquad
f_n(q)=\begin{cases}q,&q\le c,\\q+nL,&q>c.\end{cases}
\]

注意两个阈值不相同：**地址 c 搬移，容量 c 不搬移**。
对任何旧前缀两点 `1≤p<j<N`，实际基本列 G[n] 满足

\[
\boxed{\operatorname{Cap}_{G[n]}(\sigma_n(p),\sigma_n(j))
=f_n(\operatorname{Cap}_G(p,j)).}\tag{1}
\]

这里不包括原末列 j=N；正步之后其最终临时副本已被删除。
n=0 时只是删末列，式 (1) 是原前缀不变。

## 2. 一次完整反射

首先 `Cap_G(p,j)≤p`：若 p 在第 r 行祖先链中，进入 p 的那条父边
所在列至少高 r，严格条件使其父号 p≥r。

使用[完整反射七类容量公式](FULL-REFLECTION-CAPACITY-INTERFACE.zh-CN.md)。
该公式的逐行路径证明只使用严格语法与祖先嵌套，不需要额外的原生最近父条件。
令 G⁺ 为一次反射但尚未删临时列的表，分五类：

1. `p<j<c`：两点不变，容量不变，而且旧容量 q≤p<c。
2. `p<j=c`：j 的代表变为旧末位置 N。严格外部到接缝公式给容量
   `Cap_G(p,c)`，仍有 q<c。
3. `p<c<j`：旧严格外部到新副本公式给原容量 q，而 q<c。
4. `p=c<j`：p 的代表为 N，新接缝到副本公式给原容量 q；q≤c。
5. `c<p<j`：同份内部副本公式恰给 `f_1(q)`。

这五类穷尽 p<j<N，得到一次式 (1)。其中 p=c 的边界不损一行：
使用的是**新接缝代表**，不是把旧 c 留在原地后要求其跨接缝连接。

## 3. 任意 n 及实际删除

完整反射保持严格与嵌套性。接缝高度是 `max(h−1,H_c)≤c−1`：保留的低父号
均≥c，高尾若非空则继承列 c 的父号并满足原来的高度界，拼接处父号仍非增。
内部副本若插行，原高度 H>c，其全部父号都≥H>c，因而高度及父号一起增加 L；
不插行的列仍满足原高度界。接缝第 h−1/h 行的嵌套由 c 属于旧末列所有低行
祖先链保证，内部插入段则重复第 c+1 行的森林。跨接缝的逐行路径仍由同一切点
的低祖先与高尾拼接；七类公式的逐行证明只用旧嵌套性，给出新的初始行区间，
没有预先假设输出嵌套性。原末列高 h≤c，所以其完整副本不插行，新的末父为 c+L，
跨度仍为 L。第 i 次反射前，切点、末地址分别为 c+iL、N+iL。

迭代地址搬运得到 σ_n。对于旧容量 q≤c，各步均不搬移；对于 q>c，
第 i 步前容量为 q+iL>c+iL，每步增加 L。因此复合的行变换恰为 f_n。
每个旧 j<N 都有 σ_n(j)<N+nL，故最终删除临时末列不删任何选定代表，
也不影响这些代表的祖先链。这证明 (1)。

此证明既不要求 j 的父列逐字搬运到 σ_n(j)，也不要求 σ_n(1) 仍是空列。
前者可能由于接缝继承失败，后者也可能由于旧根变成接缝而失败；
两者均不妨碍容量等式。

## 4. 全对稀疏覆盖的保存

设逻辑有限图 B 的有序代表为 `x₁<…<x_m<N`，满足全对覆盖

\[
\operatorname{Cap}_G(x_i,x_j)\ge b+\operatorname{Cap}_B(i,j)
\quad(i<j).\tag{2}
\]

包括逻辑非祖先对，其需求也为 b，而不是 0。因为 f_n 严格递增且 f_n(q)≥q，
式 (1) 给出搬移后同一全对覆盖 (2)。更精确地，需求可一起按 f_n 搬运。
如果所有需求≤c，原需求无需任何改变：高于 c 的实际富余容量可能增长，
但不会让原覆盖失效。由此保存的是**完整祖先覆盖**，不是字面父表。

## 5. 对额外一份复制资源协议的应用

使用[额外副本协议](crossing-lower-extra-copy-resource.zh-CN.md)的记号：
当前末位置 N；旧完整温模板 Γ 全在 `e<a<t<N`；私有数据在 t；
逻辑切点代表 c<e，正逻辑步要取第 n 项。

先暴露末列控制只改 N，Γ 的全部旧前缀容量不变。
实际执行 M[n+1]，但选择第 n 份私有资源与 Γ 的代表 σ_n(x_i)。
第 n+1 次反射只改旧末位置 N+nL 及其后的新列；
Γ 的最后代表 `e+nL<N+nL`，所以这额外一次不改选定模板。
随后删到 `t+(n+1)L` 并在该末列恢复第 2 行导航，仍全部发生在
`e+nL` 之后。故选定 Γ 的覆盖严格持续。

在当前协议中 b=3，逻辑最大行高≤4，故最大需求 7≤c。
Γ 的所有旧要求 `3+Cap_B` 无需重新编码，非边的基线 3 也同时保留。
逻辑删除选择第 0 份模板，所有模板列都在被操作末列之前，同理保持。

真实父返回先删到私有 t，再执行有限反射并只恢复新末列；Γ 位于 a 之前，
因而父返回也不改 Γ 自身的覆盖。**恢复后的活动末点能否使用它**还需要
第 2 行端口、第一行私有链、足够的数据高度及真实返回支付；不能仅据 (1)
把温模板当作免费可调用资源。

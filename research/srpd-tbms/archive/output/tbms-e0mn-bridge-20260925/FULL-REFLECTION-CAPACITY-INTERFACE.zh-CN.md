**本页是一般结构定理，不是 W₂≤S₂ 或 M13≤B_(ε₀) 的证明。**
公式适用于任意原生相容的严格 M 父图，不限于二阶类 C_b。
它补足旧“内部副本容量公式”没有描述的旧前缀、接缝、不同侧之间的接口。

## 1. 约定

列和行均一基。原图 G 宽 N，末列高度 h>0，末父 d，跨度 L=N−d。
严格父表给出 h≤d。做一次完整反射，**暂不删除最后的临时列**，所得图 G⁺ 宽 N+L。
原 j>d 的副本位于 j+L；原末位置 N 变成接缝

\[
C_N^+=C_N\upharpoonright(h-1)\frown C_d[h,\ldots].
\]

记 q(a,z)=Cap_G(a,z)、q⁺(a,z)=Cap_(G⁺)(a,z)。
容量是 a 在 z 的逐行祖先链上能保持到的最大行号；没有连接时为 0。
山脉相容性使这些行恰是一个初始区间，且 q(a,z)≤a。
这里始终沿**相应行**追父链，不使用已被反例否定的第一行追根捷径。

定义

\[
f(t)=\begin{cases}t,&t\le d,\\t+L,&t>d.\end{cases}
\]

## 2. 容量定理

对所有 1≤a<z≤N+L，有下表。表中“副本”用 z=t+L、a=s+L 表示，d<t≤N。

| 源、目标位置 | 精确容量 |
|---|---|
| a<z<N | q⁺(a,z)=q(a,z) |
| a<d，z=N | q⁺(a,N)=q(a,d) |
| d≤a<N，z=N | q⁺(a,N)=min(q(a,N),h−1) |
| a<d，z=t+L | q⁺(a,t+L)=q(a,t) |
| d≤a<N，z=t+L | q⁺(a,t+L)=min(q(a,N),h−1,q(d,t)) |
| a=N，z=t+L | q⁺(N,t+L)=q(d,t) |
| a=s+L，z=t+L，d<s<t≤N | q⁺(s+L,t+L)=f(q(s,t)) |

这些是等式，不只是用来筛除候选的充分条件。

### 2.1 旧前缀与接缝

N 以前的列不改。对 r<h，d 是旧末列在第 r 行的祖先：这是末父在第 h 行为 d
以及祖先森林嵌套性的直接推论。
所以 a<d 时，a 是旧末列第 r 行祖先当且仅当它是 d 的第 r 行祖先。
对 r≥h，接缝直接继承 d 的尾，得到同一个等价。
因此接缝指向 a<d 的容量恰为 q(a,d)。

若 d≤a<N，则接缝继承 d 的尾不可能再指回 a；仅 r<h 的旧末列部分能保留它。
故容量恰为 min(q(a,N),h−1)。这也包括 a=d。

### 2.2 副本内部与新接缝根

两端都在内部副本时，原行 r≤d 不变，原行 r>d 搬到 r+L；
插入区间重复原第 d+1 行。内部祖先链按同一地址偏移搬运。
因此初始行区间的最大端点恰按 f 变换，得最后一行公式。

原 d 到 t 的连接只可能出现在 r≤d。复制时原 d 替换为接缝 N；
在到达这个端点之前不读取接缝自身的父，所以容量恰为 q(d,t)，不受接缝截短影响。

### 2.3 从新副本回到旧前缀

对于 a<d，原内部路径不经过 d 就离开复制块时，外部父直接保留。
若原路径经过 d，副本先到 N，再由 §2.1 恢复 d 的所有严格外部祖先。
两种情况都恰保持原容量 q(a,t)。相关行都≤a<d，不涉及插行。

对于 d≤a<N，副本不能用一条未搬运父边直接进入这个区间：
未搬运父号严格小于 d，搬运父号至少为 N。
所以路径到旧 a **必须经过 N**。
到 N 的容量由 §2.2 给出 q(d,t)，从 N 到 a 的容量由 §2.1 给出
min(q(a,N),h−1)。串接两段取最小值，就得到跨接缝公式。

以上穷尽了所有位置组合，定理成立。

## 3. 对高低控制交替的两个严格推论

### 3.1 旧坏块到新副本的接口至多 h−1

对于每个旧地址 d≤a<N，以及每个新副本 t+L，

\[
\boxed{\operatorname{Cap}_{G^+}(a,t+L)\le h-1.}
\]

因此本次高度 h 的控制不能在新副本中原样保留同高度的旧坏块接口。
这个结论与源、目标列的总高度可能增加多少无关。

固定二阶边界 b 时，若 h≤b+1，则这些旧地址到新副本的第 b+1 行连接全部消失。
低控制 h≤b 尤其如此；这是接口分离，不是说新副本的全部高行都消失。

### 3.2 不能把“损失一层”推广到所有旧控制

a<d 的严格外部控制仍然保留 q(a,t)，不一定降到 h−1 以下。
接缝 N 到新副本也保留 q(d,t)，没有损失这一层。
所以不能给每条旧控制统一减一，再由有限控制高度宣布全部过程已获上界。
后续可能重新使用的正是这两类接口；内部副本还可能通过 f 拉长容量。

对任意基本列指标 n，可逐次使用本定理 n 次，再删除最后临时列。
容量仅由目标列及其前缀决定，因此删去最后临时列不改变其余容量。
这给出全指标的精确更新过程，但**不是**沿任意长过程严格下降的序数赋值。

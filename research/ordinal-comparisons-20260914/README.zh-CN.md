# 序数记号比较研究总览：Y、RPD、wY、ARD、TPD、ARD2 与 IPD

> 仓库研究文档：纸面论证、局部核验与未证候选分别标注，不并入正式良序证明。配套原稿和数据见 archive/；标为“原工作区”的代码或历史材料未随文档归档。

整理日期：2026-09-14。本文汇总本会话最近的 IPD 上界研究、Y→RPD 比较，以及 ARD2→IPD 的两轮研究。它是结论与推导的合并入口，不是一次新的完整证明审计。

## 1. 目前最重要的结论

1. **Y≤RPD 已有一份纸面比较证明，尚未端到端 Lean 形式化。** 它通过规范山脉图、RPD 的有限不变量、控制边预降和最小覆盖映射建立严格保序映射；不是由共同的良序证明方法猜出来的。
2. **RPD、Y、wY、ARD、TPD 都找到了很具体的 IPD 上界候选。** 候选的标准可达路径、完整图、精确计数及多种局部编码接口已有核对；但这些源记号的整个序型小于相应 IPD 式子，尚未完成全域比较证明。
3. **ARD2 当前的具体上界候选是 IPD 的 $U=A_3[2]$。** 完整列表为 `[][0:2/.][1:2/^]`，精确计数序列为 **`1,4,15`**。已给出统一种子覆盖、首次展开的覆盖论证，以及五条独立 JS 重放通过的后续模拟；仍缺任意后续展开的统一封闭性。
4. **目前偏向 IPD 极限大于 ARD2 极限，但没有大小定理。** 没有证明 $\alpha_{\mathrm{ARD2}}\le |U|$，也没有发现 ARD2>IPD 的证明或反例。
5. **ARD2 的这个候选并不比此前的候选小。** 此前五者的候选全部低于 $A_2$，而 $A_2<U<A_3$。这只比较候选，不能反推 ARD2 大于此前五个源记号。

文中 $\alpha_X$ 表示记号 X 的有限标准域的序型，$|G|_{\mathrm{IPD}}$ 表示一个具体标准 IPD 图在该良序中的位置。写“候选上界”时，不省略其尚未证明的性质。

## 3. 统一口径与证据等级

### 对象与工作前提

- **wY** 始终指 ω-Y 下的 **weak magma**，不是另一个 weak-wY。
- **ARD2** 是旧工作名 Full-Context 的记号，不能与 ARD 混用；**RPD** 是正确拼写，不是 RDP。
- **Y** 使用固定证明仓库的标准域。用户已接受它与所指 Naruyoko Y 在关注标准域上等价；不重开该审计，也不把这项接受前提说成新完成的 Lean 等价定理。
- BO 指 Buchholz ordinal，对照 BMS `(0,0,0)(1,1,1)`。BMS 极限 = Y/wY 的 `(1,3)` 按用户给定的已知结果使用。
- “Y 极限可能等于 wY 的 `(1,4)`”仅作研究线索，未作为证明前提。本汇总不使用 BMS=PTO(Z2) 等猜想。
- 标准域是从规定种子经有限次实际展开得到的表达式，不是所有语法合法图。允许手写的树或邻接表，不自动意味着它是标准可达式。

### 本文的四种状态

| 标记 | 含义 | 不代表什么 |
| --- | --- | --- |
| 纸面论证 | 已有明确的数学证明链，依赖项有说明 | 不自动等于比较定理已被 Lean 验证 |
| 局部引理 | 对明确限定的种子、一次变换或编码接口给出统一论证 | 不自动推广到全部后续展开 |
| 有限核验 | 具体图、具体路径或有界样本经过程序检查 | 不覆盖无限标准域；超限项不算成功 |
| 候选／判断 | 有结构依据、值得继续证明的大小关系 | 不是已经成立的不等式 |

## 4. 候选总表

下面每一条计数都对应一个指定的完整图。**计数只是显示方式，不是一般可反解的输入，也不是跨记号序数比较器。**

| 目标 | IPD 对应点或上界候选 | 精确计数序列 | 当前依据与限制 |
| --- | --- | --- | --- |
| $\varepsilon_0$ | $H_\varepsilon=A_0[3]$ | `1,1,2,4` | 既有低段森林解释可辨认为 $\varepsilon_0$；本轮未新做比较 Lean |
| BO | $H_{\mathrm{BO}}=T^2(H_B[1])$ | `1,1,2,4,1,2,5` | 紧候选；冻结根投影、三角归一化的统一共尾性仍需补齐 |
| BMS 极限 = Y/wY `(1,3)` | $H_B=T^6(A_0[4])$ | `1,1,2,4,2` | 同上；较松备选为 $A_1[2]$，计数 `1,2,5` |
| Y 极限 | $R^\star$ | `1,3,10,35,125,449,1609,5725,20175,70380` | Y≤RPD 的纸面证明，再接尚待全域封闭的 RPD→IPD 路线 |
| RPD 极限 | $R^\star$ | `1,3,10,35,125,449,1609,5725,20175,70380` | 固定保留列的行／根二叉编码 |
| ARD 极限 | $A^\star$ | `1,3,10,35,125,449,1609,5725,20175,70565` | 两个移动地址的编码与标准种子链覆盖 |
| wY 极限 | $W^\star$ | `1,3,10,35,125,449,1609,5725,20175,70932` | 任意有限长度祖先词的二叉位置编码 |
| TPD 极限 | $T^\star$ | `1,3,10,35,125,449,1609,5725,20175,71043` | 形状与数字词分开编码；理论包络与实际轨道点区分 |
| ARD2 极限 | $U=A_3[2]$ | `1,4,15` | 统一种子及首步覆盖、五条实际后续模拟；全局封闭未证明 |

RPD、Y、ARD、wY、TPD 五者还有一个简短而较松的**共同候选**：

$$
H=T^5(A_2[2][2]),\qquad \operatorname{count}(H)=(1,3,10,36).
$$

这里 $A_d$ 是零起始 IPD 种子 `[][0:d/.]`；$T$ 是实际 `[1]` 后，用 `[0]` 删去新增列、恢复原宽度的辅助操作，不是新基本列。它与 $T^\star$ 这个候选名称不同。

## 5. 哪些大小关系是确切的

具体 IPD 候选图之间有实际下降见证：

$$
R^\star<A^\star<W^\star<T^\star<H<A_2<U=A_3[2]<A_3.
$$

其中 $A_2=A_3[1]$，且 $A_3[1]$ 是 $A_3[2]$ 的真前缀。十列候选之间还有：

$$
W^\star=T^{111}(T^\star),\qquad
A^\star=T^{367}(W^\star),\qquad
R^\star=T^{185}(A^\star).
$$

这解释了三个曾经容易误解的地方：

- RPD/Y 与 wY 的候选到第十列才不同，是我们选择了同一标准轨道、同一前缀的结果，不是证明了两种源记号前九列完全一致。
- `1,4,15` 虽然短、末数小，却在这些特定 IPD 图中高于那几条十列候选；不能比较计数总和、位数或末项来判断序数。
- 即使今后证明各个候选都是上界，也不能由上界的次序推出 $\mathrm{RPD}<\mathrm{ARD}<\mathrm{wY}<\mathrm{TPD}<\mathrm{ARD2}$。

## 6. 良序证明与大小比较是两件事

本次整理时，正式仓库中的 [IPD 定义](../../notations/IPD/definition.zh-CN.md) 和 [ARD2 定义](../../notations/ARD2/definition.zh-CN.md) 已分别记录了标准域按列良序证明、普通 Lean 编译结果，以及纸面公理上界

$$
KP_\omega+\text{“存在不可数序数”}
$$

（含完整集合归纳）。两份定义也明确没有收录这些跨记号序型比较为定理。

这里仅报告当前文件记载，不表示本次汇总重新构建或独立审计了全部 Lean。普通 Lean 完成，也不等于已经在 Lean 中形式化该弱公理体系的语法和内部推导。

因此，旧研究稿中“良序后端尚未整合”等说法应按历史状态阅读。**当前这条比较研究真正未完成的是跨系统的统一模拟与覆盖封闭性，而不是用旧状态否认现有单个记号的良序成果。** 共同公理上界不能决定两个序型孰大孰小，也不证明该上界最优。

## 7. 已淘汰的说法与保留的问题

| 不应继续使用的表述 | 应改成 |
| --- | --- |
| “ARD2 的下界是 `1,4,15`” | 这是试图压住 ARD2 极限的 IPD **上界候选** |
| “已经把 RPD、wY、ARD、TPD 嵌入这些 IPD 点” | 编码、候选与有限核验已有；完整序型比较尚待证明 |
| “浅树能写下三元组，所以 ARD2≤低层 IPD” | 还必须处理 IPD 地址合法性、复制切点、旧前缀和任意后续接续 |
| “精确编码失败，说明 ARD2>IPD” | 只否定被测试的编码；允许辅助列与额外目标结构的路线未被排除 |
| “搜索超限，说明没有模拟” | 有限模板／预算没有找到，数学问题仍未定 |
| “只要每次重新选一个大目标就完成模拟” | 必须从同一个已下降的实际目标继续，不能中途补回较大的起点 |

后续最有价值的两个方向：

1. 将 RPD→IPD 的候选接口补成完整的标准覆盖与下降秩论证；这样可把已有纸面 Y≤RPD 接上。
2. 为 ARD2→IPD 定义能沿真实历史保持的覆盖关系，统一证明任意严格源步都有目标的严格实际后代覆盖。$U$ 是否足够、是否需要更大的有限 IPD 式子，都以这个问题为准。

## 3. 标准可达见证

沿用局部操作 T：先作 IPD `[1]`，随后反复 `[0]` 删除新追加的列，只保留原宽度。这是普通基本列的有限复合，没有增加规则。

依次定义

\[
\begin{aligned}
H&=T^5(A_2[2][2]),\\
G_0&=H,\qquad G_{i+1}=T(G_i[2])\quad(0\le i<4),\\
B&=G_4[3].
\end{aligned}
\]

则

\[
\boxed{W^\star=T^{151444}(B),\qquad
R^\star=T^{151996}(B).}
\]

G₄ 的计数为 `1,3,10,35,125,449,1609,5726`，其末列控制树为 `1(*)`。B 的末列控制父为 8，子列为 9。到 R★ 为止，局部轨道中的这条边一直强于其他边，因而可以只计算它的第零轮廓降低，而把已经并入的其余边保持不变。

未共享树的 Python 定义完成了这段 151997 步有界检查；实际 NER 的共享树与剪枝降低实现独立回放到两个终点，完整列表相同。NER 回放时还逐步断言没有换控制父。两者的计数均为精确整数，不是估计或溢出占位符。[^tests]

这里跑的是固定十列、单条有限树轮廓的有界见证核对，不是沿任意起点不断取固定指标、等待整个序数下降完毕。

## 4. 固定的空列为何能缩小编码

先在源图最左边保留一个额外空列，编号为 0；源的实际数据列全部加 1。因此源边的父至少为 1，源根和 SELF 的地址也至少为 1。

把 **ROOT 0** 用作树的结构头，而把真正的源地址放在叶上。对第 j 列，记

\[
Z=\text{零树},\quad s=j(),\quad Q(q)=q(),\quad
f(t,u)=0(t,u),\quad g(t)=0(t).
\]

此处 0 是真实保留列的引用，不是额外添加到 IPD 规则里的常量。所有这些节点都在第 1 层。s 是 SELF **叶**，不是零树。

源与目标控制相匹配时，目标复制切点至少为 1，故复制固定 ROOT 0；其他叶引用照常搬动。因此对固定 0 的严格递增地址映射 φ，编码满足真正的交换律，而不是仅仅在几次样例中相似。

还要处理目标有额外父 0 控制边的情况。它不承载任何源边要求。作一次目标 T，只降低这条额外边并继承空列 0，不改变任何源所需的边或前缀；覆盖仍在。其余控制不匹配情况的切点大于 0，仍固定该结构标签，可沿用既有的共尾预降归纳。[^cover]

这一步是保留空列的实质。若让源复制本身也从保留列 0 开始，却继续把结构头当作不动常量，交换律就会出错。最终编码没有这样做。

## 5. RPD：固定行号只需要一条右梳

定义

\[
M_0(q)=Q(q),\qquad M_{k+1}(q)=f(s,M_k(q)).
\]

对每个父 p，取该父下最大的 `(行 k,根 q)`，用 M_k(q) 编码；父与根须按上一节先加 1。低组不是被声称不存在，而是在覆盖模拟中用最高组作摘要。当前标准 RPD 的低行饱和性解释了这个摘要与源接缝规则的联系。[^rpd]

在固定列内，所有地址叶都不大于 s，而每个正高度右梳严格大于 s。两个右梳按高度 k 优先、末叶 q 次之比较。因此编码精确保留 `(k,q)` 的控制优先级，不会让某个较大的根号抢过较高行。

若 `(h,r)<(k,q)`，则

\[
M_h(r)\le\ell_{1,0}(M_k(q)).
\]

同高时，沿右子树降低末叶即可。行号降低时，末叶原地址至少为 1，降低后仍可保留原梳高；它已支配任何较低梳高的末叶。源在非控制父同时删掉的高根关系，目标可以保留为覆盖余量。源在正块中增加的根地址，仍由搬动后的同一有限字母表前驱所支配。

关键统一界是

\[
C_R=f(g(s),Z)=0(0(*),.).
\]

对所有有限 k 和合法 q，M_k(q)<C_R：正高度右梳首子项为 s，C_R 的首子项 g(s) 严格大于 s；其尾部由归纳控制。任意多的固定行号都被这一个有限树包住。

R★ 的末列父 8 的控制树恰为 C_R。把保留列映到目标列 0，把任意 RPD 两列种子映到目标列 8、9，就得到统一种子覆盖。接上实际展开秩的覆盖归纳，支持

\[
\alpha_{\mathrm{RPD}}\le |R^\star|.
\]

## 6. wY：多个移动地址仍需再包一层

沿用 wY 文稿的有限几何接口：固定一个起点后可取共同有限维度 D，把祖先轮廓补成 D+1 位的 ROOT/SELF 地址词；复制、控制优先级和低接缝与这些词的下降相容。整体系统不要求有共同有限 D。[^wy]

在同一保留列编码下，对非空词定义

\[
\begin{aligned}
E(q)&=Q(q),\\
E(q_0,\ldots,q_{\ell-1})
 &=f\bigl(M_{\ell-1}(q_0),E(q_1,\ldots,q_{\ell-1})\bigr)
 \quad(\ell\ge2).
\end{aligned}
\]

位置从高到低递减。所有右梳标记都小于任何长度至少二的完整词编码：标记根的首子项是 s，完整词根的首子项是一个严格大于 s 的正高度标记。尾词位置较小，无法借 LPO 的子项分支越过首位置屏障。

因此比较恰为“词长优先，同长再按数字字典序”。固定 D 所需的比较是其特例。编码仍交换固定 0 的搬运；并且对较小词 u<v 有

\[
E(u)\le\ell_{1,0}(E(v)).
\]

若首坐标相同，递归降低尾词；若首坐标或长度降低，可用降低非零尾词、保留原高首位的候选，或对位置标记应用上一节的较小段支配。后面任意合法地址不会破坏位置优先级。

所有有限词统一满足

\[
E(w)<C_W=f(C_R,Z)=0(0(0(*),.),.).
\]

证明只需对词长归纳：首标记低于 C_R，尾词低于 C_W。W★ 的末列父 8 的控制树恰为 C_W，故同一有限图统一覆盖全部 wY 两列种子的编码，而不仅覆盖某一个固定维度。

这给出候选比较

\[
\alpha_{wY}\le |W^\star|.
\]

C_R、C_W 的区别来自“一个不移动的梳高＋一个地址”与“多个独立移动地址的位置序”，不是把两个数值计数之间的差当作序数强弱。

## 7. Y 与 wY `1,4` 的线索

Y 的上界使用既有 Y→RPD 规范图、祖先覆盖与有限预降模拟，再接本次 RPD 编码。Y 的两列种子 `(1,m)` 对应 RPD 的种子 S_(m−2)，所以直接得到与 RPD 相同的上界 R★。[^y]

“Y 极限可能等于 wY `1,4`”没有用作证明前提，也没有在这里另作证明。它提醒一个重要局限：一般图/一般地址词编码会抹去原山脉的几何限制，因而即使上界已经缩小，也可能离真正对应点很远。

要把 Y 的上界与 RPD 继续分开，需要进一步利用 Y 的规范山脉约束；仅重复“所有种子都由这套最高行摘要覆盖”，不会产生新的区别。要继续压 wY，也需要改变祖先词的图层模拟或利用其几何限制，而不只是沿同一条已知上界下降几步。

## 8. 缩紧程度与结论边界

R★、W★ 是所选标准分支中，控制树仍分别达到 C_R、C_W 的最后位置。两个终点的树已经精确等于对应边界；下一局部步即低于它。它们不是任意挑选的末项计数。

这仅说明**当前编码、当前种子捕获方式与当前分支**内的缩紧程度，不是源序数的全局最优上界定理。别的编码、列嵌入或图层共尾论证仍可能显著改进。

目前最需要补充的无限论证，不是更多程序样例，而是：

1. 对当前零起始 IPD 的整体良序后端与一般覆盖秩归纳作合并独立审计。
2. 将保留列的固定标签条件正式纳入覆盖归纳；上文给出了控制父为 0 与正控制父的分情况处理。
3. 对 Y 与 wY 的源接口逐条确认适用域。Y→RPD 仍依赖原规范图/数值规则接口；本报告没有重做全域 Lean 与 Naruyoko JS 等价证明。wY 仍使用给定文稿的有限几何引理。

所以可靠的陈述是：**已找到显著更小、有具体结构依据的表达式上界候选，并验证其确为标准可达式。** 不能改写成“已经精确算出三个极限所在位置”。

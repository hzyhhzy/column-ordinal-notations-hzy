## 2. 对照的精确定义与真正新增的障碍

使用 FullContext Python 定义（原工作区：`output/simple-ipd-20260914/full_context.py`；未归档）、研究总稿第 3 节（原工作区：`output/simple-ipd-20260914/RESEARCH.zh-CN.md`；未归档）、审计稿第 8—9 节（原工作区：`output/simple-ipd-20260914/self-anchor-proof-audit.md`；未归档） 和 [强度限制稿](full-context-strength.md)。目标 IPD 使用 当前零起始独立定义（原工作区：`output/new-notation-20260914/ipd.py`；未归档）。这些文件均只读。

ARD2 第 j 列的组为 (k,p,q)，满足 k,q≤j、p<j；较低行可以获得直到接缝自身的全部根。相反，IPD 一条父为 p、子为 j 的边，其任意深度树中的地址叶只能是

\[
0,1,\ldots,p\quad\text{或 SELF}=j.
\]

因此增加 IPD 树的层数或深度，**本身不会**让这条边直接引用 p<q<j 的中间地址。它仍可能通过更复杂的编码模拟，但不能只说“局部可用 K₂ 静态编码，所以整个 ARD2≤某个 K₂ 种子”。

### 2.1 中间地址真的能控制标准展开

令 S₃ 为三列 ARD2 种子，令 T 表示 `[1]` 后用 `[0]` 删回原宽度。

```text
S3 = [][(1,0,1)][(2,1,2)]
```

T⁴(S₃) 为

```text
[][(1,0,1)][(2,1,0);(1,1,2);(0,1,2);(2,0,1);(1,0,2);(0,0,2)]
```

其控制组按 (k,q,p) 最大选取，恰是 **(2,0,1)**。在子列 j=2、父 p=0 的地方，中间根 q=1 直接参与控制。

这排除了“只在非标准任意图出现”与“只出现在可以忽略的低优先级组”两个捷径。完整八步轨道由 接口核对脚本（原工作区：`output/ard2-ipd-bound-20260914/context_obstruction_probe.py`；未归档） 输出。

## 3. 第一类尝试：保留原父，用树参数代替中间地址

### 3.1 将所有父之后的地址统一记成 SELF

沿上一轮 ARD 的思路，在每个父下取最大 (k,q)，但把大于父的 k、q 都截成当前 SELF；增加固定空列 0 后用 `0(0(k,SELF),q)` 编码。

所得图在 IPD 中结构合法，但会把严格下降识别成同一个图：

\[
T^2(S_3)<T(S_3),\qquad
E(T^2(S_3))=E(T(S_3)).
\]

相等的完整编码是

```text
[][][1:1/0(0(*,*),*)][2:1/0(0(*,*),2);1:1/0(0(*,*),*)]
```

因此这种**固定的精确摘要作为最低覆盖要求**，不能直接支持每个源步都对应目标严格下降的旧证明路线。这不排除增加额外预算、使用不同覆盖关系的编码。

### 3.2 把中间位置写成固定自然数高度

同父以后的间距 q−p，或 k−p，可以静态编码成树高，但复制时未必固定。

脚本在标准路径

```text
G = (T^3(S4))[2]
```

找到一个五列图，末列控制切点 c=1、旧末位置 x=4、块长 L=3。其来源列 j=3 中有：

- `(3,0,1)`：第二块复制到列 6，得到 `(6,0,4)`，中间根到父的间距从 1 变成 4。
- `(2,0,3)`：同次复制得到 `(5,0,6)`，中间行锚到父的间距从 2 变成 5。

这两条都是实际来源块中的组，不是仅讨论接缝时新造的参数。IPD 的普通搬运不改变树的形状，因而不会自动把一个固定高度 1 改成高度 4。以 j−q 编码也有对偶问题：当 q 在切点左侧固定、j 被复制时，其距离会增长。

这里只排除这些**要求高度精确交换搬运**的直接方案；没有得到关于任意参数编码的一般不可能定理。

## 4. 第二类尝试：抬高父列，随后用宏步补回原复制

### 4.1 具体测试的编码

对每个源组 (k,p,q)，把物理父改成

\[
\widehat p=\max\bigl(\{p\}\cup\{k:k<j\}\cup\{q:q<j\}\bigr).
\]

SELF 不参与抬父。用上一轮固定 ROOT 0 的三位二叉位置词编码 **(k,q,p)**，所有源地址先加 1，原父 p 仍保存在词的第三位。将这条轮廓放在物理父 \(\widehat p+1\) 下；同物理父按 IPD 规则保留最大轮廓。

这样所有树都合法，而且没有简单丢掉原父。但抬父改变了切点，普通一步展开并不等于源展开。

### 4.2 一个局部失败确实可以用预降修好

取 G=T⁴(S₃)。仅对 E(G) 作一次 `[n]`，没有任何 n 能覆盖 E(G[1])：n=1 长度不足，n≥2 在所需宽度上的前缀均已固定且不覆盖。

不过，**先作一次 T，再作 `[1]` 可以覆盖**：

\[
E(G[1])\preceq T(E(G))[1].
\]

覆盖指同位置、同物理父下目标轮廓不小于所需轮廓，允许额外边。这个正例已核对。因此不能仅凭“抬父后一次复制不对”便宣告所有宏步不可能。

### 4.3 更小而致命的顺序障碍：S₃[2]

令 G=S₃[2]。在上述同一个编码下，出现

\[
G[1]<G,\qquad E(G[1])>E(G).
\]

这里的第二个不等式是**实际 IPD 列比较**，不是轮廓计数。

在最后一个旧位置（原 ARD2 第 3 列，编码后第 4 列），E(G) 的父列表是 `3,1`。编码输出在该位置的父列表变为 `3,2,1`；父 3 的轮廓保持相同，新插入的父 2 排在原父 1 之前。因此编码输出的这个旧宽度前缀已经严格大于整个 E(G)。

IPD 的任何非空有限展开串都严格降低列序，而覆盖 E(G[1]) 的图必不小于其旧宽度前缀。所以从 **这个 E(G)** 出发，增加预降步数、改展开指标或插入更多真实展开，都不可能达到覆盖 **这个 E(G[1])** 的结果。

这是对该固定抬父编码更强的否定：不是搜索预算不足，也不只是某个指定的宏步模板失败。仍然可以换编码、增加真正具有序数语义的缓冲结构，或换成更宽松的模拟关系。

此处不声称编码图已是标准 IPD 式；这些反例检验的是合法原始 IPD 图上的候选接口。源 G 及其展开则确实标准可达。

## 5. 为什么暂时不填 A₂、A₃ 或上一轮的十列上界

前一轮 ARD/TPD 缩紧的关键，不只是树包络够大，还包括：

1. 编码使用合法地址；
2. 复制搬运与编码相容，或有可保持的覆盖替代；
3. 每次源展开能被目标实际下降模拟；
4. 一个具体标准目标式统一容纳全部源种子。

ARD2 当前缺的是第 2、3 项的一般接口。单纯找一个更大的树包络，不能补足它们。双 SELF 深度不增加的旧不变量，也没有消除普通中间行/根的上述搬运现象。

所以本轮不把“静态编码层数有限”转写成 ARD2≤A₂，不任意再加一层写成 ARD2≤A₃，也不声称 ARD2 的极限落在上一轮 R★、A★、W★、T★ 附近。

仍值得尝试的方向是**多列上下文编码**：让“原复制父”与“保存后方引用的代理位置”各自有明确表示，并证明一组有限宏步之后恢复同一编码类，同时保留旧前缀的序数意义。上面的局部预降正例说明不应排除宏步；顺序反例说明不能继续原封不动使用本次抬父摘要。

这是一条具体的后续研究方向，不是已经构造出的 IPD 上界。

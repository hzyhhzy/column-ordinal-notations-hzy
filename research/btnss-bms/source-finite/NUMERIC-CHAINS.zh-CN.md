# BTnSS 的父链与激活

> 收录说明：本篇为配套局部引理，不单独承担整个比较定理。总体状态以[主证明](../upper-bound.zh-CN.md)为准。实验脚本与旧研究日志的文件名是历史来源记录，未作为可运行附件收录。

令 d≥1 为数值坐标个数，P_j 是第 j 个数值父，0≤j<d。
父关系只引用当前作用域内较早的结点出现位置。P_0 是最近较小第一坐标；
P_j 沿 P_(j−1) 链取最近第 j 坐标较小的位置。
以下引理只依赖有限父链定义，不使用标准性、良序性或大基数公理。

## 父链逐级包含

若 r 是 x 的 P_j 祖先，且 i<j，则 r 也是 x 的 P_i 祖先。

证明：每条 P_j 边按定义是一段非空 P_(j−1) 路径。把有限条边逐一替换成这些路径，
得到 P_(j−1) 祖先关系；再对 j−i 归纳。作用域退出不造成例外，
因为一条父路径上的所有位置同时存在于后端可见的作用域中。

## 激活等于祖先关系

给指定根 r 激活上限 b≤d。a(r)=b，其余结点按原定义计算 a。
以 P_j^* 表示包含自身的祖先关系，则

    a_r(x)>j  当且仅当  j<b 且 r P_j^* x。

证明：对出现位置的读取顺序归纳。根本身结论成立；不晚于根的其他位置均不激活。
对非根 x，若 a_r(x)>j，则 P_j(x) 存在且 a_r(P_j(x))>j。
由归纳假设，r P_j^* P_j(x)，故 r P_j^* x。
反向，若 r P_j x，则 r P_i x 对所有 i≤j 成立。每个 P_i(x) 也以 r 为 P_i^* 祖先，
归纳假设给 a_r(P_i(x))>i。因此定义中的每一项测试 i≤j 都通过，a_r(x)>j。
这也证明 j≥b 永远不激活。

## 正确的不再激活命题

固定 j≥1，且 r 是 x 的 P_(j−1) 祖先。则

    r P_j x  当且仅当  从 r 到 x 的 P_(j−1) 路径上，
    除 r 外每个结点 v 都有 v_j>r_j。

证明：在这条有限线性路径上，P_j 正是最近严格较小数值的栈父。
若路径所有中间值大于 r_j，沿 P_j 反复搜索不能越过 r，有限严格下降必到 r。
若存在中间值≤r_j，取路径上最晚一个这样的结点 q。
从 x 的 P_j 搜索所形成的链在到达 r 前必须被 q 或其后更近的低值结点截住；
到达值≤r_j 后，后续数值严格下降，不可能再到值为 r_j 的 r。
末点值≤r_j 的情形同样不能到 r。

因此，在一条从 r 向外延伸的 P_(j−1) 路径上，激活第 j 坐标的结点构成初段；
第一次失去资格的位置满足 v_j≤r_j，此后不能恢复。
这不是说整个 P_0 子树内第 j 坐标都不可恢复。

## 三坐标警示例

原始合法式

    ()(1,1)(2,1,1,*)

以首零结点为根，P0 链激活为 3,2,3。第三坐标可以在 P0 链恢复，
但 P1 链直接从末结点连到零根，没有经过中间结点；上面的正确命题没有反例。
此例目前没有标准路径证书，不能据此否定标准域中更强的不变量。

现在另有一个**已证标准**的反例，否定一概把第 j 坐标不再激活放在 P0 链上的版本：

    L2[0][2][1][1][1][1][1][0]
      = ()(1,1,1)(2,2)(3,1,1)。

以首零结点为根、b=3，P0 是整个四结点链，激活为 3,3,2,3。
末结点的 P1、P2 都是首零结点，因此第三坐标重新激活。
`regression_chain_reactivation.cjs` 用未改规则的 NER 源精确重放。
这不表示该式处于一次实际最高分支复制中，也不否定加上其他分支假设的命题。
它只说明“标准式中任意根的最高激活沿 P0 都是初段”也为假。

## 尚不能直接推出的内容

这些引理尚未证明多份复制中的全部实际父关系运输，也未证明块序或覆盖。
特别不能继续使用二坐标特有的“某结点最高坐标不激活，则整个 P0 块的最高坐标不动”。
各级链上的阈值引理需要在具体比较所用的作用域和父链上分别应用。

## 固定进入数据下的平移保序

固定根 r、上限 b、非负向量 δ，以及同一进入作用域。
对每个被比较森林重新按其原数值父计算激活，仅给激活坐标 j<b 加 δ_j。
此运算保持树形结构、列数、结构前缀和第一处差异的方向。
这里的列数不等于省略零坐标后的原子字长：指定根自己的零坐标可变正，
从而增加读取原子。除指定根外，零坐标没有根祖先而不激活，因此非根材料的原子数保持。

证明：比较第一处不同坐标之前，两项的所有先读数据相同，当前结点更低编号坐标也相同。
所以第 j 坐标查询用的 P_(j−1) 链与其已有激活状态相同。
j=0 时，是否进入指定根的 P0 子树由相同前缀和当前第一坐标的阈值决定。
j≥1 时，如果该链不含 r，或在 r 之后已失去第 j 坐标资格，当前值的任何选择都不激活；
否则由上一节，资格恰为当前值 t>r_j。
因此当前坐标的映射要么是恒等，要么是 t↦t+δ_j·1_(t>r_j)，两者都严格递增。
根自身若在待平移材料中，其取值固定，不能作为被比较项的首次自由差异。
若共同的根头因此新增原子，两边添加相同的根头原子，仍保持比较方向，
但不能声称该头之后的第一差异在绝对字下标上完全不移动。
若差异是列表结束或森林结构变化，原子/结构位置未变，方向同样保留。

相对键值编码也可作同样的逐坐标证明：活跃阈值情况下映射为
t↦(0,t)（t≤r_j），t↦(1,t−r_j)（t>r_j），严格递增；
资格恒为假时映射 t↦(0,t)。因此固定所属坐标和进入数据时，完整森林列表与其相对键同序。

这里只比较具有**同一进入数据及同一基点**的材料。
跨副本或不同基点的键值比较需要另外的运输/共轭引理，不能仅引用本节。

# 各级块比较的部分变基

> 收录说明：本篇为配套局部引理，不单独承担整个比较定理。总体状态以[主证明](../upper-bound.zh-CN.md)为准。实验脚本与旧研究日志的文件名是历史来源记录，未作为可运行附件收录。

高维 SB_j 需要只移动前 j 个坐标，不能把所有坐标一概规范化。
本节给出该操作的数值运输，并明确什么时候能从 SB_j 推出最高键比较。

## 部分变基引理

令 1≤j<d，G 是 X 的严格 P_(j−1) 祖先，且二者 P_j 位置代表相同。
取 G 的完整 P0 块，把它放到 X 的位置，给以 G 为 P_k 祖先的坐标
k<j 加 X_k−G_k；所有 k≥j 的坐标均不动。保留 G 的原首列表。
该操作就是候选 SB_j 中的 τ^j_(G,X)。

所得块在 X 的进入作用域中数值合法。新首的 k<j 输入取原 X 的输入，
k≥j 输入取原 G 的输入；所有非首内部数值父按复制位置对应，早于 G 的外部父不动。
新首完整键等于原 K(G)。该结论也允许 G 是 X 的所属结点。

### 证明

父链包含关系给出 G 是 X 的每个 P_k 祖先，k<j。
因此这些坐标的非负增量及屏障搜索与完整列表移植的前 j 行相同：
活跃部分一起平移；未活跃搜索若向外越界，其值不大于 G_k，
跳过新接入的全部较高候选，回到原外部父。

在边界行 j，共同 P_j 代表先给出相同的实际父位置及 G_j=X_j。
若不存在父，二者坐标同为零。若从 G 到 X 的 P_(j−1) 链上有值小于 G_j 的新位置，
它或更近位置就会成为 X 的 P_j 父，与共同的旧父矛盾。
故这段链上所有值≥G_j。

复制内第 j 坐标不变。搜索若在首之后停止，输入链和决定比较均按来源对应；
若需要越过首，它的查询值≤G_j，因而略过上述新接入链段，仍到原外部父。
新首本身的查询正是原 X 的查询，也就是原 G 的 P_j 输入。

对 k>j，前一行父已经逐位置对应，整行坐标又没有变化，故最近较小搜索原样对应。
归纳得到所有父运输、差一条件及所属第一坐标间隙。
内部相对于新首的激活模式保持；前 j 行的活跃相对差抵消，
其余行的首值及内部值均不动，故完整键等于 K(G)。

完整 P0 块的所有材料都是 G 的 P0 后裔，外部输入只能早于 G；
所以该论证适用于整个块，不局限于首的附属列表。
即使原块包含 X，搬到 X 后的是原有限块的一份副本，不是自引用。

## 从块不等式到键不等式的准确条件

若该对满足 SB_j，且 G 与 X 的第 j 至 d−1 坐标全相同，则

    K(G)≥K(X)。

因为部分变基后两个首的全部数值坐标相同；首列表先于块的后续主列比较，
所以块不等式先迫使首列表不小于 X 的列表。
在 X 处的共同进入数据下，键编码严格保序，而移植列表的键仍为 K(G)。

若更高的某个数值坐标已决定严格大于，则不能再推出最高键比较。
这是二坐标证明推广到高维时必须补出的分支；不是只把原 SB 换一个下标。

## 最高捐赠中可使用的源不等式

设 T 带列表 Q 后接空森林，Y 位于真列表 Q 内，且 (T,Y) 满足 SB_j 的假设。
若第 j 至 d−1 数值坐标都相同，上一节给

    K(Y)≤K(T)=K_T(Q)⌢[空森林键]。

Y 的列表是 Q 的真正内部子结构，它的完整键结构编码严格短于 Q 的编码，
所以它不等于 K_T(Q)，也不等于 K_T(Q) 后接空森林键。
后两者之间又没有键值，故

    K(Y)<K_T(Q)。

若更高坐标先决定 T 严格大于 Y，则应使用那个数值差异，不必也不能强求这个键不等式。
这给出源侧的新首与捐赠内部结点比较所需的两类理由。
把它们通过全部跨份数改写运输，仍属于 SB_j 保持性的未决部分。

## 有限检查

`check_partial_rebase.py` 检查5000个原始合法森林中的12964对位置，
重算697753条数值父；其中5853对首有附属森林、4334对 G 是 X 的所属结点、
3854对更高数值坐标并不全相同。全部输出通过数值合法性及新首完整键一致性检查。
用时约3.09秒，无失败。这些不是标准路径证书，也不是一般证明的替代。

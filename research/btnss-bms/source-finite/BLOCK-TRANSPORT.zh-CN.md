# 完整块变基与固定外部根

> 收录说明：本篇为配套局部引理，不单独承担整个比较定理。总体状态以[主证明](../upper-bound.zh-CN.md)为准。实验脚本与旧研究日志的文件名是历史来源记录，未作为可运行附件收录。

本节补充最高分支块比较所需的两个局部计算。
它们区别于只移动根的附属列表，也不把原块里的某个复制位置与进入作用域中的原位置混同。

## 完整块的最高变基

设 G 是 X 的最高数值 P_(d−1) 祖先，且 G 不是 X 的所属结点。
将完整 P0 块 B_G 放到 X 的位置：各行按以 G 为根的激活加 X−G，
删去首的原列表，改装 X 的完整列表。记为 A_(G,X)(B_G)。

列表移植的逐行证明适用于整个块的非首材料：每个位置是 G 的 P0 后裔，
其外部数值父早于 G。各行在活跃链前段一起平移；外部搜索值≤G_j，
略过从 X 回到 G 的所有新接入高值位置，得到原外部答案。
因此非首内部父按复制位置对应；新首输入是 X 的输入。

原首列表在 X 前已经关闭，列表内部的任何位置都不可能成为块内后续主列的数值父。
删去它、装入 X 的列表不改变这些后续数值父。新首的各个附属森林则按 X 的作用域读取。
这是非所属条件在此处的用途。

所有非首来源 v 的根激活仍恰为原 G 祖先指示。
此结论不要求某行的活跃位置在整个 P0 块中连续，只要求它在各自的搜索链上满足屏障性质。

## 变基合成

设 H、G、X 依次位于同一最高数值祖先链；H 非 G 的所属，G 非 X 的所属。
各操作在相应原进入作用域中读取，列表用相应原结点的完整列表。
则逐位置有

    A_(G,X) A_(H,G)(B_H) = A_(H,X)(B_H)。

第一次变基保持非首位置相对于新首的全部激活。
对每行 j，活跃位置接受的两个增量相加为

    (G_j−H_j)+(X_j−G_j)=X_j−H_j；

不活跃位置两次均不动。树形只作两次深度重定位，增量同样相加。
第二次删去第一次安装的首列表，最后安装 X 的列表。因此全部坐标、森林和列表相同。

两块若有同一首坐标及同一完整首列表，更换该相同列表并进行同一变基保持比较方向。
不能对首列表原本不同、且大小由那个列表决定的两块无条件使用这句话。

## 固定外部根的变基公式

设 G 在复制根 R 之前，X 是普通或捐赠材料的来源位置，且 G 是 X 的非所属最高数值祖先。
R 可以出现在 B_G 的后续主列中；搬走块时，那一列是 R 的新副本，
不能与仍在进入作用域中的原 R 当作同一位置。

固定一份全局平移量 δ（不激活的行相应置零）。记 r_j(X) 为原 R 是 X 的 P_j 祖先的指示，
因此对应目标坐标为 X'_j=X_j+r_j(X)δ_j。
在原 X 的进入作用域中，对一个虚拟森林作同样的 R 激活平移，记为 S_R^X。

取以 G 为首、外部输入早于 G 的固定块 W。先计算 A_(G,X)(W)。
对其非首来源 v，变基后相对于原外部 R 的激活恰为

    1[G P_j^* v]·r_j(X)。

因为内部父按复制位置对应，原 R 即使是 W 的内部来源也已经成为另一个位置。
一条路径要到原外部 R，只能经新首 X 出界；若不经过新首，外部输入早于 G，
而 R 晚于 G，不可能再遇到 R。

于是非首位置在 S_R^X 后的第 j 坐标为

    v_j+1[G P_j^* v](X_j−G_j)
       +1[G P_j^* v]r_j(X)δ_j
      =v_j+1[G P_j^* v](X'_j−G_j)。

首列表改装为其平移像后，得到精确公式

    S_R^X A_(G,X)(W) = A_(G,X')(W)。

右侧仍使用同一个固定 W，而不是已经作全局基本列改写后的 W'。
这不是把 S_R 从 A 的右侧随意移到 W 上；若 W 含原 R 的来源位置，那样的另一公式一般没有根据。

## 延迟改写的用法与边界

比较 A_(G,X)(B_G) 与 B_X 时，两边进入数据同为 X；
故 S_R^X 对两边严格保序，即便一边的来源块包含原 R。
若随后 B_G 与 B_X 都在原 T 处改写，T 在左侧对应编码中的出现有严格正偏移。
右块的首处下降因而早于左块的对应改变，可使用源延迟改变引理。
若 B_X 在 T 前已关闭，左侧改变位于完整右块之后。

实际应用仍须逐例确认：此前没有别的首列表替换、该端点不是新首、
右侧改写确为此前不变的首次下降、闭合森林没有泄露父输入。
本节提供固定外部根的计算公式，不代替跨份数祖先对的分类证明。

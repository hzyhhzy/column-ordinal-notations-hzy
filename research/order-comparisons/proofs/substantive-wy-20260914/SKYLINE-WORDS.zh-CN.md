## 0. 结论及边界

当前已写出两条分开的纸面证明链：

1. 在下述 S 中，新标准域的列字典序良序，展开严格下降，基本列共尾。
2. 依据已逐项核对的 wY 有限几何引理，每个标准 wY 图在新规则下仍是标准图，
   因而新序型不小于 wY。

\[
S=KP_\omega+\exists\nu\,[\nu\text{ 为不可数序数}].
\]

这里 KP 使用完整集合归纳；不可数意为不存在集合满射 \(\omega\twoheadrightarrow\nu\)。
不增加幂集、一般选择或大基数。新证明尚未写成 Lean。

**尚未证明新序型严格大于 wY，更未证明增幅不是一个很小的闭包。**
规则的确在有限项内部改变了维度再生，但这不能代替严格序型比较。
因此尚不能把“实质性的大幅增强”标成已经完成。

## 1. 一个表达式到底存什么

表达式是有限列序列 \(G=C_0\cdots C_x\)。第 j 列是一张关系表，行写成 `(p,W)`：

- `0 <= p < j` 是父列地址。
- W 是非空词 `(r,u1,...,ud)`；`r <= p`，且 `r < u1 <= ... <= ud`。
- 全部字母来自 `{0,...,p} union {j}`。j 表示本列 SELF，其余是前面的 ROOT 地址。

例如 `[2:(0);0:(0,3)]` 是第 3 列的两条关系。没有树、操作历史、原始 wY 数值或隐藏共享字典。
空列写 `[]`；空表达式写 `0`。

词序是三重字典序

\[
W\longmapsto(r,d,(u_1,\ldots,u_d)).
\]

先同父取最大词，然后父从大到小扫描，只保留比此前保留词都严格大的行。
这个操作记为 \(\operatorname{sky}\)。在最终列中，父严格递减而词严格递增。

**比较表达式：** 先比最左不同列；列内逐行按 `(父,词)` 的通常字典序比较；
真前缀较小。不是把父的比较反过来。非空列的控制行恰为最后一行。

原始良形图和标准式必须分开：实现允许输入任意上述良形图，用于局部引理和诊断；
不是说所有原始图都在同一个良序标准域内。

## 2. 有界词前驱

给定父 p、子 j 及 \(B\ge d(W)\)，定义

\[
\operatorname{pred}_B(W;p,j)
 =\max\{V<W:V\text{ 为该字母表上的合法词},\ d(V)\le B\}.
\]

无候选则返回“删边”。无需枚举：

1. 从右向左找可减小的尾字母，换成字母表前驱，并把右边全部填 SELF。
2. 没有这种位置且尾部非空：尾长减一，尾部全部填 SELF。
3. 单字词 `(r)` 且 r>0：改成 `(r-1,SELF,...,SELF)`，尾长 B。
4. `(0)`：删边。

第一步仍须保持非降和首根不重复；SELF 的前驱是 p，不是 j-1。
有限同长度字典序、长度层、首根层依次借位，故此算法正是上述最大值。

## 3. 展开规则

空式不变。非空式的 `[0]` 删除末列。末列为空时是后继，所有 `[n]` 都删末列。

其余设旧末列为 x，控制父 c，块宽 \(w=x-c>0\)，旧图最大尾长 D。
**D 和所有来源列在本次调用期间固定，不读取已经生成的输出作新来源。** 定义

\[
\phi_b(i)=\begin{cases}i&i<c,\\ i+bw&i\ge c,\end{cases}
\qquad B_b=D+\lfloor\log_2(b+1)\rfloor.
\]

先保留 \(C_0,\ldots,C_{x-1}\)。然后对 \(b=0,\ldots,n-1\) 追加一块：

1. 将旧末列按 \(\phi_b\) 搬运，只把其控制词换为目标字母表上的
   \(\operatorname{pred}_{B_b}\)，无结果则删该行。
2. 合并 \(\phi_{b+1}(C_c)\)，再取 skyline，作为本块接缝列。
3. 追加 \(\phi_{b+1}(C_{c+1}),\ldots,\phi_{b+1}(C_{x-1})\)。

两份接缝同址，因为 \(\phi_b(x)=\phi_{b+1}(c)\)。输出恰有 \(x+nw\) 列。
这就是全部展开规则，不执行后文的 wY 模拟宏，也不调用 wY 原引擎。

标准域定义为全部种子

\[
S_m=[][0:(0,\underbrace{1,\ldots,1}_{m})]\quad(m\in\mathbb N)
\]

的有限展开后代之并。有 \(S_{m+1}[1]=S_m\)。标准域本身不加外部最大元。

## 4. 美观条件与完整字符串界

每块只依赖原输入和块号 b，不依赖最终 n，所以 G[n] 是 G[n+1] 的列前缀。
极限时每次增加 w 列，是真前缀；G[0] 正好删末列。

首个接缝中，父大于 c 的行不变，父 c 的词严格减小或删除。
来源列仅加入父小于 c 的行。skyline 至多进一步删除 c 或更小父的行，
不改变高父前缀，故所有非空 G 均满足 G[n]<G。

固定极限输入 G，每块除一条控制词外都是固定来源副本；控制词尾长至多
\(D+\lfloor\log_2(b+1)\rfloor\)。每个地址至多 \(O_G(n)\)，通常十进制写法占
\(O_G(\log(n+2))\) 字符。因此完整标准串满足

\[
\Omega_G(n)\le |\operatorname{str}(G[n])|
 \le O_G(n\log^2(n+2)).
\]

包括每一个地址、关系和分隔符，不靠省略号、乘幂写法或运行轨迹压缩。
原字母表和列序比较也均可计算。

## 5. 良序上界：先证自由图，再投影

### 5.1 词的实际集合序数秩

暂在 S+V=L 中，取最小不可数序数 \(\kappa\)，令 \(K=\kappa+1\)、
\(\Omega=K^\omega\)、\(B_d=\sum_{i<d}K^i\)。对语义词定义

\[
h(r,u_1,\ldots,u_d)
=\Omega r+B_d+\sum_{i=1}^dK^{d-i}u_i
<\Lambda:=\Omega K.
\]

有限 K 进制向量严格保持固定长度字典序；各长度层依次排列，各首根层再依次排列。
因此 h 严格保序。有限积和可数序数和在 KP 中构成实际集合函数。
任何严格递增地址重标都保持词序，固定有限词模板的比较可化为有限底层比较。

### 5.2 有限反射关系不是新公理

语义边写成 R(t,a,b)，守卫为 \(\omega<a<b\le\kappa\)，
t 的 ROOT 不超过 a、SELF 为 b。
对有限图 H 的递增标签 f，Rep(H,f) 表示其全部边的 R 事实成立；
End_b(N,f) 表示有限末端需求 N 在虚拟端点 b 成立。

R(t,a,b) 的递归子句是：每当

\[
\operatorname{Rep}(H,f),\quad f(c)=a,\quad \max f<b,
\quad \operatorname{End}_b(N,f),
\]

且每个需求 `(u,parent)` 严格小于 `(t,a)`，存在新表示 g，使

\[
\max g<a,\quad g\restriction c=f\restriction c,
\quad\operatorname{Rep}(H,g),\quad\operatorname{End}_a(N,g).
\tag{FR}
\]

按 `(b,h(t),a)` 递归，编码阶段小于实际集合序数
\(((\kappa+1)\Lambda)(\kappa+1)\)。内部及输出查询的端点较小，
同端点需求的 `(词,父)` 较小，所以没有读取未来关系。
标签向量、有限模板和图代码均有集合源；每步定义有界，
用 KP 的分离、收集及相容历史的唯一性构成 R。
从允许请求包含直接得同父词弱化；**没有跨父弱化**。

### 5.3 表示供应的明确接口

这一步的完整集合论账本见
[IPD 的见证闭包证明 §4、§12](../new-notation-20260914/IPD-KP-WELL-ORDERING.zh-CN.md)，
这里不调用其树秩定理，只把有限模板替换为上述词。
具体所用闭包只有：

- `Bad`：对每个固定控制词模板、有限 ROOT 参数和父值，选择一份最小失败请求的各坐标。
- `Ext`：对每个固定请求形状和切点以前的前缀，选择一份最小完整扩充表示的各坐标。
  **不固定新切点的值，不把旧控制词或切点以后的参数一起固定。**
- 对每个非零 \(\alpha<\kappa\) 的统一自然数枚举操作。

前两类最小化只在已构成的 R 与有限标签集合内进行。
按形状码再按固定长度标签字典序取最小包，具有有限序数积给出的实际秩。
操作只有可数多个有限模板；有限闭项的值域是一个可数、向下封闭的序数
\(\omega<\delta<\kappa\)，并可取在任意给定 \(\gamma<\kappa\) 之上。

按 `(h(t),a)` 归纳，Bad 闭包给出端点 \(\delta\) 与虚拟端点 \(\kappa\) 的一致性；
Ext 闭包给出控制父为 \(\delta\) 时的强供应。控制词含 ROOT=\(\delta\) 也可处理，
因为 Ext 不把这份控制词作为低于 \(\delta\) 的参数。
取有限多个递增闭包高度即可表示任意有限良形图。

构造性内模型和集合满足关系所需的通常 KP 基础见
[McKenzie，§2，Lemma 2.6 与 Theorem 2.8](https://arxiv.org/html/1806.08500v4#S2)；
普通 KP 的内模型路线与 Power KP 的区别见
[Rathjen，引言](https://arxiv.org/html/1801.01897v1)。
本证明采用显式 Bad/Ext 后，不必把整个宇宙真值作为闭包操作。

### 5.4 固定来源的整块拼接

先对只做同父最大、不作 skyline 的自由版本证明严格下降秩。
给原表示末标签 \(\beta\)，在块 b 维护旧来源前缀的精确标签，
及旧末列仍在虚拟端点 \(\beta\) 的事实。

控制词在搬运后严格降低，同父弱化给出降低事实；其余旧末列行的 `(词,父)`
都较小，故全部是 FR 的合法末端请求。FR 将当前输出压至控制父标签 a 以下，
固定更左标签；接缝取旧标签 a，再接旧来源标签的剩余部分。

接缝所合并的来源 C_c 在 a 处已有事实，ROOT 都在切点左边，SELF 原来就是 a。
它们**不需要**比控制词小，也不作为 \(\beta\) 处的 FR 请求。
逐块恢复精确来源标签等式，得到完整输出末标签严格小于 \(\beta\)。

令 \(\mu(H)\) 为所有自由表示中的最小末标签，空图取 0。
供应及有界分离给出实际集合函数，以上证明
\(\mu(\operatorname{FS}_{free}(H,n))<\mu(H)\)。

### 5.5 Skyline 的关键投影引理

令 \(\Pi\) 逐列删除受 skyline 支配的行，保留全部列。
任一 H 的表示仍是 \(\Pi H\) 的表示，所以

\[
\mu(\Pi H)\le\mu(H).
\]

对 skyline 输入 G，源码及固定来源公式直接给出

\[
\operatorname{FS}_{sky}(G,n)
 =\Pi(\operatorname{FS}_{free}(G,n)).
\tag{Projection}
\]

原因是每块读取同一原图，局部正规化可以推迟到整次输出结束；
没有后块读取前块已删除关系的情况。因此

\[
\mu(\operatorname{FS}_{sky}(G,n))
\le\mu(\operatorname{FS}_{free}(G,n))<\mu(G).
\]

这里不必恢复被删除的跨父事实，也不把“skyline 支配”误读成 R 的语义单调性。

### 5.6 从展开到标准列序

对 \(\mu(G)\) 归纳：G 的任意两个真后代分别来自 G[i]、G[j]，设 i<=j。
G[i] 是 G[j] 的前缀，因而可由删末列从 G[j] 到达。
两者属于同一个秩更小的后代锥，归纳给出它们按可达性可比。

可达性严格降低列字典序，于是每个后代锥内，严格可达性与严格列序相合。
种子相互嵌套，任意两个标准式有共同种子祖先，故 \(\mu\) 在整个标准列序上严格保序。
对任何非空标准式子集最小化其 \(\mu\) 值，即得良序；不需要依赖选择。

任何标准 H<G 均由 G 可达，路径首步给出 H<=G[n]，所以基本列共尾。
末列为空时唯一后代入口是删列项，确为后继；非空时基本列严格增长，确为极限。
不同标准列列表在此良序上对应不同序数，不会因不同操作路径重复定义两个相等元素。

最后在 L 内构成的是实际集合秩 \(\mu\)，不是只得一个内部“无下降链”断言。
环境不可数序数在 L 内仍不可数，有限语法与计算绝对，秩不等式也绝对；
把 \(\mu\) 转回环境后再作序数最小化，去掉 V=L。

完整独立核对见 [SKYLINE-UPPERBOUND-AUDIT.md](SKYLINE-UPPERBOUND-AUDIT.md)。

### 5.7 标准域可判定，精确序数值与反射秩分开

给定宽 m 的目标 X，可从第二列显式选一个足够大的种子 S：
第二列为空取 S_0；非空且尾长 d 取 S_(d+1)。若 X 标准，它必为这个 S 的后代。
令 `T_m(A)=prefix_m(A[m])`。末列以外不改动及 `[0]` 逐列删除保证：
A 的所有宽度至多 m 的真后代，也都是 T_m(A) 的后代。

所以从 S 反复取 T_m，遇到 X 则接受、降到 X 以下则拒绝。
固定宽度的所有 raw 图可按列存在标志、各父行存在标志、首根、尾长与尾整数码，
保序编码到固定有限长自然数字典序向量；该链必有限终止。
这项终止不需要先使用不可数反射，完整论证见
[STANDARD-DOMAIN-AUDIT.md §3](STANDARD-DOMAIN-AUDIT.md)。

此成员算法可能极慢，当前 Python 构造器没有实现它，只检查并正规化 raw 语法。
若未来加预算验证器，超限必须返回“未知”，不能返回“不标准”。

精确序数解释取标准良序中的位置 \(|A|\)。它满足后继和基本列上确界等式。
\(\mu\) 只是用于证明良序的下降秩，未证明其无间隙或保持上确界，不能与 \(|A|\) 混同。
标准域可判定且列序可计算，故各表达式确实表示递归序数。

## 6. 整体不小于 wY：不是一步支配的重复使用

\(\Phi(s)\) 记录 canonical wY 山脉每个父列的最高规范祖先词。
已核对的有限几何给出：Phi 严格保序，且所得列为 skyline。
所用来源是用户提供的 `omega-Y-Weak-Magma-KP.pdf`，不是把其整个良序结论当作桥。

### 6.1 单位减一的精确目标

设旧末列 \(C_x=R+(c,T)\)，R 的父都大于 c。
删掉实际顶单元后的保留低部为 L=R+(c,U)，或 U 缺省时 L=R。
令 Q 为来源 C_c 把 SELF 从 c 改到 x。有限嫁接引理给出

\[
D=\operatorname{sky}(L\cup Q)=\Phi(s\text{ 末数值减一})_x.
\]

这里 Q 的父和 ROOT 都小于 c；L 的父都至少为 c。
完整来源比真实嫁接上尾多出的下部，恰被 skyline 删除。

若 U 存在且首根小于 c，其尾长不超过固定 canonical 前缀的最大尾长，
因为它的父盖存在且维度不增。若比较词 V 与 U 同首根且 V>U，
则 U 的尾长又不超过 V 的尾长。所以有界前驱不能跳过这个**特定** U。

### 6.2 带指定切点的局部宏

从形如 `R+(c,V)+S` 的列开始，其中 S 的父小于 c，V>U，
且已经认证目标为上面的完整 graft 分解。反复只取首块，再用 `[0]` 截回固定宽度。

- 控制父小于 c 时，仅修改 S，保留 R 与 c 行。
- 控制父为 c 时 S 为空；前驱不能跳过 U。首次到 U 就精确生成 D。
- 无 U 时，第一次使 c 行删除或被 R 支配，同样精确生成 D。

固定宽度下首块尾长不增，候选列有限且严格下降，所以此宏必有限终止。
最后穿越目标的控制父仍为 c。它是有限存在证明，不是新展开器执行的算法。

**任意自由较大列不跳过目标是错误命题。** 本宏依赖平台和指定切点证书；
反例及完整有限论证见 [局部宏证明](SKYLINE-NOSKIP-PROOF.md)。

### 6.3 来源改变的接缝吸收式

令 \(\tau_b(i)=i\)（i<c），否则 \(i+bw\)，记 \(D_b=\tau_bD\)、\(L_b=\tau_bL\)。
对 a<b，把 \(D_a\) 的 SELF 改到第 b 接缝，但其父和 ROOT 不动，记为 \(\sigma_{ab}\)。则

\[
\operatorname{sky}\bigl(L_b\cup\sigma_{ab}(D_a)\bigr)=D_b.
\tag{Abs}
\]

Q 的全部非 SELF 参数小于 c，所以其旧来源与新来源完全相同；
旧 L 行的父较小、ROOT 逐坐标不大于对应新 L 行、SELF 相同，故被新 L 行支配。
再用 `sky(X union sky(Y))=sky(X union Y)`，连之前删掉的 Q 行也一并处理。
这是有限行集代数，不是跨父 R 单调性。

### 6.4 精确模拟完整旧基本列

ordinary wY 复制在 Phi 中恰是上述纯地址搬运，不只是一个不等式；
加强为等式的有限几何理由见 [精确复制审计](../wy-linear-20260914/exact-copy-audit.md)。
因此旧第 n 项由 n 个 D_b 接缝和固定普通来源列组成。

对第 b 个接缝逐一修正。在局部宏最后一步之前，改取新 `[n-b]`，重建剩余全部块。
较早接缝已精确，普通来源列仍是旧纯副本；未来接缝或者已精确，
或者只在同一个 pivot 上比目标大，能继续使用带证书宏。

从第 1 块起，实际来源切点列是前一已修接缝，而不是旧 C_c。
一般式 Abs（不只相邻版本）恰保证这种更早来源会被当前低部吸收。
若 U 存在，已修前缀还保存其相同尾长，后续有限前驱始终容纳目标。
如此至多 n 次有限宏，精确得到 \(\Phi(s[n])\)。

故对每个 canonical s，存在新规则下的有限路径

\[
\Phi(s)\longrightarrow^*\Phi(s[n]).
\]

共同种子 \(S_m=\Phi(1,m+2)\) 加上路径归纳，得到

\[
\Phi(\operatorname{Std}_{wY})\subseteq\operatorname{Std}_{sky},
\qquad \operatorname{type}(wY)\le\operatorname{type}(\operatorname{Std}_{sky}).
\]

完整多块归纳见 [GLOBAL-COVER-BRIDGE.md](GLOBAL-COVER-BRIDGE.md)，
独立逐项复核见 [LOWERBOUND-INDEPENDENT-AUDIT.md](LOWERBOUND-INDEPENDENT-AUDIT.md)。
这不宣称 Phi 像为初始段，也不宣称严格不等式。

## 7. 内部再生及尚存的强度障碍

令

```text
A=S_1=[][0:(0,1)]
G=A[2]=[][0:(0)][1:(1)]
G[4]=[][0:(0)][1:(0)][2:(1,3)][3:(2,4)][4:(3,5,5)]
```

有 \(D(G)=0\)，但 \(D(G[n])=\lfloor\log_2n\rfloor\)。
旧 wY 固定输入一次展开的维度界性质已经被实际改变，而非只换字符串显示。

不过更强的不变量提醒我们不要过早下结论：记

\[
M(G)=\max\{d(W):(p,W)\in G,\ \operatorname{root}(W)=p\},
\]

空集最大值约定 0，则 \(M(G[n])\le M(G)\)。复制保持根父相等关系；
唯一会增加尾深的借位降低了首根，使它严格小于父，因此不能增加 M。
任何固定 S_m 后代都不能包含根父相合、尾深大于 m 的边。

所以再生见证不能直接容纳任意大的地址平移 wY 种子。
这不证明同序，也不排除别的编码；它解释了严格增强论证还缺什么。

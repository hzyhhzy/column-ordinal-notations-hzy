# Skyline 局部桥接审计：自由 no-skip 的反例与 canonical 单位减一宏

## 0. 结论

1. 旧命题「固定 canonical 左前缀，任意自由 skyline 列 C>T 一步不跳过 canonical 目标 T」是假的。第 2 节给出完整小反例。
2. 需要的更窄结论可以保留：从 canonical 原列本身开始，反复做第一块局部步骤，必能精确命中其 canonical 数值减一列；首次命中的最后一个控制父仍是原控制父。
3. 这个单位减一宏只需有限组合归纳。固定宽度、第一块尾长上界不增，局部列严格下降且可选列有限，不需要调用新记号良序性来保证宏终止。
4. 宏的两个核心有限引理是「目标词尾长界」和「完整父列 skyline 嫁接」。它们在第 3、4 节给出证明。

第二点不是把第一点换个说法：只断言原 canonical 列产生的特定局部轨迹，不量化所有位于其下的自由列。

## 1. 记号及局部操作

第 j 列的关系写成 `(p,W)`，其中 `p<j`，W 是非空、非降的规范词，字母来自

    {0,...,p} union {j}。

首字母是 ROOT，首字母的初始重复只保留一次。词序依次比较首根、尾长、尾部字典序。列先按父递减排列，再按通常的 `(父,词)` 字典序比较。

`sky` 先对同父取最大词，再按父递减扫描；只保留严格大于此前最高词的行。因此非空 skyline 列的末行也是其最大词控制行。

固定前缀 P，宽度为 j，末列 C，定义第一块局部操作 `L_P(C)`：

1. 设末行为 `(c,W)`，令 B 为 P+C 中所有词的最大尾长。
2. 在字母表 `{0,...,c} union {j}` 上，将 W 改为尾长不超过 B 的最大严格较小词；不存在则删行。
3. 合并整个来源列 `P[c]`，其中原 SELF 地址 c 改为 j，其他 ROOT 地址不变。
4. 取 skyline。

其余末列关系保留。它等于新系统 `FS[1]` 的前 j+1 列；复制出的更右列可以逐次用 `[0]` 删除。

## 2. 任意自由列 no-skip 的反例

取原始 wY 前缀

    p = (1,3,4,3)，
    P = Phi(p)
      = [][0:(0,1)][1:(0)][0:(0,3)]。

canonical 目标末列为

    T = Phi(1,3,4,3,5).last
      = [3:(0);0:(0,4)]。

取自由 skyline 列

    C = [3:(0);2:(0,1)]。

确有 C>T：首行相同，第二行父 2 大于父 0。C 合法且词严格增加。

整个输入 P+C 的最大尾长 B=1。控制行为 `(2,(0,1))`，其有界最大严格前驱为 `(0)`。来源第 2 列为 `[1:(0)]`，搬运 SELF 不改变该单词。因此合并前为

    [3:(0);2:(0);1:(0)]。

skyline 删除后两行，故

    L_P(C) = [3:(0)] < [3:(0);0:(0,4)] = T。

这完全反驳了原先量化「任意 canonical T、任意自由 C」的命题。它不证明反例目标或 C 属于新记号标准域；也不宣称原目标 `(1,3,4,3,5)` 是 wY 标准式。实际上，已检查的一条标准前缀导向路径在第五项只能达到 4，不能用这条路径证明目标标准性。

反例中的 C 并非必须发生在从同一前缀的 canonical 上界出发的局部宏中。因此不能由它推翻第 5 节的更窄命题。

## 3. Canonical 目标词的尾长界

令 P 是 canonical 左前缀，`D_P` 为它存储的所有最高轮廓词的最大尾长。对新列中任一 canonical 单元 e，若其父为 c、词为 U，则：

> 若 U 的首根 r<c，则 U 的尾长不超过 `D_P`。

证明：如果 e 的父脚没有上盖，轮廓定义给出 `U=(c,SELF^d)`，首根必为 c。因此 r<c 强制父盖存在。该父盖及其整个 cap 祖先链都位于 P。父盖界给出 `d(e)<=d(parent-cap)`；覆盖末 d 个坐标不会使词长超过 P 的最大几何维数加一。此前 `CANONICAL-PROFILES.zh-CN.md` 第 3 节已证明，canonical 图的最大几何维数恰等于最高轮廓表中可读出的最大尾长 `D_P`。于是得到结论。

特别地，设 V 是任意同父 c 的合法词，且 V>U。则

    tail(U) <= max(D_P, tail(V))。

因为首根相同的情形直接由词序得 `tail(U)<=tail(V)`；首根不同的情形有 `root(U)<root(V)<=c`，可用上面的结论。

因此，只要当前输入仍包含原 canonical 前缀 P，有界最大前驱 `pred_B(V)` 的候选集中就一定包含 U，其中 `B=max(D_P, 当前末列最大尾长)`。由最大性有

    V>U  ==>  pred_B(V)>=U。

这里不假设原数值很小，也不假设 U 的尾长直接小于 V 的尾长。

## 4. Canonical 减一等于完整父列 skyline 嫁接

设原 canonical 末列顶单元为 t，左脚位于父列 c，左脚高度为 L，右脚高度为 B，高度记为 sigma。令 `Low` 是删除 t 后保留的旧非底单元按父取最高词所得的表。令 `Move(P[c])` 只把来源列的 SELF c 改为 j。

则 canonical 数值减一列精确等于

    D = sky(Low union Move(P[c]))。

证明分两部分。

- 父脚以上的来源单元：论文 Lemma 2.3 的 equality graft 说明 canonical 减一恰嫁接来源列的整个上尾。其左脚都位于 c 以前，因此 profile 只需改变 SELF。得到的轮廓严格高于 Low，且形成 canonical skyline；这些单元正是应保留的来源部分。
- 父脚及以下的来源非底单元：论文 Lemma 6.1 的初始 anchor 结论说明，原末列保留低部在同高度存在一个单元，其 profile 恰为该来源单元的 profile、仅把 SELF c 改为 j。注意两者父列不必相同，不能错误地把这里当成逐父相等。但所有 Low 单元的父都至少为 c，而来源列每条关系的父都小于 c。故 skyline 在处理任何来源关系之前已看过 Low 的全部关系；来源下部的词至多为 Low 的最高词，必被删除。

同父取最高词不影响结论：若一个来源父段横跨左脚高度，其上部较高词胜出；若整个段位于左脚以下，它仍被 Low 最高词删除。若 Low 为空，则左脚以下也没有来源非底单元，否则 Lemma 6.1 会在 Low 中给出对应单元。

因此完整来源列比实际嫁接上尾多出的关系全部、且仅仅在 skyline 中被丢弃，得到精确等式。

本证明使用的是论文有限几何 Lemma 2.3、Theorem 5.5 和 Lemma 6.1 的初始轮次，不借用不可数反射或展开良基性。第 6.1 节关于后续复制轮次的部分不需要用于本局部等式。

## 5. Canonical 单位减一宏

### 5.1 命题

固定 canonical 前缀 P，令

    U = Phi(p,a).last，a>1；
    D = Phi(p,a-1).last。

从 U 反复施行 `L_P`，必在有限步后精确命中 D。第一次命中 D 的最后一步，其控制父恰为原 U 的控制父 c。

### 5.2 原列的分解

写

    U = R followed by (c,T)，

其中 R 的父都大于 c。删除实际顶单元后，保留低部有两种形式：

- 同父段仍有单元：`Low=R followed by (c,U0)`，且 `U0<T`；
- 同父段没有单元：`Low=R`。

由第 4 节，目标 D 精确等于 `sky(Low union Move(P[c]))`。

### 5.3 命中前不变量

在第一次命中 D 以前，当前自由列保持形式

    R followed by (c,V) followed by S，

其中 S 的父均小于 c。若 U0 存在，则保持 `V>U0`；若 U0 不存在，V 仍严格大于 R 的最高词，所以 c 行没有被 skyline 删去。R 为空时该最后要求只表示 V 非空存在。

初始时 S 为空，V=T。考察下一步：

- 控制父小于 c 时，只能修改 S 中的末行，并继承更小父列的关系。按父递减扫描使这些操作无法改变 R 或 c 行，不变量保持。
- 控制父为 c 时，由于 controller 是末行，S 必为空。设替换词为 v。
  - 若 U0 存在，第 3 节保证 `v>=U0`。若严格大于，c 行仍被保留，不变量保持；若等于，本步输出就是第 4 节的 D。
  - 若 U0 不存在，只要 v 尚严格大于 R 最高词，c 行保留，不变量继续。当 v 不存在或不再严格大于该词时，c 行由 skyline 删除；本步输出就是 `sky(R union Move(P[c]))=D`。

因此每一步要么保持严格高于 D 的上述不变量，要么恰好命中 D；不能在原控制父位置越过目标。

这里关键是「从原 canonical U 开始的轨迹」。第 2 节反例从一个人工加入父 2 的自由列开始，没有这个不变量给出的原始 U、c、U0 与来源嫁接关系。

### 5.4 有限终止，不需要先引用良序定理

局部操作始终只作用于固定宽度 j+1，保留前缀 P。

- 它在原末控制父处严格降低词或删除该行，新增关系只有更小父，所以整个末列严格下降。
- 第一块的有界前驱使用当前最大尾长，没有对数块号增量；父列搬运也不改变词长。因此全图最大尾长不增，始终不超过初始有限值 D0。
- 固定父 p 的字母表有限，尾长至多 D0；每个父最多一行。故可能出现的末列只有有限多个，skyline 只是其中的子集。

例如，不要求 skyline 的全部父表数量已由下式有限界住：

    product_(0<=p<j) [1 + sum_(0<=r<=p) sum_(0<=l<=D0) binom(p-r+l,l)]。

括号中的 1 表示该父缺省；二重和枚举首根 r 与长度 l 的非降尾。

故严格下降的局部轨迹不可能无限持续。只要仍在第 5.3 节不变量中，c 行还在，局部操作仍有定义；所以必在有限步内离开该不变量。而前节已证明唯一出口是由原父 c 控制的一步精确命中 D。

上述巨大有限界只是数学终止界，绝不建议据此实际暴力运行，也不能据此声称宏运行时间很小。

### 5.5 带切点证书的推广

上述归纳实际上还证明一个可复用的版本。固定 canonical P，给定 canonical 目标 D 与某个切点 c，并已经独立验证

    D = sky(R + (c,U0，可缺省) + Move(P[c]))，

其中 R 的父都大于 c；U0 若存在，就是 D 中父 c 的 canonical 词。若起始自由 skyline 列满足

    C = R + (c,V) + S，S 的父都小于 c，

且 U0 存在时 V>U0，U0 不存在时 c 行仍被保留，那么同一局部宏也精确命中 D，最后一步控制父为 c。

这是逐字复用第 5.3、5.4 节：目标 U0 的 canonical 性给出尾长界，原起始列本身的 canonical 性并不再需要。关键前提是目标的完整嫁接分解和起始平台，不是单独的 C>D。应用于后续块时，必须先证明这些前提，不能由块的外观相似直接推断。

## 6. 这能支持什么，不能支持什么

已经得到：canonical 数值单位减一可以在 skyline 新系统中用有限次 `FS[1]` 与删末列精确实现；最后一次局部变化的切点也与原 wY 减一切点一致。这个结论不依赖显式恢复巨大底值来定义新系统。

仍需主线处理：一次完整 wY 基本列包含多块拼接和所有中间来源列。把局部宏放到整个基本列的生成流程中，必须证明各接缝及后续纯复制列能同时实现或覆盖；不能仅凭本局部宏就宣布整个新标准域包含 wY。

另外，任意自由 C 的 no-skip 已被彻底反驳，不得在其他论证中继续以「已有大量测试」为由调用它。

## 0. 结论与依赖

本稿给出一个有限组合桥接：**每一次 canonical wY 基本列，均能在 skyline 新系统中用有限次新基本列和删末列精确到达。**
因而，若 skyline 新系统的标准域定义为共同种子的有限后代，则包含全部 canonical wY 标准图；列比较不变，得到整个序型至少 wY。

这里只证明下界桥，不另行证明 skyline 新系统良序，不声称严格大于 wY，也不声称该包含是初始段。
这三个问题必须与“至少 wY”分开。

本稿依赖 `SKYLINE-NOSKIP-PROOF.md` 第 3--5 节的有限引理：

1. canonical 低部同父目标词的尾长界；
2. canonical 数值减一等于完整父列合并后取 skyline；
3. 从 canonical 原末列出发的单位减一宏，最后命中切点仍为原控制父。

此外使用已审计的 canonical 最高词压缩的精确纯复制公式，见
`../wy-linear-20260914/exact-copy-audit.md`。
下面的新内容是“上一接缝吸收”及其多块归纳；并不使用已被反例推翻的任意自由列 no-skip。

## 1. 必须先排除的错误桥

仅知道新基本列第一步逐列不小于旧基本列，不能反复套用，因为新输出一般不 canonical。
仅知道固定 canonical 前缀时任意较大自由列不跳过目标，也不够处理未来尾部，而且该命题本身已经是假命题。

具体反例：

```text
P = Phi(1,3,4,3) = [][0:(0,1)][1:(0)][0:(0,3)]
T = Phi(1,3,4,3,5).last = [3:(0);0:(0,4)]
C = [3:(0);2:(0,1)] > T
L_P(C) = [3:(0)] < T.
```

本稿只使用具有确定 pivot/cut 证书的平台；不会把上面的 C 当成可随意替换的平台。

## 2. Skyline 的支配代数

行 `(p,W)` 被 `(q,V)` 支配，是指 `p<=q` 且 `W<=V`。
`sky` 恰好保留有限行集中未被较强行支配的行；同父取最大也包含在内。
因此

```text
sky(X union sky(Y)) = sky(X union Y).
```

严格递增地址重标与 `sky` 交换。在相同长度词上，逐坐标不增蕴含词序不增。
后者适用于下面仅把 SELF 换到新端点、但保留旧 ROOT 的比较。

## 3. 完整旧基本列的记号

固定 canonical 源图

```text
G = C_0 ... C_x,
C_x = R followed by (c,T),
w = x-c > 0.
```

R 中所有父严格大于 c。删除实际顶单元后，旧保留低部为

```text
L = R followed by (c,U)   或   L = R.
```

U 是原控制父段在减一后仍留下的最高词；不存在时不写这行。
设 Q 为来源列 C_c 把 SELF 从 c 改到 x 的结果。精确嫁接引理给出

```text
D = sky(L union Q).
```

L 的每行父至少为 c，Q 的每行父小于 c。L 中的行全部在 D 中保留。
设

```text
tau_b(i) = i              if i<c,
           i+b*w          if i>=c;
c_b = c+b*w;
x_b = x+b*w;
L_b = tau_b(L);
D_b = tau_b(D).
```

旧 wY 第 n 项的压缩图精确为原前缀 `C_0 ... C_(x-1)`，再接 n 块：

```text
D_b, tau_(b+1)(C_(c+1)), ..., tau_(b+1)(C_(x-1))
```

其中 `b=0,...,n-1`。块宽恒为 w。

## 4. 核心：上一接缝吸收引理

对 `0<=a<b`，令 `sigma_ab(D_a)` 只把 D_a 的 SELF 地址 x_a 改到 x_b，保留其父和全部 ROOT 地址。
则

```text
sky(L_b union sigma_ab(D_a)) = D_b.                 (Abs)
```

这是任何满足上述支持分解的词图都成立的有限等式，不要求 D_a 或 D_b 另由数值重建。

证明：由 `D_a=sky(tau_a(L) union tau_a(Q))` 和 skyline 幂等性，合并前可展开这份正规形。

- Q 的所有父、ROOT 均小于 c。因此对 Q 的每一行，

  ```text
  sigma_ab(tau_a(Q)) = tau_b(Q).
  ```

  两边只有 SELF 不同，统一换到 x_b 后完全相同。
- L 的每一行父 p 至少为 c。对应的旧行经 `sigma_ab tau_a` 后父为 `p+a*w`，
  而 L_b 中对应行父为 `p+b*w`，后者严格更大。对词中 ROOT：小于 c 的坐标两边相同，
  大于等于 c 的坐标后者更大；SELF 两边均为 x_b。因此旧行的词不大于当前对应行，
  被 L_b 中该行支配。

故合并旧接缝，等效于仅合并 `tau_b(Q)`，所得恰为 D_b。
先前被 `sky` 删除的 Q 行不会造成遗漏：删除它的旧 L 行也被当前 L_b 支配，所以正规化的幂等性正好覆盖这一点。

这解决了此前的实质障碍：后一块的实际来源切点列是上一个 D，而不是原 C_c。
不能说它们相等；准确事实是经当前低部吸收后得到同一目标。

## 5. 带切点证书的局部修正宏

固定宽度和前缀 P，设指定切点 c 的来源列为 P[c]，目标

```text
D = sky(R union [(c,U), 若有] union Move(P[c])).
```

R 的父全部大于 c。起始列为

```text
R followed by (c,V) followed by S,
```

其中 S 的父小于 c；有 U 时 `V>U`，无 U 时 `(c,V)` 仍被 skyline 保留。
还要求有 U 时，在整个局部过程中，当前有限前驱的尾长界都包含 U。

那么，反复做第一块并截回原宽度，必有限步恰好命中 D，最后一步控制父为 c。

证明与 canonical 单位减一宏相同：

- 控制父小于 c 时，只动尾部 S，不改变 R 或 `(c,V)`。
- 控制父等于 c 时，S 已空。有限最大前驱不能越过 U；第一次命中 U 后完整 graft 恢复目标 D。
  无 U 时，第一次删掉 c 行或使其被 R 支配，完整 graft 同样恢复 D。
- 固定宽度下第一块尾长界不增，可出现的列只有有限多个；每步严格列下降，不能无限停在目标以上。

两处特别要注意：

1. 最后一个局部状态 E 的控制父是 c，而 skyline controller 是末行，所以 E 确实没有低父尾：

   ```text
   E.last = R followed by (c,V).
   ```

2. 宏是有限存在证明，不要求实际按这个巨大有限界暴力运行。

## 6. 下一块的尾長界和重标没有隐藏假设

第 0 块：使用 canonical 单位减一宏；其尾长可用性由 canonical 左前缀引理保证。

第 b 块，`b>=1`：已修好的固定左前缀包含 D_(b-1)。若 U 存在，D_(b-1) 仍保存 `(c_(b-1),tau_(b-1)(U))`，所以固定前缀已经包含 U 的相同尾长。
因此局部修正期间，不论末列其它词怎样消失，当前全图尾长界都不会降到 U 的尾长以下。

从最后局部状态 E_b 做多块展开时，设其控制词 V；V 可以含由新规则产生的中间地址，**不要求 V 是旧词的纯搬运**。
只使用：

```text
V > U_b,
phi_l(V) > phi_l(U_b) = U_(b+l),
```

其中 phi_l 是以当前切点 c_b、宽 w 的严格递增重标。
目标 U_b 的支持只有旧小 ROOT `<c`、当前切点 c_b 和 SELF x_b，因此后一等式精确成立。

并且，最后一次第一块前驱已经产生 U_b，所以其尾长必不超过 `D(E_b)`。
后块上界 `D(E_b)+floor(log2(l+1))` 只会更大，有限最大前驱的候选中始终包含 U_(b+l)。
因此后续接缝的 pivot 词不小于目标词；不是凭模糊的“复制自然性”推断这一点。

## 7. 多块归纳：精确到达旧 wY 第 n 项

n=0 是直接删末列，后继情况也直接一致。现在设源末列非空，n>=1。

### 第 0 块

先沿 canonical 单位减一宏，找到恰好生成 D_0 之前的状态 E_0。
最后一次不只取新 `FS[1]`，而取新 `FS[n]`。

- 首接缝精确为 D_0。
- 非接缝的来源列是原 `C_(c+1),...,C_(x-1)` 的精确副本。
- 每个较后接缝，其高父 R_b 与目标相同；如果不同于 D_b，首次差别只可能是额外/更大的 pivot c_b。

最后一点来自有限最大前驱不小于搬运目标 U，以及相同来源 Q；无 U 时，pivot 行一旦被删，接缝就已等于目标。

### 修正第 b 块

假设第 b 块以前都已精确匹配，而后面还保留若干完整的暂定纯来源块。
若本接缝本来就等于 D_b，则无需修改，继续检查下一块。

否则先用 `[0]` 把当前图截到本接缝；这保留的左前缀已经是旧 wY 目标的 canonical 前缀。
本接缝具有第 5 节的 pivot 平台形式。

其实际来源切点列：b=0 时是原 C_c，b>=1 时是 D_(b-1)。
由 (Abs)，用后者完整 graft 后的目标恰好仍为 D_b。
第 6 节保证尾长界，于是局部修正宏精确命中 D_b，最后切点仍是 c_b。

在最后一个状态 E_b，取新 `FS[n-b]`，而不是只取 `FS[1]`。

- 首接缝得到 D_b。
- 当前来源的非接缝区间 `c_b+1,...,x_b-1` 已是旧来源列的精确搬运，所以后续纯副本继续精确。
- 未来接缝合并的是旧切点 D_(b-1) 的 SELF 再搬运，而不是刚生成的 D_b。
  对未来第 k 块用 (Abs) 的一般形式 `a=b-1<k`，即可证明这个更早来源仍被当前 L_k 吸收。
- 第 6 节的前驱界保证每个未来接缝，要么已经等于 D_k，要么仅在其 pivot c_k 处严格更大。

因此同一归纳不变量恢复。最多对 n 个接缝做修正；每个宏有限，故总路径有限。
最后得到的完整图精确等于旧 canonical wY 第 n 项，而不仅仅逐列较大。

这里所有截断都是合法的反复删末列，没有删中间列，也没有保留被截掉的未来尾部。
被截掉的部分由最后一次多块展开重新生成；(Abs) 正是认证其来源变化无害的引理。

## 8. 整体下界

新种子 `S_m=[][0:(0,1,...,1)]`，其中 SELF 1 有 m 份，恰是旧 canonical `Phi(1,m+2)`。
更小的 `(1,1)`、`(1)`、空式均由删除/后继得到。

对旧标准生成路径长度归纳：

- 种子属于新标准域；
- 若 Phi(s) 已属于新标准域，第 7 节给出 Phi(s[n]) 也是新后代；
- 所以全部 Phi(Std_wY) 都属于新标准域。

Phi 的列字典序保序已由旧有限山脉审计给出。故该包含给出严格保序映射，得到

```text
type(wY) <= type(skyline regenerative words),
```

条件是右侧已由独立反射论证确认为良序。
该结论不要求实际运行巨大的宏来定义新基本列；新规则仍是有限前驱、完整 graft 和纯块复制。

本稿没有证明严格大于 wY。新标准域中存在额外非canonical图，单独并不能推出严格序型增长；旧良序内插入新点仍可能保持相同序型。

## 9. 本轮独立有限诊断（非证明）

在形成上述吸收引理之前，做过两项限时诊断：

- 120 个旧标准来源，逐个局部命中数值减一后检查 n=1,2,3 的首步有限宽覆盖：120 命中，0 失配，1.40 秒、99 MiB。
- 200 个旧标准目标，对确定的最大有限宽后代链每个最多 3000 步：88 命中，112 因步数上限仍未知，0 已观测跳过；2.55 秒、116 MiB。

第二项没有完成全称验证，不能当成包含证明；它也不是以找到后继或清空为目标的无界下降搜索。
所有程序均用 Node 堆 384 MiB 上限，正常退出，没有遗留进程。

额外检查了第 1 节自由反例：其 canonical 上界值 6 为 `[3:(0,3)]`。
从这个上界出发的真实局部轨迹为

```text
[3:(0,2);0:(0,4)]
→ [3:(0,2)]
→ [3:(0,1);0:(0,4)]
→ [3:(0,1)]
→ [3:(0);0:(0,4)]。
```

该轨迹最后控制父始终按宏证书回到 3，不经过人工反例的父 2 平台。
这说明为何本稿的受证书约束宏与已失败的任意自由 no-skip 并不矛盾。

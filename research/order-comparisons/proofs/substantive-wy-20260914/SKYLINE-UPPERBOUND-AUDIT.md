## 0. 审计结论

在本文明确的

```text
S = KP_omega + 存在序数 nu>omega，使不存在集合满射 omega -> nu
```

下，未发现以下纸面证明链需要更强公理：

1. 全体结构合法有限自由词图的实际集合序数下降秩；
2. 将该秩直接限制给 skyline 系统；
3. skyline 标准生成域的真实列字典序良序、后继/极限分类与基本列共尾性；
4. 标准生成域成员的一个总可计算判定算法。

这里的 KP 使用完整集合归纳、Delta_0-Separation、Delta_0-Collection 和无穷公理。
不是 Power KP，也不是把“存在有限图的表示”追加成一个新公理。
以下把词版本需要的接口逐项实例化，避免仅以“以前树版本证明过”作为理由。

这是纸面审计，不是该系统专属的 Lean/KP 内部形式化，亦不提供判定算法的实用时间界。

## 1. 局部词序具有 KP 内直接构成的集合秩

先在 S+V=L 中工作。令 kappa 为最小不可数序数，K=kappa+1。
词 W=(r,u_1,...,u_d) 规范、非降，所有字母 <=kappa，尾部字母严格大于 r。
令

```text
B_d = sum_(i<d) K^i,
Omega = K^omega,
h(W) = Omega*r + B_d + sum_(i=1..d) K^(d-i)*u_i.
```

固定尾长时，有限 K 进制序数和严格保持尾向量字典序；
尾长 d 的值落在 `[B_d,B_(d+1))`，各长度块均低于 Omega；
最后按根 r 排序。故 h 严格保持 `(首根,尾长,尾部字典序)`，且

```text
h(W) < Lambda := Omega*K.
```

所有有限积、omega 次序数和及相应求值图均由给定序数递归与 KP 收集构成。
不需要任意内部良序的塌缩定理，更不需要 LPO/Kruskal。
词归一化只删除首根的重复初始出现，不在严格递增地址重标下改变长度，
因此重标严格保持词序及 `(词,父)` 比较。

## 2. 自由图的有限需求关系是实际集合递归

有限语义词合法性为 ROOT<=a<b<=kappa，SELF=b，且 omega<a。
对有限图 G、端点模板族 N、切点 c 和递增标签 f，使用原文的 Rep/End/Adm：

```text
Adm_(W,a,b)(N,f):
每条端点请求的 (求值后的词, f(父)) < (W,a)。
```

R(W,a,b) 要求：每份在 b 以下、切点值 a 的合法已表示输入，
连同所有已成立且满足 Adm 的端点请求，都有一份在 a 以下的输出表示，
固定切点以前的标签，并把请求端点从 b 换成 a。

预先构成的集合源包括：全部有限语法代码、`(kappa+1)^(<omega)`、词集、求值图和 h。
按如下已有序数阶段递归：

```text
((kappa+1)*Lambda)*b + (kappa+1)*h(W) + a.
```

内部输入的右端点 <b；所有输出查询的右端点 <=a<b；
同端点输入由 Adm 有更小的 `(h(词),父)`。
守卫或 Adm 失败时不读未来历史。故下一位真值是已有集合参数下的有界条件。

后继用有界分离，极限用 Sigma_1-Collection 收集唯一相容的较短历史再取并。
有效历史检查有界；历史存在性为 Sigma_1；其唯一性用给定阶段序数归纳。
这不构造所有历史的幂集，也不沿新图的待证下降关系递归。

由允许请求包含，得到且只需得到同父弱化：

```text
W'<=W 且两者在 (a,b) 合法，R(W,a,b) => R(W',a,b)。
```

没有跨父弱化结论；改变父标签会改变输出界。

## 3. 任意有限图的表示供应：专门核对 KP 使用

### 3.1 统一枚举不需要环境选择

在 V=L 内，最小不可数 kappa 的存在可由完整集合归纳作类极小化得到，
不需要先分离“所有不可数序数”。每个非零 alpha<kappa 有 omega 满射。
“f 是从 omega 到 alpha 的满射”是有界条件，Delta_0-Collection 收集全部所需见证。

收集集中的元素都在 L；先收集包含它们的 L 层级，再在一个足够大的构造层级的
构造性良序中选最小见证，得到实际集合函数 e(alpha,n)，枚举每个非零 alpha<kappa。
这一步没有在外部作可数选择或不可数选择。

### 3.2 可以不构造全一阶满足关系

IPD 文稿第 12 节的显式见证闭包足够，且在词版本中更直接。
模板只有有限 ROOT 变量表与 SELF 次数，由自然数编码。定义两类操作：

- Bad_(tau,i)(q,a)：若 kappa 端的 R(tau[q,kappa],a,kappa) 失败，
  取按“请求形状码、固定长度标签字典序”最小的失败输入，返回其第 i 个标签；
  不存在或越界时返回 0。
- Ext_(G,N,c,i)(u)：寻找前 c 个标签为 u、内部图 G 已表示且 End_kappa(N) 成立的输入，
  取固定长度标签字典序最小者的第 i 个标签；不存在或越界时返回 0。

操作图只在已构成的 R、有限语法集和有限标签集内量化，均可有界分离。
固定长度标签字典序有有限 kappa 进制秩；再按形状码作 omega 序数和，
故最小化有显式秩，不假设任意集合良序可以塌缩。
操作符是模板/形状/坐标的自然数代码，**不是每个语义词一个操作符**。

特别地，Ext 不固定新切点值，也不固定控制词或允许性；它只固定切点之前的 u。
如果把切点也固定为原 delta，接下来的闭包供应就会失败。

### 3.3 闭包是实际可数序数

将 e、Bad、Ext 看作可数多个有限元集合函数。以 0、omega、gamma 为常量，
求所有有限操作项的值；有限项可由自然数编码，其唯一有限求值历史由 KP 归纳与收集构成。
值域 H 因而是实际集合，并有实际 omega 满射。

H 对 e 封闭，所以 alpha∈H 且 alpha>0 蕴含 alpha⊆H；因此 H 是序数 delta<=kappa。
不可数性排除 delta=kappa。常量保证 omega,gamma<delta。
这里不需要 kappa 的正则性，也没有任意选择得到一串见证。

### 3.4 端点一致性不是额外反射假设

对这样的闭包 delta，固定 ROOT 参数 <=a<delta，以 `(h(tau[q,delta]),a)` 归纳证明

```text
R(tau[q,kappa],a,kappa) <=> R(tau[q,delta],a,delta)。
```

正向：delta 端请求的较小端点事实由归纳假设提升到 kappa，
在 kappa 端应用 FR；输出都 <=a，查询没有改变。

反向：若 kappa 端失败，Bad 操作选出的全部输入标签因闭包性低于 delta。
替换共同最大 SELF 从 kappa 到 delta 保持所有词比较；
较小端点请求经归纳假设变成 delta 端事实，而“无 a 以下输出”不变，矛盾。

控制模板含 SELF=kappa 不是域内参数：模板是自然数代码，ROOT 才是闭包参数。
同词可能有不同模板写法也无害，归纳针对其实际求值词；共同最大 SELF 的提升唯一。

### 3.5 强供应以及所有有限图

对任意合法控制词 W（允许 ROOT=delta），证明 R(W,delta,kappa)。
给定一份 FR 请求，仅保留其切点前缀 u。原请求使 Ext 的候选集非空；
Ext 闭包提供全部标签低于 delta 的新表示，端点一致性把 End_kappa 改成 End_delta。
这恰是所需输出。控制 W 或旧切点 delta 从未被作为 Ext 的固定参数。

因此任意两个闭包高度 alpha<beta 之间、任意 ROOT<=alpha 的合法词关系都成立：
先在 alpha 用强供应，再在 beta 用端点一致性。
对给定有限图，有限次选择递增闭包高度作为其列标签，逐边应用此事实，得到表示。

所以“任意有限自由词图可表示”确实由 S 的构造得到，没有偷加供应公理。

## 4. 自由图的逐块下降与 skyline 的安全投影

自由版的逐块拼接只用：控制词严格降低、同父弱化、原来源标签不变量。
原父列嫁接事实可以高于控制词；它来自重新使用的来源切点标签 a，
不是被错误塞进虚拟 beta 的受控端点请求。
新 ROOT 可以使用新切点之前的任意已有列；其标签已经存在，降低后的词在语义求值后仍严格较小。
这逐项吻合 `regenerative_words.py` 的固定来源循环。

令 mu_free(G) 是全部自由合法图中最小表示末标签，空图取 0。
有限图初始供应和有界最小化给出一个实际集合函数，并有

```text
G非空 => mu_free(FS_free(G,n)) < mu_free(G)。
```

令 Pi 按列取 skyline。它只删除关系，不删除列，不改变被保留词的地址。
任何 H 的表示 f 仍表示 Pi(H)，故

```text
mu_free(Pi(H)) <= mu_free(H)。
```

对已是 skyline 的输入 G，源码直接给出

```text
FS_sky(G,n) = Pi(FS_free(G,n))。
```

原因：两者读同一个原图 G、选择同一控制、使用同一原始 D；
每一块读取固定原来源，不读取已生成接缝，亦不更新 D。
所以可把全部 skyline 过滤移到整次自由展开之后。普通复制保持 skyline。
于是

```text
mu_free(FS_sky(G,n)) <= mu_free(FS_free(G,n)) < mu_free(G)。
```

这避免了“恢复被 skyline 删除的来源事实”的伪问题。
每次重新对当前 skyline 输入应用自由图定理即可；不需要保持跨步骤的隐藏边或跨父语义弱化。

## 5. 标准列序与真正的基本列

实际 skyline 规则有三个有限性质：

1. 第零项删除末列，所以每个列前缀均可达。
2. 基本列按完整列前缀严格递增（非空末关系列的每块宽 w>0）。
3. 每个非空项的任何一步都严格降低列字典序。

第三点：控制是 skyline 最后一个父行；更大父的原行保持，
控制父词降低或该行消失，新来源的父全部更小；skyline 不会由更小父行删掉这些更大父原行。

对 mu_free(G) 归纳证明同一个 G 后代锥内可达性可比。
两条非空路径第一步 G[i]、G[j] 均置于 G[max(i,j)] 的后代锥，因为前缀可删除。
归纳秩更小。严格列下降排除相反方向，故该锥上列序恰等于非平凡可达性。

种子满足 S_(m+1)[1]=S_m，任意两个标准式有共同种子祖先。
因此 mu_free 在标准列序上严格保序：实际列序良序，而不只是展开关系良基。

进一步，任意标准 H<G 都可从 G 到达，第一步为某个 G[n]，故 H<=G[n]。
于是非空末关系列的严格增长基本列真正共尾；末列为空时唯一孩子就是删末列，
它确实是前继；空式为 0。

全体手写良形图的列序仍不在这个良序结论内。

## 6. 标准域成员其实可判定，但不应拿它作实用展开算法

下面补足原稿未显式给出的总判定，而不是把“存在一条有限路径”误当成可判定。

固定目标 T，宽 m。先作有限语法及 skyline 正规形检查；零和单空列直接接受。
宽至少 2 时，第二列若为空，取 A=S_0；否则它必为唯一行
`[0:(0,1,...,1)]`，设 SELF 数为 d，取 A=S_(d+1)。均有 A>T。

若 T 已标准，则因为共同种子锥可达性可比，T<A 蕴含 T∈Desc(A)。
反向显然。因此只需决定 T 是否为这个具体 A 的后代。

### 6.1 有限宽截断引理

对非空 G，令

```text
B_m(G) = G[m] 的前 m 列（不足 m 列则全保留）。
```

每个宽 <=m 的真后代 H 均满足 H<=B_m(G)。
证明：其第一步是 G[k]。若 k<=m，用前缀性质；
若 k>m 且 G 为极限，G[m] 至少有 m 列，G[k] 的前 m 列与它相同；
后继情况所有 G[k] 相同。再使用纯字典序事实：宽 <=m 的 H<=X 蕴含 H<=prefix_m(X)。

B_m(G) 本身是 G 的后代。由后代锥可达性可比，得到

```text
T∈Desc(G)  <=>  T=G 或 T∈Desc(B_m(G))   （width(T)<=m）。
```

### 6.2 判定程序与终止

```text
while True:
    if A == T: accept
    if A < T: reject
    A = B_m(A)
```

每轮使用一次有限、总可计算的基本列和截断；若还在循环，A 非空，mu_free 严格下降。
故在 S 中以此实际序数秩归纳证明程序终止。
有限宽截断引理保证每轮保留成员判定的真假值；越过 T 时可正确拒绝。

这证明标准域是递归集合，而不仅是可枚举集合。它不保证合理复杂度；
程序可能需要巨大多轮，不能违反用户警告拿来作野蛮长降链搜索。
本审计没有实现或运行此循环。

## 7. 移除 V=L 与集合性账本

普通 KP 可以构造内类 L，具有相同序数和自然数，L 满足 KP+V=L。
环境中不存在 omega 满射的 nu，在 L 中仍无该满射。
因此在 L 中完成上述证明可得实际集合秩 mu_free∈L；
词语法、有限计算及序数大小绝对，故该秩在环境中仍逐步严格下降。
转移的是实际秩函数，不是直接转移“L 中没有无限降链”。

有限图、有限路径与 FS 图都是 KP 内的实际集合。
一旦有限计算图及自然数代码源构成，有限可达性只需在该源中有界量化，
所以标准域集合的存在不需要完整 Separation。
判定算法的总性还可以用前节秩归纳单独证明，并非标准域集合性的前置假设。

外部基础事实已核对原始文献：

- [McKenzie, Lemma 2.6 与 Theorem 2.8](https://arxiv.org/html/1806.08500v4#S2)：
  集合结构满足关系的 Delta_1 定义、构造层级函数的全性及 Delta_1 定义。
- [Rathjen, Introduction 与 §2](https://arxiv.org/html/1801.01897v1)：
  普通 KP 的内构造模型路线及其与 Power KP 的区别；这里使用的完整集合归纳版本也在该处明确。

上述文献只支撑这些基础事实，不被冒充为再生词图或 skyline 良序的现成发表定理。

## 8. 仍须严格区分

- 纸面 S 内良序证明与已经有本系统 Lean 形式化，是两件事。
- 标准域可判定与当前 Python 构造器只检验语法，也是两件事；当前构造器未实现标准成员判定。
- 全部自由图展开有秩，不推出全部自由图列序良序。
- skyline 投影是删关系的语义保真；不能据此声称跨父 R 单调。
- 与 wY 的 >= 下界依赖另一份组合桥接；本上界论证既不需要它，也不证明严格更大。

# ARD2：全上下文行锚图的轮廓版 · [English](definition.md)

2026-09-17。[PDF](definition.zh-CN.pdf) · [NER](ARD2.ne-rewritten.js) · [Python](ard2.py) · [良序与精确等价证明](../../proofs/paper/ard2-well-ordering.zh-CN.md) · [Lean](../../lean/ARD2/README.zh-CN.md)。

ARD2 是 Anchored Row Diagrams 的全上下文版本。现在的默认版将被支配的关系删去，以单个控制前驱替代整包低行生成。它与保留的 [ARD2-legacy](../ARD2-legacy/definition.zh-CN.md) 在标准域上**序同构、逐指标展开交换、局部计数相同**。原版本的程序、文稿和 Lean 源码没有丢弃。

## 1. 列与轮廓

有限式是列串 $G=(C_0,\ldots,C_{m-1})$。第 $j$ 列记录为

$$ (k,p,q),\qquad 0\le k,q\le j,\quad 0\le p<j. $$

分别表示行锚、父列、最大根；最大根代表全部根 $0,\ldots,q$。与 ARD 不同，行和根不必在父列之前，并且都可以等于子列 $j$，即 **SELF**。SELF 是当前这个子列的地址，搬运时随列移动；父列必须严格靠左。

令记录优先级为有序对 $(k,q)$，取通常字典序。列的轮廓 $S(C)$ 用两个步骤得到：

1. 对每个父列 $p$，只保留优先级最大的记录。
2. 按父列递减扫描，只保留优先级严格超过此前所有记录的项。

所以规范列的父严格递减，优先级严格递增。空列不能删除。零是无列图 `∅`；一个空列 `[]` 是一；$m$ 个空列表示自然数 $m$。完整列表如

```text
[][(1,0,1)][(2,1,2)]
```

每一列仍只用三元组，不加入树、展开历史或辅助参数。构造器和解析器检查全部原始坐标后取轮廓；无效坐标不能靠被支配而绕过检查。输入旧列表会得到其轮廓，不自动认证标准可达性。

## 2. 按列比较

记录比较键为 $(p,k,q)$。列内记录已按该键递减排列；按列表字典序比较列，再从最左列开始字典序比较图。两级都规定真前缀较小。比较不展开、不搜索路径。

外加最大项 $\mathsf{Top}$，显示为 `Limit of ARD2`。它不是有限列或可引用的坐标。**任意合法图的列序并不良序**；良序声明限定于第 4 节的标准域。

## 3. 基本列：末记录前驱、合并来源、追加副本

指标 $n\in\mathbb N$。规定 $0[n]=0$；这个自环不算严格下降。有限非零图满足

$$ G[0]=G\text{ 删去末列}. $$

若末列为空，所有指标都执行相同删除。其余情况设末位置 $x=m-1$，末列的最后一个记录为控制 $(K,c,R)$，令

$$ L=x-c>0,\qquad N_b=x+bL,\qquad
\phi_b(i)=\begin{cases}i,&i<c,\\i+bL,&i\ge c.\end{cases} $$

搬运作用于每个记录的全部三个坐标。对已经搬运的控制定义

$$ \delta_N(k,p,q)=\begin{cases}
\{(k,p,q-1)\},&q>0,\\
\{(k-1,p,N)\},&q=0<k,\\
\varnothing,&k=q=0.
\end{cases} $$

这里借位用的是**新接缝自身 $N$**，不是父 $p$。必须先搬运再取前驱，不能只在第一个块减一次后复制结果。

先保留 $C_0,\ldots,C_{x-1}$。依次对 $b=0,\ldots,n-1$ 追加

$$ J_b=S\left(\phi_b(C_x\setminus\{(K,c,R)\})
\cup\delta_{N_b}(\phi_b(K,c,R))\cup\phi_{b+1}(C_c)\right), $$

随后追加 $\phi_{b+1}(C_{c+1}),\ldots,\phi_{b+1}(C_{x-1})$。所有来源均取自调用开始时的旧图；不读取刚生成的输出。

注意来源切点列 $C_c$ 使用 **$b+1$** 搬运，且 $\phi_{b+1}(c)=N_b$。因此其中的行 SELF 和根 SELF 都重新绑定为接缝 $N_b$；父仍严格小于旧切点。不能像 ARD 那样不加区分地直接合入未搬运的 $C_c$。

若 $H=A_2$，则

```text
H    = [][(1,0,1)]
H[0] = []
H[1] = [][(1,0,0)]
H[2] = [][(1,0,0)][(2,1,1)]
H[1][1] = [][(0,0,1)]
```

输出列数为 $x+nL$。旧末列之前完全不变，$G[n]$ 是 $G[n+1]$ 的完整列前缀。末列非空时是真前缀；外顶端没有此要求。

## 4. 种子、标准域及证明范围

种子 $A_n$ 有 $n$ 列，$C_0=\varnothing$，$C_j=\{(j,j-1,j)\}$（$j>0$），且 $\mathsf{Top}[n]=A_n$。有限标准域是这些种子的全部有限展开后代，不把可及性、语义表示或良序性放进标准性定义。

[纸面证明](../../proofs/paper/ard2-well-ordering.zh-CN.md) 给出：

- 全部合法轮廓图的非零展开良基。
- 标准域的指定列序良序，加外顶端后仍良序。
- 逐列压缩 $Q$ 满足 $Q(E_nG)=F_n(QG)$，其中 $E,F$ 是旧、新规则；$Q$ 在标准域上是序同构，保持局部计数。并不声称 $Q$ 在全部原始合法图上单射。

纸面公理上界仍为 $KP_\omega+$“存在不可数序数”，保留完整集合归纳，不增加幂集或选择公理。新版 [Lean 入口](../../lean/ARD2/src/ARD2SkylineFinal.lean) 直接验证新规则的良序性，显式复用旧版语义后端；**新旧精确同构、弱对象理论内部推导和跨记号比较尚未 Lean 形式化**。Lean 不是 Python/JS 虚拟机认证。

已有 [ARD 嵌入 ARD2(1,3) 以下的纸面结论](../../proofs/paper/ard-le-ard2-13.zh-CN.md) 通过该同构保留；该固定式 `[][(0,0,1)]` 自身已经是轮廓。与整体 wY、CWY2、IPD 的比较不由本次简化得到。

## 5. 局部计数与五种显示

固定某列此前的前缀，将它作为末列展开一次，再丢弃新追加列；重复到该位置被删去。其次数包含最后的空列删除，所以空列计数为一。压缩保持列数、截列、非空性并与这个局部步骤交换，故计数与旧版相同。种子计数从

```text
1,5,55,969,23751,...
```

取对应长度的前缀。计数器使用精确整数；不以有限工作量预算作为数学定义。固定位置只有有限多个轮廓列，局部步骤严格下降，所以局部计数必终止。

NER 保留五种显示：默认**列表**，另有**计数序列、弧线图、邻接表（文字）、邻接表（图）**。不重复提供列表按钮。文字邻接表每列一对 `[]`，分号分行锚，逗号定位父列，空位无数字，零不表示空位；例如 $A_2$ 为 `[][;1]`。邻接表图每行锚一张完整紧凑上三角表，浅色对角格充当列标，表顶独立显示计数序列。弧线图与表格显示当前轮廓的全部关系，不恢复或暗中绘制旧版冗余关系。

字体继承网页。计数、几何和展开的预算互相隔离，保留约一秒预算及列数、工作量、画布限制。超限明确提示，不填近似数，也不将局部图冒充全图。

## 6. 使用与检验

将 [JS 文件](ARD2.ne-rewritten.js) 导入 [NER](https://smilelee-lyx.github.io/ne-rewritten/) 自定义记号，选择 **ARD2**。新注册 ID 为 `ard2-skyline-v02`；旧版独立注册为 `ard2-legacy-v01`、显示名 **ARD2-legacy**，可以同时载入。既有网页中已加载的脚本不会自动更新，需要重新导入。

输入支持 `A3`、`A3[2][1]`、`Limit[3]`、`Limit of ARD2`、自然数和完整列表。自然数是空列数量，不是计数词。`FS`、`FS_alter`、`FS_short` 完全相同，无指标偏移。

```python
from ard2 import ARD2, TOP
a = ARD2.seed(3)
assert TOP[3] == a
assert a[1] < a
assert a[1].columns == a[2].columns[:len(a[1].columns)]
assert a.local_step().columns == a[1].columns[:len(a.columns)]
```

Python 使用任意精度整数，省略绘图、缓存及资源保护；调用者需限制实验规模。测试命令从仓库根执行：

```text
python -B tests/test_ard2.py
python -B tests/test_ard2_legacy.py
node --max-old-space-size=256 tests/ard2_ner.cjs
node --max-old-space-size=256 tests/ard2_display.cjs
```

测试包括独立完整根 oracle、旧版逐指标交换、双 SELF、零指标、前缀、比较、局部计数及完整显示。有限测试不是序同构或良序定理的证明。

## 1. 表达式与比较

ICP 全称 **Interpolating Copy Patterns**。有限式是列串 $A=(C_0,\ldots,C_{m-1})$。第 $j$ 列是有限部分函数 $p\mapsto q$，其中 $0\le p,q<j$；两个字段是父地址和根地址。**不要求 $q\le p$。** 同父保留最大根，按父递减存放。

列表用逗号分隔记录，例如 `[][0:0][1:1,0:1]`。零无列，`[]` 是一。记录按 $(p,q)$ 比较，列按记录字典序比较，图按列字典序比较，真前缀较小。外顶端为 `Limit of ICP`，不是地址。

非空列控制是 **$(q,p)$ 最大**的记录。表达式比较与控制选择采用不同优先级，这是定义的一部分。

## 2. 局部降低

以 $N$ 表示同父规范化。控制为 $(c,r)$ 时，定义

$$
T_A(C)=N\left((C\setminus\{(c,r)\})\cup C_c
       \cup\begin{cases}\{(c,r-1)\}&r>0,\\\varnothing&r=0.\end{cases}\right).
$$

即继承旧父列，控制根减一，零则删除控制边。此前列不变；父 $c$ 处降低，继承父均更小，因此局部列序严格下降。

## 3. 一次插值反射

零或末列为空时 $R(A)=A$。否则设 $x=m-1$，末控制为 $(c,r)$。

1. 输出 $B$ 先放 $(C_0,\ldots,C_{x-1},T_A(C_x))$。
2. 部分地址映射为 $\phi(p)=p$（$p<c$），$\phi(c)=x$。
3. 依次处理**原始**来源列 $i=c+1,\ldots,x$，每列一次；新插入列不加入来源清单。
4. 搬运两个坐标，得到 $V=N\{(\phi(p),\phi(q)):(p,q)\in C_i\}$。
5. 若 $V$ 非空，控制为 $(a,b)$，从当前输出第 $b$ 列的控制父开始向左追控制父，只收集大于 $a$ 的地址；遇空列或不大于 $a$ 的地址停止。收集结果递增排列为 $s_1<\cdots<s_t$。$V$ 为空时清单为空。
6. 先追加 $V$。随后对每个 $s_\ell$，令 $v$ 为刚追加列的位置，将 $V$ 换成 $N(V\cup\{(s_\ell,v)\})$，再追加这一列。
7. 令 $\phi(i)$ 为该来源小块的末位置，继续处理下一个原来源。

追父读取**当前输出前缀**，不是冻结的旧图。所得 $\phi$ 严格递增，父链都有限，所以单次反射有限；这不排除反复基本列下降永不结束。

## 4. 基本列与种子

令 $\partial$ 删末列并保持零。定义

$$
A[n]=\partial R^n(A).
$$

因此 $A[0]=\partial A$；末列为空时任意指标都删末列。反射只改工作末列并追加，因此 $A[n]$ 是 $A[n+1]$ 的完整列前缀。每个非零展开严格降低指定列序。

种子 $S_h$ 有 $h+1$ 列：$C_0=\varnothing$，$C_j=\{(p,j-1):0\le p<j\}$（$j>0$）。规定 $\mathsf{Top}[n]=S_n$。标准式只取这些兼容种子的有限后代，不包括全部手写合法图。

```text
S1       = [][0:0]                          计数 1,2
S1[1]    = [][]                            计数 1,1
S1[2]    = [][][1:0]                       计数 1,1,2
S1[3]    = [][][1:0][2:1,1:0]              计数 1,1,2,4
S3[1][1][0] = [][0:0][1:1,0:1][2:1,1:1,0:2]
```

最后一行正是无穷降链的标准起点，不是任意拼出的非标准反例。

## 5. 计数、接口与范围

每列固定前缀，反复用局部 $T$ 降为空，再加删除空列的一步。位置 $j$ 只有 $(j+1)^j$ 个规范列，$T$ 严格降低这个有限序，所以局部计数有限；它与全局存在无穷链不矛盾。

在 NER 导入并选择 **ICP候选**。提供列表、精确计数序列、三角邻接表；接受 `S3`、`Limit of ICP`、`0` 和完整列表，不接受 `S3[1][1][0]` 这样的路径字符串输入；路径可通过点击展开或 Python API 获得。三种 FS 入口一致。未知计数显示 `?`，不填近似数。

在本目录使用：

```python
from icp import Budget, display, expand, seed
a = seed(3)
for n in (1, 1, 0):
    a = expand(a, n, Budget())
print(display(a))
```

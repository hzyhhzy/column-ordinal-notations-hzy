# LRD：序数行标列图 — [English](definition.md)

发布定义，2026-09-13。[PDF](definition.zh-CN.pdf) · [NER 展开器](LRD.ne-rewritten.js) · [Python](lrd.py) · [良序证明](../../proofs/paper/well-ordering.zh-CN.md)。

这是固定多项式行标的 LRD。其顶端是普通两列种子，不是外加符号。下述有限规则不调用良序判定，也不使用资源阈值。

## 1. 行标与有限图

令 $\Lambda=\omega^\omega$，行标集合为

$$
L=\{\xi:\xi<\Lambda\}\cup\{\Lambda\}.
$$

低于 $\Lambda$ 的行标唯一写成有限多项式 $\omega^d a_d+\cdots+\omega a_1+a_0$，系数为自然数；除零外不保留最高位零系数。先比较次数，再从最高位系数向下逐项比较。$\Lambda$ 大于所有多项式。

有限图 $G=(m,E)$ 的关系为

$$
(\xi,q,p,j),\qquad \xi\in L,\quad0\le q\le p<j<m.
$$

四个字段依次是行标、根列、父列、子列。要求根闭包：包含根 $q$ 的关系时，也包含其余字段相同且根为任意 $u\le q$ 的关系。闭包 $\downarrow$ 只增加较小根，不增加较低行标。重复关系忽略，空列保留。

空图为 $0$，显示 `∅`；单个空列是 `[]`。第 $j$ 列内的三元组 `(行标,父列,最大根)` 代表根零至最大根的全部关系。同一 `(行标,父列)` 分组合并取最大根。例如 `[][(w,0,0)]` 是第二列非空的两列图。项的身份是图，不是构造历史。

## 2. 行标近似与生成包

对每个 $t\in\mathbb N$ 定义

$$
\begin{aligned}
0\langle t\rangle&=0,\\
(\beta+1)\langle t\rangle&=\beta,\\
(\beta+\omega^d)\langle t\rangle&=\beta+\omega^{d-1}(t+1)\quad(d\ge1),\\
\Lambda\langle t\rangle&=\omega^{t+1}.
\end{aligned}
$$

第三种情况用于非零极限多项式：从最后一个非零 Cantor 单项式中移去一份 $\omega^d$，剩下 $\beta$。等价的系数算法是：对 $(a_0,\ldots,a_d)$，找到最小的非零位置 $e$，将 $a_e$ 减一；若 $e>0$，令 $a_{e-1}=t+1$；最后删掉最高位零系数。非零行标的近似总是严格较小。

第 $b$ 个接缝的生成包是有限集合

$$
P_b(K)=\begin{cases}
\varnothing&K<\omega,\\
\{0\}\cup\{K\langle t\rangle:0\le t\le b\}&K\ge\omega.
\end{cases}
$$

上限为 $b$，包含 $b$；重复行标去重。有限行不生成新行。

## 3. 展开规则

规定 $0[n]=0$，它不是严格下降步。对非空图令 $x=m-1$，以 $\partial G$ 表示删末列和它的所有入边。规定 $G[0]=\partial G$；若末列为空，则所有 $G[n]=\partial G$。

否则令 $n>0$。按 $(\xi,q,p)$ 取末列最大关系，写成 $(K,r,c,x)$。令

$$
\ell=x-c>0,\qquad
\phi_b(i)=\begin{cases}i&i<c,\\i+b\ell&i\ge c,\end{cases}
\qquad E^- =\{(\xi,q,p,j)\in E:j<x\}.
$$

对关系施加 $\phi_b$ 时移动根、父列、子列，不改变行标。普通接缝与生成接缝分别为

$$
\begin{aligned}
U_b=\{(\xi,u,\phi_b(p),x+b\ell):\;&(\xi,q,p,x)\in E,\quad0\le u\le\phi_b(q),\\
&\xi<K\text{ 或 }(\xi=K\text{ 且 }u<\phi_b(r))\},\\
V_b=\{(\delta,u,\phi_b(c),x+b\ell):\;&\delta\in P_b(K),\quad0\le u\le\phi_b(c)\}.
\end{aligned}
$$

完整规则为

$$
G[n]=\left(x+n\ell,\ \downarrow\left(
\bigcup_{b=0}^{n}\phi_b(E^-)
\ \cup\ \bigcup_{b=0}^{n-1}(U_b\cup V_b)\right)\right).
$$

所有集合都是有限的。源块连同原块共出现 $n+1$ 次。生成包附在平移后的控制父列上，并包含所有允许的根。平移后再做根闭包，补上平移跳过的根索引。

## 4. 列序、种子和标准域

每列的最大根三元组 $(\xi,p,q)$ 按 $(p,\xi,q)$ 降序排列，再按该键逐项比较；整图从最左列开始比较。两个层级都是真前缀较小。逐个展开所有小根给出相同顺序。

控制边优先级是**行标、根、父列**；比较优先级是**父列、行标、根**。二者不能混用。

种子为

$$
T=\bigl(2,\{(\Lambda,0,0,1)\}\bigr).
$$

其列表为 `[][(w^w,0,0)]`。标准域恰好是从 $T$ 经过有限展开路径可达的图，包含 $T$ 本身。没有额外外顶端。特别地，$T[0]=[]$、$T[0][0]=0$。构造器和解析器只验证有限图结构，不判断是否属于标准域。

对有限图 $G$，旧末列之前的列在展开时不变。$G[n]$ 是 $G[n+1]$ 的完整列前缀；末列有关系时为真前缀。非零展开总使列序严格变小。所有行标为有限数时，这张图的展开规则与当前 RPD 一致，但这本身不证明两套记号具有前序段关系。

链接的纸面证明在 $KP_\omega+\exists\text{不可数序数}$ 内证明标准域良序。发布包也包含通常经典 Lean 证明，但并非弱集合论的编码推导。本文不声称最小公理强度或序型比较。

## 5. 局部计数与显示

NER 文件提供无损单行列表、计数序列和山脉图。计数只是显示：不同图可能有相同数列；数列不作为比较键，也不能反解成唯一的图。

对每列固定左前缀，把该列当作末列，作任意正指标展开，然后丢掉新追加的列。重复这个固定宽度的局部操作，直到该列无关系，再删除它。计数包括最后一次删除；空关系列计数为一。保留下来的位置只涉及第 $b=0$ 个接缝，故全部正指标的局部操作相同，包括生成包 $P_0(K)$。

计算完成时显示精确计数；触发资源限制时明确标为未完成，不悄悄截断答案。局部计数终止不能单独证明允许增长列数的全局展开终止。

| 表达式 | 计数序列 |
| --- | --- |
| $T$ | `1,5` |
| $T[1]$ | `1,4` |
| $T[2]$ | `1,4,19` |
| $T[2][1]$ | `1,4,18` |

## 6. 软件使用

在 NER 的自定义记号入口导入 `LRD.ne-rewritten.js` 并选择 LRD。三个接口 `FS`、`FS_alter`、`FS_short` 完全相同。文件原样复制，保留中文显示标签及资源保护；保护阈值不是额外数学规则。

独立 Python 定义需要 Python 3.10+，不依赖第三方包。在本目录运行：

```sh
python lrd.py 2 1
```

它从 $T$ 出发，输出 $T[2][1]$。作为库使用：

```python
from lrd import Row, LRD, T
assert Row((0, 0, 1))[2] == Row((0, 3))  # (w^2)[2] = w*3
a = T[2]
assert a < T
assert a[0] == LRD(a.columns[:-1])
```

`Row((a0,...,ad))` 按次数从低到高储存系数；`Row(None)` 表示 $\omega^\omega$。整数使用任意精度。Python 库没有时间、宽度或内存保护，极大展开可能耗尽资源。发布测试有明确边界，对照独立 Python 算法与 NER 实现。

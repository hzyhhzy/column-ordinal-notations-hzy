# RPD：有限列图定义 — [English](definition.md)

发布定义，2026-09-13。[PDF](definition.zh-CN.pdf) · [NER 展开器](RPD-mountain.ne-rewritten.js) · [Python](rpd.py) · [良序证明](../../proofs/paper/well-ordering.zh-CN.md)。

本文定义当前按列比较的 RPD，不是旧操作路径记号。表达式就是图本身；不同构造历史不会产生不同表达式。程序的资源保护不属于数学规则。

## 1. 有限语法与根闭包

有限图是 $G=(m,E)$，列号为 $0,\ldots,m-1$，有限关系集中的元素为

$$
(k,q,p,j),\qquad k\in\mathbb N,\quad 0\le q\le p<j<m.
$$

$k$ 是行标，$q$ 是根列，$p$ 是父列，$j$ 是子列。要求根向下闭合：

$$
(k,q,p,j)\in E\implies(k,u,p,j)\in E\quad(0\le u\le q).
$$

用 $\downarrow E$ 表示补全小根的操作；它不会补全所有较低行标。重复关系忽略，空列保留。空图 $0=(0,\varnothing)$ 写作 `∅`；`[]` 是一列空列，不是空图。

列表中每个方括号是一列。三元组 `(k,p,q)` 依次表示行标、父列、最大根；子列由位置确定。最大根 $q$ 代表全部根 $0,\ldots,q$。同一 $(k,p)$ 组合取最大根，也可逐个列出全部根。Python 存储全部根，NER 列表使用最大根压缩；二者编码同一张图。

## 2. 比较

每列按键 $(p,k,q)$ 降序排列，再按该键逐项作字典序比较；整图从左往右逐列比较。关系列表与列序列两级都以真前缀较小。同图相等，与构造历史无关。最大根压缩和全部根展开给出相同的比较。

外加顶端 $\Omega$，规定它大于所有有限图；它不能用作行标。

## 3. 基本列

指标 $n$ 是非负整数。定义两列种子

$$
S_n=\bigl(2,\{(k,0,0,1):0\le k\le n\}\bigr),\qquad \Omega[n]=S_n.
$$

规定 $0[n]=0$，不将此恒等式计为严格下降步。对非空图令 $x=m-1$，以 $\partial G$ 表示删去列 $x$ 及以它为子列的所有关系。规定

$$
G[0]=\partial G,\qquad
G[n]=\partial G\text{ 对所有 }n\text{ 成立，若末列为空。}
$$

余下考虑 $n>0$ 且末列有关系。按键 $(k,q,p)$ 取末列最大的控制关系，写成 $(K,r,c,x)$。控制优先级是**行标、根、父列**，与比较优先级**父列、行标、根**不同。令

$$
\ell=x-c>0,\qquad
\phi_b(i)=\begin{cases}i&i<c,\\i+b\ell&i\ge c,\end{cases}
\qquad E^- =\{(k,q,p,j)\in E:j<x\}.
$$

对关系施加 $\phi_b$ 时同时移动三个列索引，行标不变。每个接缝 $0\le b<n$ 定义为

$$
\begin{aligned}
U_b=\{(k,u,\phi_b(p),x+b\ell):\;&(k,q,p,x)\in E,\quad 0\le u\le\phi_b(q),\\
&k<K\ \text{或}\ (k=K\text{ 且 }u<\phi_b(r))\}.
\end{aligned}
$$

完整的正指标规则为

$$
G[n]=\left(x+n\ell,\ \downarrow\left(
\bigcup_{b=0}^{n}\phi_b(E^-)
\ \cup\ \bigcup_{b=0}^{n-1}U_b\right)\right).
$$

也就是删旧末列，源块 $[c,x)$ 保留原位并再复制 $n$ 份，总共 $n+1$ 份；接缝保留较低行及同一行较小根。RPD 没有额外的行标生成包。所有并集、循环和闭包都有限；展开不包含可达性搜索或语义判定。

对有限图 $G$，$G[n]$ 是 $G[n+1]$ 的完整列前缀；旧末列有关系时为真前缀。旧末列之前的列保持不变。外顶端的 $S_n$ 不要求满足列前缀关系。

## 4. 标准域与良序范围

标准有限图是包含每个 $S_n$、并对所有操作 $G\mapsto G[n]$ 封闭的最小集合。本记号由这个集合和 $\Omega$ 构成。手写的结构合法图未必是标准式，不能将列良序结论扩大到整个原始语法域。

每个非零有限图的展开项都在列序下严格变小。种子满足 $S_{n+1}[1]=S_n$。链接的纸面证明在 $KP_\omega+\exists\text{不可数序数}$ 内证明标准域及顶端良序。配套 Lean 是通常经典公理下的证明，不是该弱集合论的编码推导。本文不声称 RPD 与 Y 或 LRD 的序型大小关系。

## 5. 显示与局部计数

NER 提供列表、计数序列、操作记录和完整山脉图。操作记录只记录来源；计数既不参与比较，也不唯一编码图。

对第 $j$ 列固定左侧上下文 $P$，将它的关系集 $C$ 当作末列。若 $C\ne\varnothing$，作任意一次正指标展开，再丢掉右侧新增列。将第 $j$ 个位置的结果记作 $T_P(C)$。等价地，若控制关系为 $(K,r,c,j)$，则

$$
T_P(C)=C_c\cup\{(k,p,q)\in C:k<K\text{ 或 }(k=K\text{ 且 }q<r)\},
$$

这里 $C$ 和 $C_c$ 都是展开全部小根后的关系集，不是最大根压缩列表；$C_c$ 是源列的关系，现在以 $j$ 为子列。当某个压缩三元组的最大根不小于 $r$ 时，公式仍可能保留其中小于 $r$ 的根。定义

$$
h_P(\varnothing)=1,\qquad h_P(C)=1+h_P(T_P(C))\quad(C\ne\varnothing).
$$

计数包括最后删除空关系列的一步。局部过程终止：所有关系来自固定有限集合，而列序严格下降。正指标展开使旧末列位置的数字恰好减一，之后可能追加数字；指标零删除末数字。空图显示 `0`。

| 表达式 | 计数序列 |
| --- | --- |
| $\Omega[0]$ | `1,2` |
| $\Omega[1]$ | `1,3` |
| $\Omega[1][2]$ | `1,2,5` |
| $\Omega[1][2][1]$ | `1,2,4` |

## 6. 使用展开器

在 NER 的自定义记号入口导入 `RPD-mountain.ne-rewritten.js`，选择 RPD。`FS`、`FS_alter`、`FS_short` 的指标约定相同。文件从当前实现原样复制，显示标签保持中文。资源保护会拒绝超大任务，不返回截断的数学答案。

Python 3.10+ 只依赖标准库。在本目录运行：

```sh
python rpd.py 1 2
```

输出 $\Omega[1][2]$。作为库使用：

```python
from rpd import RPD, ZERO, TOP
a = TOP[1][2]
assert a < TOP[1]
assert a[0] == RPD(a.columns[:-1])
```

Python 使用任意精度整数，不截断图，也不判定标准性。极大展开可能耗尽资源。发布包中的有界测试对照 Python 与 NER，但不是对全部输入的实现等价证明。

## 1. 列与祖先图

ACD 全称 **Ancestral-Context Diagrams**。有限式是列串 $G=(C_0,\ldots,C_{m-1})$。第 $j$ 列是有限部分函数 $p\mapsto h$，其中 $0\le p,h<j$。两个数分别为**父地址**和**头来源地址**，彼此没有大小限制。记录按父地址递减存放。

对第 $i$ 列，收集它自身及沿父、头两类引用得到的全部祖先；保留原先后顺序，连续重编号，得到**祖先图** $V_i$。共享引用仍共享，不展开成树。空列的祖先图都是一列空列。

每列一对方括号，记录用分号分隔：

```text
[][0:0][1:0;0:0][2:1;1:0;0:0]
```

地址从零开始；`0` 无列，`[]` 表示一。外顶端 `Limit of ACD` 不是可引用的列。

## 2. 比较与合并

图按列字典序比较；列内按父递减的顺序比较记录，记录的比较键是 $(p,V_h,h)$。祖先图递归使用同一种比较，内部地址以重编号后的图为准。两级列表都是真前缀较小。

递归会进入更小的祖先图，因此比较终止。这是严格全序，**不是良序证明**。合并时，同父记录按 $(V_h,h)$ 留较大的头。

## 3. 末列降低

设末列非空，位置为 $x$。

1. 选取使 $(V_h,c)$ 最大的控制记录 $(c,h)$。
2. 在全部 $k<x$、$V_k<V_h$ 的来源中选最大祖先图；并列时取最大地址 $k$。
3. 将控制换成 $(c,k)$；若不存在较小祖先图，就删掉控制。
4. 合入旧父列 $C_c$，同父冲突按上一节处理。

所得列记为 $D$，此前列不变。这里只进行有限前缀扫描，不运行整式下降至零的过程。

## 4. 反射与基本列

令 $L=x-c$，搬运 $\phi(i)=i$（$i<c$），否则 $\phi(i)=i+L$。复制时父、头**两个字段都搬运**。定义一次反射

$$
R(G)=(C_0,\ldots,C_{x-1},D,\phi(C_{c+1}),\ldots,\phi(C_x)).
$$

最后复制的是**旧末列模板**，不是 $D$。下一次反射在实际新图中重算祖先图与控制，不冻结第一次的头或切点。

以 $\partial$ 表示删末列。规定 $0[n]=0$；末列为空时 $G[n]=\partial G$；否则

$$
G[n]=\partial R^n(G),\qquad n\in\mathbb N.
$$

于是 $G[0]=\partial G$，且 $G[n]$ 是 $G[n+1]$ 的完整列前缀。各次反射的复制块可以不同。每个非零展开都严格降低指定列序，但这本身不证明整体终止。

## 5. 种子与标准域

种子 $S_n$ 有 $n+1$ 列：$C_0=\varnothing$，$C_j=\{(j-1,j-1)\}$（$1\le j\le n$）。外顶端满足 $\mathsf{Top}[n]=S_n$，且 $S_{n+1}[0]=S_n$。

**标准域只包含这些种子的有限基本列后代。** 解析器接受一个手写图，不代表已经证明它标准可达。

```text
S1    = [][0:0]                         计数 1,2
S1[n] = n+1 个空列
S2    = [][0:0][1:1]                    计数 1,2,4
S2[1] = [][0:0][1:0;0:0]                计数 1,2,3
S2[2] = [][0:0][1:0;0:0][2:1;1:0;0:0]  计数 1,2,3,5
```

## 6. 计数与使用

每列固定此前前缀，反复执行局部降低直到空列，再加删除空列的一步。空列计数为一；这**不是**反复展开整个式子。固定位置 $j$ 后，把可用头来源排序，可以给出 $(j+1)^j$ 的局部倒计数上界；这不排除列数无界的无限链。

将完整 JS 导入 NER 自定义记号，选择 **ACD候选**。支持列表、精确计数序列、完整三角邻接表；可输入 `S2`、`0`、`Limit of ACD` 或完整列表。`FS`、`FS_alter`、`FS_short` 共用规则。超限不是数学不终止；未知计数显示 `?`，不参与比较。

Python 只用标准库。在本目录可执行：

```python
from acd import ACD
g = ACD.seed(2)
print(g.fs(2))
print(g.counts())
```

可读 Python 核心没有自动展开预算；请限制指标和列数，昂贵的 `counts` 调用应传入有界 `tick` 回调。本定义不包含整体良序证明，也不声称 ACD 已超过 e0MN、IPD 或 wY。

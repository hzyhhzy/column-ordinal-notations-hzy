## 0. 结论

记 A=I[0][1]，A_n=A[n]。本篇证明：

> 对任意 n，以及从 A_n 出发的任意有限串真实基本列操作，
> 途中每一步的原生补全均不插入点，标记补全均不修改行。
> 原复制也始终有定义，不会落入首份复制失败后退化为删尾的容错分支。

因此，以从 A 真实展开可达的标准下段为范围，
$$
\boxed{\text{严格位于 01 以下的式子，继续展开不会触发有效补全。}}
$$

“以下”不包括任意手写的、仅比较键较小的非标准输入。
A 自己生成 A_n 时确实可能补全，本定理不把 A 自己包括在内。

本证明是有限结构不变量的归纳，不以 BMS 良序性、IBLP 良序性或全局无补全为前提。
它本身不证明反向 BMS 上界；后续的
[接口桥覆盖证明](<IBLP-01-BMS-upper-bound.zh-CN.md>)另行补齐了上界和等号，依赖本篇而不反过来作为本篇前提。

## 1. 基础类 C 与本篇记号

沿用 [正接口封闭引理](<IBLP-01-unconditional-BMS-lower-bound.zh-CN.md>)第 1–6 节的类 C。
该文给出了完整分情况证明；本篇在此基础上补齐零接口复制。

体行 i 的点列、步长为 R_i、L_i，定义
$$
q_i=|R_i|-L_i-1,\quad p_i=R_i[q_i],\quad
P(i)=R_i[-2],\quad h_i=R_i[L_i],
$$
以及
$$
J_i=R_i[1:q_i+2]\cup R_i[L_i+1:].
$$
P(0)=q_0=0。h_i 是末端链的首点，以下简称“层头”。

类 C 的条件简述如下：

1. 有序行、行内星号、平面 P 森林、所有引用都是祖先；
   0≤q≤L，零接口行恰为两点行；前端加一点和末端均为连续 P 链。
2. 高接口行 q_i=s≥2 的末端链 (w_0,…,w_s=i) 上，各位置满足 q_(w_t)=t，1≤t≤s。
3. 正接口行的切点满足 q_(p_i)∈{0,1,q_i}。
4. 正接口行的首点，不是其切点子树中任一行的 J 内部点。
5. 对高接口行，层头 w_0 不属于 i 之前、位于 w_1 子树内的任何行的 J 集。

C 对删尾和任意正接口原始复制封闭。
这里的“原始复制”包含工作末行，尚未执行补全和最后删尾。

## 2. 加强类 D

D 是 C 中满足以下五项额外条件的模式。下列条件都直接读取有限行数据，
不把“可达性”隐藏在定义里。

### D1：内部端口不是终结型

若 q_i=s≥2，其末端链为 (w_0,…,w_s)，则
$$
L_{w_t}\ge t+2\qquad(1\le t<s). \tag{D1}
$$
基础条件已经给出 q_(w_t)=t。

### D2：同接口切点不是终结型

若 q_i>0 且 q_(p_i)=q_i，则
$$
L_{p_i}\ge q_i+2. \tag{D2}
$$

### D3：低接口行不能接在高接口终结型节点下面

若 q_i≤1，c=P(i)>0，且 q_c≥2，则
$$
L_c\ge q_c+2. \tag{D3}
$$

### D4：碰到高层头，只能是同层头的终结型行

若 q_i≥2、$i\preceq_P j$，并且 h_i∈J_j，则
$$
q_j\ge2,\qquad L_j=q_j+1,\qquad h_j=h_i. \tag{D4}
$$

本条件包括 j=i。“终结型”在本篇精确定义为 q≥2 且 L=q+1；
“非终结型”指 L≥q+2，不含额外语义假设。

由连续末端链，D4 还蕴含
$q_j=q_i+\operatorname{dist}_P(i,j)$，故 j>i 时 q_j>q_i。
此外，高接口行不可能有 L=q：否则自身层头属于 J_i，与 D4 矛盾。

### D5：碰到层头的分支必须是最后分支

若 q_i≥2、i<j、$i\preceq_P j$、h_i∈J_j，则
$$
j\le t,\quad i\preceq_P t
\quad\Longrightarrow\quad j\preceq_P t. \tag{D5}
$$

即在 i 的子树中，经过这种 j 后，不准再返回到 j 的兄弟分支。
对平面森林，等价于 i 与 j 的子树右端点相同。

这正是上一轮手写坏输入 D_old 所缺的条件：
它在已有终结型分支后面，又附加一个返回祖先的兄弟分支。
该输入不是本类 D 的成员，不能充当本定理标准域内的反例。

## 3. 两种原始复制及一个搬运引理

以下用 c 表示当前切点，N 表示当前末点。一次原始复制把源体行 c,…,N
搬到 N,…,2N−c，保留 N 之前的前缀。行的 L、q 和 J 的位置随严格递增函数 f 搬运：
$$
J'_{f(i)}=f[J_i].
$$

### 3.1 正接口控制

当 k=q_N>0，令前端链为
$(u_0=a,\ldots,u_k=c)$，末端链为
$(v_0,\ldots,v_k=N)$。
复制函数为
$$
f(x)=x\ (x<a),\quad f(u_t)=v_t\ (t<k),\quad
f(x)=x+N-c\ (x\ge c).
$$

新接缝 N 的父仍是旧 P(N)=v_(k−1)。
基础类 C 的证明已经保证复制定义性、C0–C4 保持。

### 3.2 零接口控制

非后继零接口末行为 (c,N)，c=P(N)>0，L_N=1。
此时
$$
f(x)=\begin{cases}x&x<c,\\x+N-c&x\ge c.\end{cases} \tag{3.1}
$$

新接缝 N 的父为旧 P(c)，而不是旧 P(N)=c。
新尾子树成为旧 c 子树的一个新兄弟子树。这是与正接口情形唯一关键的森林差异。

f 对所有整数有定义，并逐边搬运所有源 P 边；
复制区内的祖先关系和节点类型完全保留。

### 3.3 旧高接口节点与新尾段的层头搬运

设 i<N 为保留的旧高接口节点，某个新复制行 j'=f(j) 是 i 的后代，
且 h_i∈J'_(j')。

则：

- 正接口情形中必有 i<c、h_i<a，且 h_i 固定；
- 零接口情形中必有 i<c、h_i<c，且 h_i 固定。

两种情形下，源行 j 也是旧 i 的后代，且 h_i∈J_j。

零接口情形直接来自新接缝接在 P(c) 下面。

正接口情形的证明如下。新尾段位于旧 N 的原父项下面，所以 i 是旧 N 的祖先。
因 h_i<i<N，层头若来自搬动区，只可能是某个 v_t，0≤t<k。

- t=0 时，原像 a 被控制行的前端首点屏障排除，不能是被复制行的内部点。
- t>0 时，i 是 v_t 之后、N 之前的祖先，故 i=v_s，s>t。
  基础条件给出 q_i=s，所以 i 的末端链首点实际是 v_0，不可能是 v_t。

因此 h_i<a，固定不动。若 i≥c，则旧 i 的连续末端链从 h_i 跨过 a 到 i，
把 a 用作内部点，仍违反控制行的屏障。故 i<c；
i 是 c 的祖先，源尾段当然位于 i 的子树中。引理得证。

## 4. D1、D2、D3 在复制下保持

### 4.1 D1

对正接口复制，使用基础证明的“末端第二点分类”：

- 若被复制高接口行的末端第二点≥c，全部内部端口正常复制，类型不变。
- 否则，源末端链从 a,u_1,…,u_k=c 开始，且 q_c=k。
  u_t（1≤t<k）搬到旧 v_t，由旧 D1 保证类型；
  c 的副本成为新接缝，其接口数 k，由控制行的 D2 保证 L_c≥k+2；
  后面的内部点正常复制。

因此新末端链全部内部端口满足 D1。

零接口复制中，每个端口要么固定，要么和其类型一起复制，D1 直接保持。

### 4.2 D2

正接口复制时，基础证明已分类被复制正接口行的切点 r：

- r<a 或 r≥c：切点类型不变，继承原 D2。
- 中间情形 r=u_t，1≤t<k：该源行接口数恰为 t；
  新切点为旧 v_t，其接口数也是 t，旧 D1 给出 L_(v_t)≥t+2。

零接口时，所有切点类型只作固定或搬运。故 D2 保持。

### 4.3 D3

只需检查复制出来的低接口行，q≤1。
若源行 i>c，其父也在尾段中，父节点的 q、L 都原样复制，继承源 D3。

剩下的是源行 i=c 被复制为新接缝，且 q_c≤1。

正接口控制的接口数为 k：

- k=1：新父为旧 P(N)=v_0，旧 N 自己就是低接口行，其 D3 正好给出所需条件。
- k=2：新父 v_1 的接口数为 1，不触发 D3 的高父条件。
- k≥3：新父 v_(k−1) 的接口数为 k−1≥2，旧 D1 保证它非终结型。

零接口复制中，新父为旧 P(c)；源 c 自己的 D3 保证所需条件。
旧前缀中的低接口行及其父都未改动。因此 D3 保持。

## 5. D4 与 D5 在复制下保持

### 5.1 D4

将待检查的高接口节点 i' 和命中其层头的后代 j' 分三类：

1. **两者都是旧前缀节点：**行数据、祖先关系未变。
2. **两者都在新复制区：**祖先关系、内部点位置和 q、L 都随 f 搬运，
   直接使用源 D4。源层头相等，像层头也相等。
3. **i' 为旧节点、j' 在新尾段：**第 3.3 节说明层头固定，源 j 也是旧 i' 的后代，
   且已经命中同一个层头。源 D4 给出 q_j≥2、L_j=q_j+1、h_j=h_(i')；
   这些事实搬运后原样成立。

旧 j' 不可能在新 i' 之后成为其后代，故分类完整。D4 对两种复制均保持。

### 5.2 正接口复制保持 D5

若新的高接口 i' 在复制区，其后代 j' 也在复制区，源 D5 直接搬运。

若 i' 是旧高接口节点：

- **旧的命中行 j'<N：**若有新尾段进入 i' 的子树，旧 N 也在其中。
  源 D5 说明 j' 是旧 N 的祖先。j'<N，故也是旧 P(N) 的祖先；
  新尾段仍接在旧 P(N) 下面，因而仍在 j' 的子树中。
- **新复制的命中行：**由第 3.3 节，源命中行 j 位于旧 i' 子树中。
  源 D5 保证源尾段里所有在 j 之后的相关节点都是 j 的后代。
  复制保持尾段祖先关系，故新命中行后的整个相关尾段仍在其子树内。

### 5.3 零接口复制保持 D5

设旧高接口 i'<N 的子树包含新尾段。此时 i' 是 P(c) 的祖先，故 i'<c，
而旧 N 是 c 的直接孩子。

先看旧命中行 j'<N。源 D5 说明 j' 是旧 N 的祖先，因此 j'≤c。

- 若 j'<c，新尾段接在 P(c) 下面，仍是 j' 的后代。
- 若 j'=c，源 D4 要求 c 为高接口终结型：L_c=q_c+1。
  但旧末行 N 是零接口行，其父为 c，D3 要求 L_c≥q_c+2，矛盾。

再看新复制的命中行，源为 j≥c。
第 3.3 节和源 D5 说明 j 是旧 N 的祖先，所以 j 只能是 c 或 N。

- j=c：再次由 D4 与旧末行的 D3 得到终结型/非终结型矛盾。
- j=N：源 D4 要求 q_N≥2，与当前零接口控制矛盾。

所以这种新命中行不可能出现。
复制区内新高接口节点的 D5 仍由源条件直接搬运。D5 得证。

## 6. 补齐零接口复制对基础类 C 的保持

原正接口引理已证明正接口复制保持 C。这里只检查零接口控制，
其中 c=P(N)>0，新接缝父为 P(c)。

### 6.1 C0、C1、C2

函数 (3.1) 全定义、严格递增、逐边搬运父关系。
复制子树接在旧 c 子树之后，仍为平面森林。
前后端链、行内祖先性、行长和步长均保持。
所有被引用节点的接口数要么不变，要么按副本保持，因此 C1、C2 保持。

### 6.2 前端首点屏障 C3

对复制正接口行，若其切点在 c 及右侧，新切点子树完全在复制区，直接搬运源 C3。
若切点在 c 之前，它是旧 c 的祖先，行首点固定；
源 C3 已保护全部旧前缀和所有尾段源行，仍保护新复制行。

对旧正接口行，只有当其切点是 P(c) 的祖先时，新尾段才进入该切点子树。
此时切点和行首点均在 c 之前且固定；源尾段也位于该切点子树内，
原 C3 直接排除同一内部点。其余旧关系不变。故 C3 保持。

### 6.3 末端首点的前缀屏障 C4：最后缺口

考察复制的高接口源行 i，末端链为
$$
(w_0,w_1,\ldots,w_s=i),\qquad s=q_i\ge2.
$$

若 w_1≥c，新 w_1 及其子树均在复制区，直接搬运原 C4。

若 w_1<c，因为 i≥c，而整串是连续祖先链，c 出现在第 t≥2 个位置。
C1 给出 q_c=t，且 c 自己的末端链恰是
$$
(w_0,w_1,\ldots,w_t=c).
$$
于是 h_c=w_0，且 w_0、w_1 均由 f 固定。

需要排除旧前缀中 w_1 子树里的内部点 w_0。按位置分为：

- **j<c：**由源节点 c 的 C4 排除。
- **j=c：**旧末行 N 是零接口行、父为 c，D3 给出 L_c≥q_c+2。
  层头 R_c[L_c] 既不属于前端内部点段，也不是末端链的非首点，因此 w_0∉J_c。
- **c<j<N：**这些点都在 c 的子树中。若 w_0∈J_j，D5 对 c、j 的应用
  将迫使旧 N 为 j 的后代；但 P(N)=c，N 是 c 的直接孩子，不可能，矛盾。

新复制区中，位于新 i 之前的相应源行仍由原 i 的 C4 保护。
故 C4 保持，零接口情形的基础类缺口补齐。

## 7. 全操作闭包与无补全

第 4–6 节共同证明：

> 若 X∈D，且 X 非零、非后继，则原始完整复制有定义，输出（包括工作模板）仍属于 D。

所有 D 条件对截取前缀保持：

- 类型条件和左侧引用不变；
- 屏障只减少被检查的后代；
- D5 只减少较晚节点，不增加任何返回分支。

所以可反复原始复制任意有限次，再删尾。
指标 1 的特殊操作则是第一份原始复制截到原宽度，仍属于 D。

D 包含 C0，因此每个新行满足
$$
P(R_i[q_i+1])=R_i[q_i].
$$
原生补全第一次取父就到达切点，不插入点；一次展开的记录 record 始终为空，
标记补全也不修改行。星号过滤只删星号，不改变体行。

因此原程序的真实基本列与上述原始复制结果完全一致：

- 零式、后继、指标 0：按原规则删尾；
- 其他指标 1：复制切点行并保留原宽度；
- 其他指标 m≥2：m−1 次原始完整复制后删工作末行。

这些都是原定义允许的步骤，未关闭补全，未省略中间点。

## 8. 所有 A_n 的初始验证

所有 A_n∈C 已在正接口文稿第 7 节由全指标闭式证明。
下面补充 D1–D5。A_0、A_1 无高接口行，直接检查即可。

对 n≥2，每个阶段 t 的端口依次为 b_1,…,b_t，接口数为 1,…,t，
末端链共同起于 b_0。其步长为
$$
L_{b_k}=\begin{cases}k+2&k<t,\\t+1&k=t.\end{cases}
$$

- **D1：**内部端口 k<t 的步长是 k+2。
- **D2：**所有正接口切点是骨架 a_k；其接口数只有 0 或 1，
  而所有接口数 1 的行都切到接口数 0 的最左根，所以同接口条件不触发。
- **D3：**零、单接口行的父都是辅助根或骨架单接口行，不是高接口节点。
- **D4：**固定阶段内高接口 i=b_k。其高接口子树只包含同阶段余下的端口；
  后续阶段接在单接口骨架上，不是这些高接口端口的后代。
  对同阶段的 b_l，层头 b_0 不属于末端内部点；
  它只有在 l=t 时才出现在前端内部点中。
  此时 L_(b_t)=t+1，且层头仍是 b_0，恰为 D4 所要求的终结型。
- **D5：**上述唯一可能的命中行 b_t 是该高接口子树的最后叶子；
  因而不存在其后的返回兄弟分支。

因此所有 n 均有 A_n∈D。结合第 7 节，对任意有限展开历史作普通归纳，
得到第 0 节的无补全定理。

## 9. 顺带得到的比较性质，以及未完成的上界

正接口展开的严格比较下降已在基础文稿中证明。
零接口控制 X 的旧末行键为 (N,c)；复制切点行后的新键第二项为 P(c)<c，
因此也严格下降。删尾当然下降。

此外，由原始逐块复制和截尾公式，实际基本项随指标为前缀链
（允许指标 1、2 在跨度为 1 时相同）。

这些性质没有单独证明良基性。尤其不能由有限宽度或有限接口数直接推出 BMS 上界。
目前已经有：
$$
\mathcal B_{\rm std}\hookrightarrow\mathcal I_{<01},
$$
见[无条件 BMS 下界](<IBLP-01-unconditional-BMS-lower-bound.zh-CN.md>)。

尚需对每个 A_n 的整个后代闭包给出有限行数 BMS 宿主，
或其他足够强的反向保序嵌入，才能得到 01 恰等于 BMS 极限。

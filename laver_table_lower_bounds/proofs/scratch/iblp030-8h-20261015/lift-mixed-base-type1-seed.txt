1. Two different bases, and a coordinate-free E doubling lemma
-------------------------------------------------------------
Keep the NUMERICAL base k0<k1<k2 fixed. A current supplied m-linedness
witness on this triple determines the numerical parameter m.

Also retain an actual helper actor D with
  D(k0)=k0, D(k1)=k1, D(k2)=w>k2.
The HELPER base is (k0,k1,w), and w is also the operator control. The
D-image of the supplied numerical witness is an m-linedness witness
on this helper base. It can be rebuilt at any call from the current D
and the unchanged numerical witness; no inverse image is assumed.

We use the following elementary coordinate-free form of E. Suppose
  p0<p1<p2<c<l<r,
  S(p0)=c, S(p1)=l, S(p2)=r,
and there is an m-lined chain with owners L_i, common root p0,
  r_0=p1, r_m=p2, L_i(p0)=r_i, L_i(r_i)=r_(i+1).
The actors S(L_i) have critical point c, send c to S(r_i), and send
S(r_i) to S(r_(i+1)). Consequently they double an actual prefix block
on [c,S(r_i)] into its original copy followed by its application image,
with endpoint S(r_(i+1)). Starting with endpoint l gives 2^m copies
ending at r. Everything below c is fixed. This proof uses only the
displayed actual points, not that p0,p1,p2 have physical addresses
0,1,2 or that no other global base point lies between them.

This lemma is the ordinary actual E construction with explicit point
sources. We distinguish two invocations:
  * operator-zero E: source is numerical (k0,k1,k2), threshold w;
  * spare E: source is helper (k0,k1,w), threshold a payload-band left.
Both copying thresholds lie strictly above k2 and fix the numerical
base. Only the first kind moves the helper third point w.

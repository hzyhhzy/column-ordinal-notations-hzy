1. Framework and established inputs
------------------------------------
Let j:V_lambda->V_lambda witness I3, and work in the same Iter(j), closed
under application and finite ordinary composition. Put k0=crit(j),
k_(i+1)=j(k_i). Generated critical points are gamma_i in increasing order.
Application F(G) and ordinary composition F o G are DISTINCT:
  F(G)(F(t))=F(G(t)).
An actor value at t cannot be read by this formula unless t is the
displayed F-image. Write F(<t) for the strict supremum of F(u), u<t.
Application transports strict suprema:
  F(G)(<F(t))=F(G(<t)).

An m-line on (p0,p1,p2) consists of p1=t0<...<t_m=p2 and actual owners
L_i with critical point p0 and L_i(p0)=t_i, L_i(t_i)=t_(i+1).
The established critical-counting theorem gives
  k4=gamma_(F(4)), q(5)=F(4)+1,
  m-lined(k0,k1,d) => gamma_(2^m)<=d.
Hence such a line ending below k4 implies q(5)>2^m.

Hardy uses the ORIGINAL Python IBLP semantics, without run-time guards:
  H_empty(x)=x;
  H_(Q+true successor)(x)=H_Q(x+1);
  H_Q(x)=H_(Q[x])(x) otherwise.
A true successor is a final row (0,last_index):1. A failed-copy cut is
not declared a successor. The exact source cone used here has no failures.

4. Strict-sup theorem paying for all six types
---------------------------------------------
Every composition power in this section is ORDINARY composition.
The published approximation K~j o j below mu shows j^2(t)=K(t)
for t<k2, since K(t)<mu. Hence j^2(<k2)=K(<k2)=v.

Exactly c=(K o K)(j), and consequently
  c o c=(K o K)(j o j).
Since K^2(k2)=a, transport of strict suprema gives
  c^2(<a)=K^2(v).                                    (4.1)
Using K=j10(j), j10=j9(j), always at genuine image arguments,
  K^2(v)=K^2(j10(s))=j10(j^2(s))=j10(K(s)).
The published strict-sup comparisons give
  K(s)<j10(s)<j9(s),       j(s)<k3.
Therefore
  K^2(v)<j10(j9(s))=j9(j(s))<j9(k3)=theta8<k4.       (4.2)

Exactly A=(c o c)(K), and c^2(mu)=a. Thus
  A(<a)=c^2(K(<mu)).
The generated critical cardinal mu is regular and K(mu)=a>mu, so
K(<mu)<a. Strict increase and the fact that a is a limit now yield
  A(<a)<c^2(<a)=K^2(v)<theta8.                        (4.3)
In particular A(x)<theta8 for EVERY x<a, including mu and theta5.
This does not claim A(a)<k4; in fact A(a)>k4, a boundary never used.

Put T=j10(j3), rho=j10(gamma3). The approximation
j3~j o j below gamma3 transports to
  T~K o K below rho.
Exact image readings give T(k0)=mu, T(k2)=rho, T(mu)=a.
As k1<k2, T(k1)<rho, so reading the cutoff from this strict T side
gives T(k1)=K^2(k1)=theta5. Consequently
  mu<theta5<rho<T(k3)<T(v)<a,                         (4.4)
using k3<v<mu. Define Z=A(T); it fixes k0,k1 and has
  Z(k2)=A(mu), Z(k3)=A(theta5),
  Z(a)=A(rho), Z(c_exit)=A(T(k3)).                    (4.5)
These are actual A-images, not application/composition substitutions.
Every A-argument in (4.5) is <a, so (4.3) bounds them all by theta8.

5. Six actual whole-object environments, with domains
------------------------------------------------------
Each row transports the SAME low open fan. The actual numerical base
remains (k0,k1,k2). The higher helper base is a different source.

 level  environment   helper       first payload left   closed output
   0    id            k2           k3                   a
   1    V             k3           a                    c_exit
   2    Q             a            c_exit               A(mu)
   3    Q o V         c_exit       A(mu)                A(theta5)
   4    Z             A(mu)        A(theta5)            A(rho)
   5    Z o V         A(theta5)    A(rho)               A(T(k3))
   6    Z o Q         A(rho)       A(T(k3))             theta8

The first V values are V(k2)=k3, V(k3)=a, V(a)=c_exit.
Q values are Q(k2)=a, Q(k3)=c_exit, Q(a)=A(mu),
Q(c_exit)=A(theta5). They follow from A(k0)=k2, A(k1)=k3,
A(k2)=a, A(k3)=c_exit and the corresponding K values.
Rows 3 and 5 then follow by ordinary composition. Row 4 is (4.5).
Row 6 has the stated first two values. Its dangerous CLOSED last
value is not used. Instead Q(<a)=A(v), so
  (Z o Q)(<a)<=Z(Q(<a))=Z(A(v))=A(T(v))<theta8.     (5.1)
The first relation is deliberately an inequality: an ordinary composite
need not commute with a strict supremum continuously. Each particular
source cap x<a satisfies Q(x)<A(v), hence Z(Q(x))<A(T(v)); this is
the strict actual bound required by the initializer.

For levels >=1, the usual two-row scalar f0(m)=m*2^m supplies a
g(m)-line at k3 from the real m-line. Extend its endpoint to the row's
helper and drive its transported low fan. This needs no inverse image
of the supplied witness. It gives payload B_g(m), and g(m)>=2 makes
the source cap STRICTLY <a, licensing the open cut in (5.1).

Here is the whole-type seam check. Each helper is exactly the preceding
level's new argument admission, and its first payload left is exactly
the preceding level's chosen output. A helper anchor has images
(helper,left,port1). Read it at the smaller numerical/lower source and
repair the last image to the right endpoint; strict monotonicity puts
that image below port1 before repair. The zero actor has critical point
helper, so fixes ALL lower domain coordinates, but moves the current
admission to the preceding whole-result endpoint. Thus each next copied
oracle genuinely accepts its argument. Nonzero spare actors have
critical point at a payload left above all these coordinates.

The domain coordinates are strictly ordered
  k3<a<c_exit<A(mu)<A(theta5)<A(rho)<A(T(k3))<theta8.
No disjoint Qi corridor is being mistaken for such overlapping domains.
The generic E/full-band compiler consequently provides, with ALL input,
argument and outer-environment quantifiers, the operations
  D_r(u)(...)(x)=K_(B_(g(x)))^(r,u)(...)(x), 1<=r<=6.
This is a whole diagonal contract, not just a matrix chosen for one x.
In particular D6(D5)(D4)(D3)(D2)(D1)(S)(f0) is an actual legal program
whose output line ends at theta8<k4.

6. Tail-local numerical comparison, including low scalar padding
-----------------------------------------------------------------
Let X0 consist of nondecreasing f(x)>=x+1. Higher types are extensive
operators preserving every lower tail preorder. The relation <=_b
means comparison at ALL final inputs >=b and all admitted arguments.
Mixed monotonicity and finite iteration preserve this relation.
Source objects initially defined only at x>=2 may be harmlessly
extended at 1; their comparisons here are used only on the tail >=3.

Well-founded induction on BMS, quantified over every base, argument,
and input, gives fast input/base monotonicity and strong prefix:
a proper prefix's whole value may be iterated 2^x times below the
longer matrix's value. Bounded-index descent with indices <=2^x also
cannot increase the fixed-input value. Source limit cover macros are
chosen after fixing x; the induction hypotheses used inside iteration
remain universally quantified. Thus no single-input inequality is
used as though it were a whole-function inequality.

Put N(x)=2+x(x+1)/2 and y=x+2^x-1. For x>=3, y>=N(x)+1, and
  S(S(u))(x)>=[S(u)]^[2^x](x)>=S(u)(y)
    >=G_(B_(N(x)+1))^u(N(x)).
The last step is an explicit seed-height path plus input monotonicity.
The safe-D cover therefore gives
  B0<=_3 S^2,       h<=_3 S^2(f0).                    (6.1)
For r>=1, N(x)<=2^x and g(x)-1>=x+2. The literal path
B_H ->* R_(H-1), using only 0,1,2, and the same cover give
  B_r<=_3 D_r.                                      (6.2)
This is the needed compensation for S's genuine height x.

For every r>=1 and ALL positive inputs, D_r(u)>=u^4 as a whole object.
Indeed g(x)>=2; bounded-index seed paths reduce B_g(x) to two zero
columns 00. If Z_r is the one-zero-column operation, then
Z_r(u)>=u^2 globally since 2^x>=2. Hence
  K_00^(r,u)=Z_r(Z_r(u))>=(Z_r(u))^2>=u^4.           (6.3)

Define the WHOLE operators
  Tstar=D5(D4)(D3)(D2)(D1) in X2,
  W=D6(D5)(D4)(D3)(D2)(D1) in X2.
Fourfold reserve descends through the typed chain:
  W>=Tstar^4.                                       (6.4)
Start with D6(D5)>=D5^4. At each next argument Y use
X^4(Y)>=X^2(Y)=X(X(Y))>=(X(Y))^4 when X>=power-four.
The collapsed X(Y) still dominates the next D_r by extensiveness,
so still has the power-four property. Repeat down the finite chain.
